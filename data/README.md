# SENSE Data MVP

This directory is the portable content contract for the SENSE national tourism platform and national store.

- `schemas/` contains JSON Schema contracts.
- `entities/` contains prototype records for the Al-Eizariya vertical slice.
- All records are bilingual (`ar`/`en`) where public text is present.
- Product commerce is catalog-only; no payment, inventory, or order data is active.
- Prototype media must not be presented as verified field documentation.

The same identifiers are intended for a future WordPress/Blocksy content import and a future API. MABA uses `municipalityId`, `merchantId`, `operatorId`, and `accessPointId` as authorization scope attributes.
