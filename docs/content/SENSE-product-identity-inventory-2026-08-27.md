# جرد نظام هوية المنتجات ومزودي الخدمة — 27 أغسطس 2026

## النطاق

هذا الجرد يصف ما هو موجود فعليًا في نسخة SENSE الحالية، ولا يضيف بيانات منتجات أو مزودين حقيقيين. النظام يربط هوية المنتج بالقراءة العامة والاسترداد وسجل الأحداث ومزود الخدمة ورابط المتجر، مع إبقاء بيانات المالك والموقع الدائم خارج العرض العام.

## طبقات التنفيذ

| الطبقة | الملفات/المكوّنات | الوظيفة |
|---|---|---|
| المخطط | `drizzle/schema.ts` | جداول هوية المنتج، أحداث المرور، بلاغات الاسترداد، ومزودي الخدمة |
| الخادم | `server/routers/productIdentity.ts` و`server/routers.ts` | إصدار الهوية، المسح العام، بلاغ العثور، وإنشاء/عرض مزود الخدمة مع صلاحيات الملكية |
| قاعدة البيانات | `server/db.ts` وملفات الترحيل | مساعدات القراءة والكتابة وربط السجلات بالكيانات الفعلية |
| الواجهة | صفحات الهوية والاسترداد ومزود الخدمة | إدخال بيانات المنتج، اختيار مزود اختياري، عرض رابط NFC/QR، وفتح مسار الاسترداد |
| الاختبارات | اختبارات الصلاحيات والخصوصية ومسارات الاسترداد | منع كشف المالك أو تحويل الوسم إلى أداة تتبع دائم، والتحقق من حالات الوصول |
| المتجر | حقل `storeListingUrl` في إصدار الهوية | ربط اختياري بصفحة المنتج دون الادعاء بوجود قائمة أو شراكة غير مؤكدة |

## مسار الاستخدام الفعلي

يمكن للمستخدم المصادق إصدار هوية منتج بإدخال نوع المنتج واسمه ووصفه ومصدره أو قصته، مع رابط متجر اختياري ومزود خدمة اختياري من القائمة المتاحة له. ينتج النظام مرجعًا عامًا ومسار قراءة يمكن استخدامه في NFC أو QR. وتعرض القراءة العامة معلومات الهوية المسموح بها ورابط المتجر عند توفره، دون اسم المالك أو موقعه.

يفتح مسار الاسترداد بلاغ العثور عند الحاجة، ويسجل أحداثًا محدودة تخدم الأصالة والاسترداد. لا يُستخدم النظام لتسجيل مسار GPS دائم، ولا تُعرض بيانات المالك للعامة، ولا تُنشأ شراكة مع مزود خدمة بمجرد إدخال اسمه.

## حدود الحالة الحالية

النظام لا يحتوي على بيانات King Shot أو أي مزود حقيقي تلقائيًا، ولا يعلن توافر خدمة أو شراكة قبل موافقة مستقلة. كما لا يقدم نظام دفع أو بطاقة ولاء مالية أو ضمانًا تجاريًا. وجود حقل رابط المتجر يعني إمكانية الربط التقني، لا إثبات ملكية المتجر أو اكتمال التكامل التجاري.

## التحقق

تم التحقق سابقًا من فحص النوع، الاختبارات، البناء، ومسارات العرض والاسترداد على سطح المكتب والهاتف ضمن نقاط المشروع المحفوظة. يبقى التشغيل الواقعي محتاجًا إلى إدخال مزودين ومنتجات من أصحابها، سياسة موافقة، واختبار استرداد حقيقي دون اصطناع بلاغات أو بيانات ملكية.
