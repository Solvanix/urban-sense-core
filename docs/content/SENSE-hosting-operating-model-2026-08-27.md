# نموذج تشغيل SENSE للاستضافة المجتمعية

## الفكرة المركزية

تتعامل SENSE مع الاستضافة بوصفها طبقة وصول ومشاركة، لا بوصفها حجزًا تجاريًا جاهزًا. يبدأ المسار بحاجة واضحة: جلسة عمل، اجتماع قصير، تعلم، نشاط، أو لقاء اجتماعي. بعد ذلك يربط الحاجة بمضيف يحدد قدرته، ثم ببرنامج أو شريك عندما يكون التوسع مناسبًا.

> الولاء المتبادل ليس رصيدًا ماليًا تلقائيًا؛ إنه علاقة تقدير تحتاج تعريفًا وموافقة وشراكة وتسوية قبل أي تشغيل مالي.

## الأدوار

| الدور | ما يقدمه | ما لا يُفترض تلقائيًا |
|---|---|---|
| المضيف | وصف المكان، حدود الاستضافة، نوع النشاط، السعة، الأوقات، وما إذا كان العرض مجانيًا أو اختياري المساهمة | لا يُفترض أنه متاح دائمًا، ولا يُنشر عنوانه أو اسمه دون موافقة |
| المستضاف | الغرض، المدة، العدد، احتياجات الإتاحة، واحترام المكان والوقت | لا يُضمن له حجز أو توافر قبل مراجعة المضيف |
| راعي البرنامج | دعم نطاق محدد مثل جلسة أو ورشة أو توثيق أو نشاط | لا تُسمى مساهمته تبرعًا أو أثرًا محققًا قبل التوثيق |
| SENSE team | تنظيم المسار، توضيح الحدود، بناء الأدوات، وربط الهوية والوصول | لا تمثل مضيفًا أو راعيًا لم تتم الموافقة عليه |

## الرحلة

1. **تعريف الحاجة:** يختار المستخدم نوع المهمة والمدة ومتطلبات الإتاحة دون إدخال موقع دائم أو بيانات حساسة.
2. **مطابقة أولية:** تُعرض فئة المكان أو البرنامج، لا عنوانًا دقيقًا أو وعدًا بالحجز.
3. **مراجعة المضيف:** يحدد المضيف ما يستطيع تقديمه، وشروط الاستخدام، وسياسة الخصوصية.
4. **تأكيد منفصل:** لا يصبح الموعد نافذًا إلا بعد تأكيد واضح من الجهة المختصة.
5. **تجربة وتوثيق:** يمكن إنتاج صورة للمكان، فيديو قصير، مقالة، أو حديث شارع بعد موافقات مستقلة.
6. **تقدير متبادل:** يمكن أن تُدرس بطاقة ولاء أو منفعة شريكة لاحقًا، بعد اعتماد النموذج وعدم تقديمها كقيمة مالية مفعلة.

## المحتوى المسؤول

يُوثق المضيف المكان أو النشاط بدل تصوير الأشخاص دون إذن. يُستخدم الفيديو للتحضير أو النشاط، والصورة لتفاصيل المساحة، والمقالة لشرح الحاجة والمسار، وحديث الشارع لصوت يوافق صاحبه على النشر. تُحذف أو تُطمس أي بيانات تعريفية غير لازمة، ولا يُنشر عنوان أو اسم أو وجه أو صوت قبل موافقة مناسبة.

## مساكن الخير وفرص الطلاب

يظهر هذا المسار كإطار مبادرة لا كإعلان شواغر. قبل استقبال أي طلب يجب تحديد الجهة المضيفة، معايير الحماية، نطاق المدة، آلية الإشراف، حقوق الخصوصية، ومسؤولية الإحالة. نموذج الاهتمام الأولي لا يعني قبولًا ولا تخصيص مكان، ولا يجمع بيانات شخصية غير لازمة في النسخة الحالية.

## الحالة التقنية الحالية

المنصة تحتوي صفحة استضافة عامة على `/?view=hosting`، مع أوضاع `mode=hosts` و`mode=guests` و`mode=programs`. الواجهة تعرض المبادئ والحدود ومسار اهتمام محليًا داخل المعاينة فقط، ويتيح للطالب اختيار نوع المساحة والإطار التقريبي دون اسم أو رقم أو عنوان أو موقع. لا توجد حجوزات، ولا مدفوعات، ولا بطاقات ولاء مفعلة، ولا سجل مضيفين حقيقي، ولا شواغر طلابية منشورة.

## الخطوات التالية قبل التشغيل

يحتاج التشغيل الحقيقي إلى قرار كيان قانوني، سياسة حماية وخصوصية، موافقة مضيفين، نموذج صلاحيات، مراجعة أمنية، تعريف مسؤولية الرعاية، واختبارات مع مستخدمين حقيقيين دون اصطناع تقييمات أو شهادات. بعدها فقط يمكن تحديد ما إذا كان يلزم تخزين بيانات في قاعدة البيانات أو ربط خدمة دفع أو إضافة نظام إشعارات.
