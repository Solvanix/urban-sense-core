# CRS-001 — استبانة إعادة هندسة الأعمال والتكيف مع التدويل

## ما استُخرج

يستكشف النموذج هوية الشركة واتصالها، قطاعها وخدماتها وموقعها وعلاقتها بالتراث والقيود، ثم الحجم والعملاء والأولويات والعقبات والموسمية. ويتناول أيضًا الجودة ورضا العملاء والاستدامة والشهادات والابتكار والحضور الرقمي والحجز والبوابات والمعارض والتعاون والعضويات وفعاليات التواصل. التحويل التفصيلي لكل سؤال موجود في [وثيقة الاستخراج الكامل](../../research/TOURISM-SURVEY-FULL-EXTRACTION-2026-08-22.md).

## ما أصبح قرار بناء

يصبح القطاع والخدمة والمنطقة ووصف التجربة مرشحات عرض **مضبوطة ومراجعة**، لا مجرد نصوص عامة. وتتحول ممارسات الجودة والاستدامة والشهادات والعضوية إلى ادعاءات يمكن إرفاق دليل بها ومراجعتها. أما الحجم والمبيعات والعملاء والمتابعون والأولويات والعقبات فتظل تشخيصًا خاصًا أو تستبعد، ولا تسرب إلى ملف الزائر أو إلى ترتيب للمزودين.

## المعايير والتحديات المشتقة

| المعيار أو التحدي | الأثر المباشر | حالة المتابعة |
|---|---|---|
| الموافقة وإخفاء الاتصال | لا ملف عام أو دعوة مبنية على موافقة النموذج الخارجي | يثبت في العقد الحالي جزئيًا؛ يحتاج سجل موافقة مفصل |
| ادعاء يحتاج دليلًا | لا تنشر «مستدام» أو «حاصل على شهادة» أو «تراثي» بوصفه حقيقة ذاتية | مخطط الادعاءات قائم؛ دليل التخزين والمراجعة معلقان |
| تشخيص لا تسويق | لا تحويل للمبيعات والعملاء والمتابعين إلى شارات أو ترتيب | قرار مسجل؛ يلزم اختبار عند إضافة المخطط |
| وصول وإتاحة حساسان | لا يعاد نشر العوائق؛ تظهر فقط حقائق وصول دقيقة يراجعها إنسان | معلق على قاموس الإتاحة وسياسة الإثبات |
| الحجز والروابط الخارجية | لا يوحي الرابط بتوافر فوري ولا يسحب بيانات خارجية تلقائيًا | معلق على تصميم خطوة الحجز |
| التعلم والتمكين | الأولويات والعوائق تحتاج مسارًا خاصًا لا كتالوجًا عامًا | محجوب حتى وصول المنهج السياحي |
