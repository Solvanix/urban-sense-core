# فهرس مصادر التطوير والبناء

هذا الفهرس لا يقيّم جودة الجهات أو المواد المذكورة؛ وظيفته أن يظهر **كيف استُخدم المصدر** وما الذي يمنع تجاوز حدوده. يبدأ بالسجلات التي أثرت في تجربة SENSE Experience أو مساراتها، ويستقبل مصادر جديدة وفق القالب المعتمد.

## نطاق الفهرس

لا يساوي وجود مصدر في هذا الفهرس قبولًا فنيًا أو قانونيًا أو تشغيليًا. كما لا يرفع المستودع مواد المصدر الخاصة أو الإجابات أو الوثائق المحمية. ويجب ربط كل إضافة جديدة بقرار بناء محدد أو توثيق صريح بأنها **مرجع فقط**.
