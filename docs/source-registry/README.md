# سجل مصادر التطوير والبناء

هذا المجلد هو **نقطة الضبط الوحيدة** لكل استبانة أو منهج أو مرجع تجربة أو وثيقة أدلة يُراد تحويله إلى قرار منتج داخل منظومة SENSE. لا يحل محل وثائق البحث التفصيلية في `docs/research/`، بل يربطها بقرارات بناء قابلة للتتبع، حتى يستطيع الفريق أن يجيب عن أربعة أسئلة: ما المصدر؟ ماذا يُسمح لنا أن نستخدم منه؟ ماذا استخرجنا؟ وما الذي بُني أو بقي قرارًا مفتوحًا؟

> لا يعني إدراج مصدر في السجل وجود شراكة أو إذن لاستخدام الاسم أو العلامة أو المحتوى. يظل المصدر مرجعًا تحليليًا حتى يثبت خلاف ذلك كتابيًا.

## طريقة الإضافة الإلزامية

عند ورود مصدر جديد، لا يُنسخ داخل المنتج ولا يُحوّل مباشرة إلى حقول. ينشئ المسؤول سجلًا جديدًا من القالب، ويحدد ما إذا كان المصدر عامًا أو خاصًا أو مشروط الوصول، ويفصل الاقتباس المسموح من الاستلهام التصميمي. بعدها توثق الأسئلة أو العناصر في تحليل مستقل، ثم تسجل فقط القرارات القابلة للتنفيذ في `BUILD-REGISTER.md` مع حالة واضحة: **موثق، مخطط، منفذ، متحقق، أو محجوب**.

لا تخزن في هذا المجلد إجابات المشاركين، أو كلمات المرور، أو مسودات نماذج، أو بيانات اتصال غير لازمة، أو مواد محمية غير مسموح بإعادة نشرها. يحتفظ السجل بالمراجع والوصف والقرارات لا بنسخ من بيانات الغير.

## العلاقة ليست مصدرًا وليست إذنًا ضمنيًا

المصدر العام يوثق معلومة وحدود استعمالها؛ ولا ينشئ تلقائيًا حوارًا أو شراكة أو تفويضًا. وتخضع أي علاقة مع جهة أو برنامج أو موقع لسجل العلاقات والصلاحيات الذي يميز بين `official_authorization` و`written_partner_agreement` و`consultation` و`public_source` و`unverified_claim` و`blocked`.

## الحالات المعيارية

| الحالة | معناها |
|---|---|
| `documented` | المصدر والنتيجة التحليلية موثقان، من دون التزام بناء. |
| `planned` | قرار بناء معتمد مبدئيًا ولم ينفذ. |
| `implemented` | موجود في المصدر البرمجي أو الوثائق التشغيلية. |
| `verified` | اجتاز اختبارًا أو مراجعة تثبت السلوك المقصود. |
| `blocked` | يحتاج مصدرًا أو إذنًا أو قرارًا أو بنية تشغيلية قبل التقدم. |

## قواعد الإسناد والحدود

كل سجل يلزم أن يشير إلى رابط المصدر أو وصفه الآمن، وإلى وثيقة التحليل التفصيلية، وإلى معايير البناء ذات الصلة. لا تُبنى «شهادة» أو «اعتماد» أو «تقييم» من إجابة ذاتية أو مرجع خارجي وحده. ويجب أن تبقى حدود الخصوصية، والموافقة، وفصل التطبيقات وقواعد البيانات جزءًا من معيار الإتمام لا مجرد فقرة وصفية.
