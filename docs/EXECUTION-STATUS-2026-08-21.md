# سجل التنفيذ الفعلي لمنظومة SENSE

**التاريخ:** 21 أغسطس 2026

**مصدر الحقيقة البرمجي:** `Solvanix/urban-sense-core` على الفرع `main`
**الغرض:** منع الخلط بين كود المستودع، والنسخة المعروضة مؤقتًا، والتشغيل المستقل على خادم تملكه الجهة.

> وجود صفحة مرئية على رابط لا يعني أن GitHub يشغلها، ووجود كود في GitHub لا يعني أن المنتج منشور أو مكتمل تشغيليًا. لكل مستوى وظيفة مختلفة يجب تسميتها بوضوح.

## الخلاصة التنفيذية

المستودع يحتوي على **تطبيقين فعليين قابلين للبناء**، ومخططات قواعد بيانات، واختبارات، ووثائق، وحزمة Docker لتشغيل Urban‑Sense على خادم مستقل. لا يشغّل GitHub التطبيق بنفسه؛ هو يحفظ المصدر والإصدارات وسير الجودة. النسخة الحية الموجودة حاليًا على نطاق Manus هي **بيئة عرض وتشغيل مُدارة منفصلة** نُشرت من نسخة عمل متزامنة سابقًا، وليست صفحة تُخدم مباشرة من GitHub.

## أين يوجد كل شيء الآن؟

| العنصر | موجود في GitHub المركزي | موجود في Manus الحي | ما الذي يعنيه ذلك عمليًا؟ |
|---|---|---|---|
| بوابة SENSE عند الجذر | نعم، في `apps/web/client/src/` | نعم، عند `/` | المصدر في GitHub، بينما العرض الحي يخدمه مشروع Manus حاليًا. |
| Urban‑Sense للبلاغات البلدية | نعم، في `apps/web/` | نعم، عند `/?view=urban` | تطبيق React/Express/tRPC/Drizzle حقيقي، مع واجهة وأدوار ومخطط بيانات واختبارات. |
| المستكشف ولوحة التقدم وجاهزية الدومين | نعم، ضمن `apps/web/client/src/pages/` | نعم، في `/?view=explore` و`/?view=progress` و`/?view=domain` | واجهات تعريف وتوجيه صادقة؛ لا تشغل تلقائيًا تجارة أو سياحة أو تمويلًا. |
| `INDEX.html` | نعم، في جذر المستودع | نعم، نسخة عامة مستقلة عند `/INDEX.html` | الملف في GitHub هو **مصدر فهرس**؛ الرابط الحي حاليًا يأتي من Manus لا من GitHub Pages. |
| SENSE Experience | نعم، في `apps/sense-experience/` | لا، ليس منشورًا كموقع إنتاج مستقل | نواة تطبيق منفصلة وكود واختبارات، لكن استقبال بيانات مزودين حقيقيين مقيد حتى استكمال النشر والهوية والمراجعة. |
| قاعدة بيانات Urban‑Sense | المخطط والكود فقط | قاعدة بيانات بيئة Manus المُدارة | البيانات التشغيلية لا تُرفع إلى GitHub ولا تُنقل تلقائيًا إلى الخادم المستقل. |
| حزمة التشغيل المستقل | نعم، في `apps/web/Dockerfile` و`compose.yaml` و`ops/` | لا تُشغّلها بيئة Manus الحالية | جاهزة ليشغّلها مطور على خادم يملكه الفريق؛ لم تُجرّب بعد على مضيف Docker يملكه الفريق. |
| الدخول والهوية | كود Manus المتوافق ومسار OIDC اختياري | OAuth المُدار في بيئة Manus | تشغيل مستقل يحتاج تهيئة مزود OIDC تملكه الجهة؛ لا توجد كلمات مرور مشتركة أو أسرار داخل Git. |

## ما الذي ينفّذ فعليًا في المصدر المركزي؟

### 1. Urban‑Sense

تطبيق بلاغات بلدية وليس صفحة تسويقية. يحتوي على واجهة عربية RTL، مخطط MySQL/Drizzle للهوية والبلديات والبلاغات والمراجعة والإسناد والأدلة وسجل التدقيق، وإجراءات خادم تحكم الصلاحيات وسير دورة البلاغ. أوامر التحقق المصدّرة معه هي:

```bash
pnpm check
pnpm test
pnpm build
```

وفي الإصدارات التي سبقت هذا السجل نجحت 33 حالة اختبار في المصدر المركزي بعد إضافة اختبار حزمة التشغيل.

### 2. SENSE Experience

هذا تطبيق مستقل من حيث الكود والبيانات عن Urban‑Sense، وله واجهة وAPI ومخطط قاعدة بيانات مستقلان. لكنه **ليس خدمة منشورة لاستقبال مزودي خدمات فعليين**: ما زالت الهوية المستقلة، المراجع البشري الفعلي، سياسات الاحتفاظ، والنشر المنفصل شروطًا قبل إدخال بيانات حقيقية.

### 3. حزمة الخادم المستقل

الملفات التالية موجودة في GitHub المركزي وهي تنفيذ تشغيلي، لا نص حواري:

| الملف | وظيفته |
|---|---|
| `apps/web/Dockerfile` | يبني الواجهة والخادم من المصدر نفسه داخل صورة Node 22. |
| `apps/web/compose.yaml` | يعرّف تطبيق Urban‑Sense وقاعدة MySQL محلية وفحصي الصحة. |
| `apps/web/.env.runtime.example` | قالب إعداد بلا أسرار؛ تبقى القيم الفعلية خارج Git. |
| `apps/web/ops/bootstrap-server.sh` | عقد إقلاع لعرض جديد: يجهز مخطط قاعدة فارغة ثم يشغل التطبيق. |
| `apps/web/ops/DEPLOYMENT.md` | تعليمات عربية تفصل العرض المحلي عن الإنتاج المستقل. |
| `apps/web/server/deploymentBundle.test.ts` | اختبار يثبت وجود فحص الصحة وعزل القيم التشغيلية عن إعداد Compose المصدّر. |

على خادم يملك Docker وملف إعداد مكتمل، يبدأ عرض جديد عبر:

```bash
cd apps/web
cp .env.runtime.example .env.runtime
# عدّل القيم البديلة محليًا، ولا ترفع الملف إلى Git
bash ops/bootstrap-server.sh
```

هذا يثبت قابلية النقل التقنية للتطبيق وبيئة عرض جديدة؛ **لا يساوي تشغيل إنتاج نهائيًا** حتى تملك الجهة قاعدة بيانات مُدارة، ودومينًا، وTLS، وOIDC، وتخزينًا، ونسخًا احتياطية.

## ما الذي يبقى داخل Manus فقط؟

يبقى داخل مشروع Manus الحي ما يلي:

| الفئة | سبب بقائها خارج GitHub |
|---|---|
| نطاق العرض الحالي `urbansense-dzfbcdz5.manus.space` | استضافة مُدارة من Manus، وليست موردًا يملكه المستودع أو GitHub. |
| جلسة الدخول والبيانات المرتبطة ببيئة Manus | أسرار وإعدادات منصة وتشغيل وقاعدة بيانات لا يجب نقلها إلى Git. |
| وثائق مذكرات التسويق وفحوص الواجهات والمواد المرحلية | مخرجات جلسات وتشغيل؛ لا تصبح جزءًا من المصدر المركزي إلا إذا قُرر أنها وثائق منتج دائمة ومراجعة. |
| نسخة عمل الواجهة الحية | نسخة نشر قد تتأخر أو تختلف شكليًا عن المصدر المركزي؛ لا يُعامل اختلافها كبديل للمصدر. |

## لماذا لا يقدّم GitHub رابط التطبيق نفسه؟

GitHub يحفظ الكود ويشغّل فحوص الجودة. لا يقدّم خادم Express دائمًا ولا MySQL ولا جلسات دخول ولا تخزين ملفات للتطبيق. GitHub Pages، حتى عند تفعيله، مناسب لفهرس HTML ثابت فقط؛ لا يشغّل Urban‑Sense ولا SENSE Experience كمنصة بيانات. لذلك لا ينبغي استخدامه كبديل لخادم التطبيق.

## فجوات لا يجوز تسميتها «منجزة»

| الفجوة | أثرها | الشرط الذي يغلقها |
|---|---|---|
| تجربة Docker على خادم يملكه الفريق | الحزمة اجتازت الفحوص الثابتة، لكن لا يوجد إثبات تشغيل حاوية على مضيف فريق بعد | اختيار خادم، إنشاء `.env.runtime` محلي، وتشغيل الإقلاع وتسجيل فحص الصحة. |
| OIDC مملوك للجهة | لا يمكن اعتبار تسجيل الدخول مستقلًا بمجرد وجود الكود | إنشاء عميل OIDC، حفظ أسراره خارج Git، وتعيين `AUTH_MODE=oidc`. |
| قاعدة إنتاج مستقلة | لا تنتقل البيانات أو النسخ الاحتياطية من Manus تلقائيًا | إنشاء MySQL مُدار، سياسة نسخ احتياطي، وخطة ترحيل مراجعة. |
| نشر SENSE Experience | لا يقبل مزودين حقيقيين بعد | خدمة وقاعدة وهوية ومراجع مستقل وسياسة احتفاظ وموافقة جاهزية مكتوبة. |
| التجارة والمحاسبة وقياس الأثر الشامل | ليست خدمات حية رغم ظهورها كمسارات مقترحة | متطلبات تجارية حقيقية، مزودون معتمدون، سياسات ودفع ومؤشرات بيانات فعلية. |

## قرار الإطلاق التالي

المسار التنفيذي وليس الحواري هو: **اختيار خادم تملكه الجهة أولًا، ثم تشغيل حزمة Docker عليه لبيئة عرض مستقلة، ثم ربط OIDC وقاعدة بيانات وإعدادات تشغيل حقيقية خارج Git، وبعد التحقق نقل Urban‑Sense إليه.** بعد ذلك فقط يصبح رابط الخادم هو الرابط الرسمي بدل رابط Manus.

GitHub Pages يبقى اختياريًا لفهرس ثابت عام، ولا يدخل في تشغيل التطبيق أو حماية بياناته.
