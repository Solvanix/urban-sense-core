# قرار توحيد المشروع المرجعي مع منظومة SENSE

**المشروع المرجعي:** [راب الإندكي](https://manus.im/share/93EGZ0Q9ZwezIwcIjno79R)
**النتيجة:** ليس مشروعًا منفصلًا عن SENSE؛ نفذ تعديلًا مباشرًا في المصدر المركزي نفسه على الفرع `main` بالالتزام `b0bf140` تحت عنوان `Add market pulse features to public index`.

## ما الذي نفذه المشروع المرجعي؟

أضاف المشروع المرجعي وحدة **«نبض السوق»** إلى كل من `INDEX.html` و`public-index/index.html`. تضم الوحدة سعرًا مرجعيًا للدولار مقابل الشيكل يجلبه المتصفح من مصدر عام عند التوفر، وحاسبة تحويل، ومقارنة قنوات أولية، وتذكيرًا سعريًا محفوظًا محليًا في متصفح الزائر.

## قرار التوحيد

| المسار | القرار الموحد | السبب |
|---|---|---|
| `public-index/index.html` | يبقى **الفهرس العام** المنشور عبر GitHub Pages | هو مدخل الزوار، ويربطهم بالمسارات الحية الصحيحة |
| `INDEX.html` | يبقى نظيرًا مرئيًا في جذر المصدر | يسهل مراجعة الفهرس محليًا ومن GitHub |
| `apps/web/client/src/pages/SensePortal.tsx` | يبقى **البوابة التفاعلية** للمنظومة | يشرح الأدوار والحدود والمنتجات المستقلة، ولا يتحول إلى متجر أو خدمة مالية |
| `apps/web/` | يبقى تطبيق Urban‑Sense التشغيلي | مسؤول عن البلاغات البلدية فقط، وليس عن نبض السوق أو مزودي السياحة |
| `apps/sense-experience/` | يبقى مسارًا مستقلاً للمزودين عند إطلاقه | لا يشارك Urban‑Sense البيانات أو الهوية أو الصلاحيات |

> النتيجة العملية: هناك **منظومة واحدة ومصدر واحد**، لكن ليست قاعدة بيانات واحدة أو حسابًا موحدًا أو تطبيقًا واحدًا يخلط كل الخدمات.

## ما يبقى من ميزة نبض السوق وما لا يجوز ادعاؤه

| المكوّن | حالته الصحيحة |
|---|---|
| السعر المرجعي العام الذي يجلبه المتصفح | معلومة عرض أولية من مصدر عام؛ يجب إظهار وقت التحديث والمصدر عند العرض |
| الحاسبة | أداة حساب تقريبية تعتمد السعر المختار؛ لا تنفذ تحويلًا أو حجزًا أو دفعًا |
| التذكير السعري | محفوظ محليًا على جهاز الزائر فقط؛ ليس تنبيهًا خادميًا ولا إشعارًا مضمونًا |
| قيم المقارنة الثابتة للقنوات | نموذج واجهة أولي، وليست أسعار بنك أو صرافة موثقة أو عرضًا تنفيذياً |
| عبارات مثل «الأفضل حاليًا» | لا ينبغي معاملتها كتوصية شراء/بيع أو تعميمها على بنك أو صرافة دون مصدر مؤرخ |

## ما الذي توحد فعلًا في هذه الجلسة؟

1. أصبح المستودع المركزي عامًا، وأصبح `public-index/index.html` منشورًا عبر GitHub Pages.
2. صُححت روابط الفهرس لكي تقود من GitHub Pages إلى بوابة SENSE وUrban‑Sense الحيين، لا إلى مسارات لا يستطيع الموقع الثابت تشغيلها.
3. أضيف اختبار يمنع عودة الروابط النسبية المكسورة في الفهرس العام، ونجحت فحوص Urban‑Sense: فحص النوع والبناء و34 اختبارًا.
4. سُجلت خريطة وصول موحدة للزوار وأصحاب المصلحة والبلديات والمدراء والمزودين والإتاحة في `ACCESS-STATUS-2026-08-21.md`.

## التركيز التنفيذي التالي

لا نفتح مشروعًا جديدًا لنفس الفكرة. التركيز ينقسم إلى خطين فقط:

1. **تثبيت التشغيل:** نقل Urban‑Sense من بيئة العرض إلى خادم تملكه الجهة عبر حزمة Docker وOIDC وقاعدة بيانات مستقلة.
2. **تهذيب نبض السوق:** قبل تقديمه كميزة عامة يعتمد عليها، نستبدل المقارنات الثابتة بمصادر محددة ومؤرخة، ونفصل السعر المرجعي عن أسعار البنوك والصرافة، ونبقيه أداة معلومات لا توصية أو خدمة تداول.

لا يبدأ المتجر أو المدفوعات أو تسجيل مزودي SENSE Experience أو خدمات إتاحة متخصصة قبل متطلبات كل مسار وقراره التشغيلي المستقل.
