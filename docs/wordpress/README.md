## ترتيب التنفيذ

يبدأ العمل بعينة قصة واحدة تجمع نصًا وصوتًا وصورًا وإنفوغرافًا، ثم تُحفظ كمسودة WordPress. بعد اختبارها مع المستخدمين، تُضاف أنواع الأخبار وملفات الأماكن والمقابلات، ثم تُربط بالعقود العامة في `urban-sense-core`.

## مبدأ النشر

WordPress هو طبقة المحتوى العام. GitHub هو مصدر الحقيقة للكود والقرارات والعقود. لا تُعرض خدمة على أنها جاهزة ما لم تكن مبنية ومراجعة وقابلة للتشغيل.

## مبدأ التصميم والتحرير

التصميم المقترح هادئ ومقروء بالعربية: عنوان واحد واضح، عناوين فرعية قصيرة، فقرات متوسطة الطول، صور ذات تسميات، واقتباس واحد يؤدي وظيفة سردية. يجب إزالة العناصر الافتراضية غير المرتبطة بالمشروع مثل بيانات الاتصال التجريبية، والتعامل بصريًا وتحريريًا مع الفصل بين القصة الدرامية والتقرير القائم على الأدلة والوسائط المولدة.

لا تُنشر صورة مولدة أو شخصية خيالية على أنها شهادة ميدانية. ولا تُرفع المسودة إلى الحالة العامة قبل مراجعة المصادر، وموافقات التصوير والتسجيل، واستبدال الصور التوضيحية بصور ميدانية مرخصة عند توفرها.
