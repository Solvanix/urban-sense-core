# نظام المحتوى التحريري لمنظومة SENSE وWordPress

## الغرض

يحوّل هذا النظام WordPress إلى طبقة تحرير ونشر تحفظ قصص المكان والناس والمشروعات، مع إبقاء `urban-sense-core` مصدر الحقيقة للكود والبيانات والقرارات. لا يقدم WordPress خدمة غير مبنية، ولا يحول التصور إلى وعد تجاري أو تقني.

## الفكرة التحريرية

> نحكي المكان من أصوات الناس، ونحوّل ما نتعلمه إلى معرفة عامة قابلة للتحقق.

المادة الجيدة ليست إعلانًا للمنصة ولا إعادة صياغة لوصف تقني. إنها قصة أو تقرير يجيب عن سؤال حقيقي، ويضع الإنسان والمكان والسياق والدليل في مركزه.

## معايير مشروع التخرج

تُنتج المادة الأساسية في نطاق 900–1200 كلمة، بعنوان رئيسي وفرعي واضحين وغير مكررين، ومقدمة إبداعية قصصية أو وصفية أو تساؤلية أو تقريرية. وتُرفق بالمكونات المطلوبة في التكليف الأكاديمي:

1. فيديو توضيحي أو تحليلي مدته 1–2 دقيقة لا يكرر المقال كاملًا.
2. تسجيل صوتي مدته 1–3 دقائق للمتحدث أو صاحب التجربة.
3. فقرة أو فيديو يشرح الحل أو التقرير من زاوية المتضررين أو المعنيين وسياق القصة.
4. قصة مصورة من 5–7 صور، ولكل صورة تعليق يضيف معلومة أو إحساسًا ولا يكرر ما يظهر بصريًا.
5. بوستر أو إنفوغراف داخل المادة.

هذه العناصر ليست زينة منفصلة؛ لكل عنصر وظيفة سردية مختلفة. المقال يشرح، والفيديو يوضح أو يحلل، والصوت ينقل الحضور الإنساني، والصور تحفظ المشهد، والإنفوغراف يختصر العلاقة أو البيانات.

## أنواع المواد

### القصة الميدانية

تبدأ بمشهد أو صوت أو تفصيل مكاني، ثم تتسع إلى سؤال أو مشكلة، وتضم شخصًا أو أكثر، وسياقًا، ودليلًا، ونهاية تترك القارئ أمام معنى أو خطوة تالية.

### الخبر المحلي الموثق

يجيب عن ماذا وأين ومتى ومن المصدر، ويفصل بوضوح بين المعلومة المؤكدة وما يحتاج متابعة. لا تستخدم صيغة عاجلة إذا لم توجد قيمة زمنية حقيقية.

### ملف المكان

يوثق ذاكرة المكان وتاريخه وعلاقته بالناس، ويضيف الموقع والخريطة والوصول والمصادر وتاريخ آخر تحديث. لا يصف المكان كوجهة سياحية فقط.

### المقابلة

تحفظ صوت الشخص وسياقه وموافقته، وتقدم أسئلة وأجوبة محررة دون تشويه المعنى. يمكن تحويلها إلى قصة أو مقاطع صوتية، لكن لا تنسب رأيًا لم يقله صاحبه.

### قصة المنتج المحلي

تشرح الصانع والحرفة والمنطقة والقيمة الثقافية، وتذكر حالة البيع أو التواصل فقط إذا كانت معلومة ومصرحًا بها. لا تنشئ مخزونًا أو سعرًا أو توفرًا من عندك.

### قصة المشروع التقني

تشرح المشكلة والمستخدم والحل والحالة الحالية والدليل والرابط إلى المستودع، وتضع شارة صريحة: مبني، قيد التجربة، قيد البحث، أو غير مبني بعد.

### تقرير التحقق

يفصل الادعاء عن الدليل، ويسجل التعارضات وحدود المعرفة والمراجع والمحرر وتاريخ المراجعة.

## قاعدة الحقيقة والحماية

لا تُنشر مادة عن شخص أو صورة يمكن التعرف إليه أو تسجيل صوتي أو شهادة حساسة بلا موافقة مناسبة. لا تجمع أو تكشف بيانات إعاقة أو صحة أو هوية حساسة إلا لسبب واضح وبموافقة صريحة. الدعم الصوتي والإتاحة جزء من جودة المنتج للجميع، وليس تصنيفًا للمستخدم.

## سير العمل

1. جمع المادة: نص، تسجيل، صورة، فيديو، رابط أو مقابلة.
2. بطاقة المادة: النوع، المكان، التاريخ، الأشخاص، السؤال، المصدر، حالة الموافقة.
3. المعالجة: تفريغ الصوت، ترتيب الملاحظات، اقتراح عنوان، واستخراج الكيانات.
4. الكتابة: إعداد المسودة وفق النوع والطول والجمهور.
5. التحقق: مراجعة الادعاءات والمصادر والخصوصية.
6. الوصول: عنوان منطقي، عناوين فرعية، نص بديل، وصف للوسائط، وتباين مناسب.
7. المراجعة الصوتية: يقرأ المساعد ملخصًا وما ينقص المادة.
8. WordPress: حفظ كمسودة أولًا، ثم مراجعة بشرية، ثم نشر.
9. الأرشفة: حفظ المصدر والنسخة النهائية وتاريخ التحديث.

## مبدأ المساعد

المساعد لا يستبدل الصحفي أو صاحب التجربة. يسأل عن النواقص، يقترح ولا يختلق، ويحوّل المادة إلى مسودة قابلة للمراجعة. لا ينشر ولا يحذف تلقائيًا في النسخة الأولى.

## نبرة الكتابة

لغة عربية واضحة، حسية حين تخدم القصة، دقيقة حين تعرض خبرًا أو رقمًا، وبلا مبالغة أو شعارات عامة. العنوان يخلق فضولًا صادقًا؛ والمقدمة تضع القارئ في المكان بدل أن تبدأ بتعريف مؤسسي بارد.

## حالات النشر

- **قيد الجمع:** مادة أولية لم تكتمل.
- **قيد التحرير:** مسودة تعمل عليها المجموعة.
- **قيد التحقق:** المحتوى مكتوب وتُراجع أدلته.
- **مراجَع:** اجتاز مراجعة تحريرية ومراجعة وصول.
- **منشور:** ظهر للعموم.
- **محدّث:** أضيفت معلومات بعد النشر.
- **مؤرشف:** لم يعد صالحًا للاستخدام النشط مع بقاء السجل.

## مقياس الجودة قبل النشر

هل للمادة سؤال واضح؟ هل يظهر مكان محدد وصوت إنساني؟ هل يمكن للقارئ معرفة ما هو مؤكد وما هو غير مكتمل؟ هل الوسائط تؤدي وظيفة مختلفة؟ هل حُفظت الموافقة والخصوصية؟ هل يستطيع قارئ شاشة فهم البنية؟ وهل يمكن تحويل المادة إلى نسخة صوتية أو اجتماعية دون فقدان معناها؟

## العلاقة مع المستودع

يرتبط كل مشروع تقني أو ادعاء عن منتج أو خدمة بملف أو قرار أو رابط داخل `urban-sense-core`. أما WordPress فيحفظ المادة المحررة ومصادرها العامة، ولا ينسخ أسرار النظام أو بياناته الخاصة.

## قرار أولي

نبدأ بمسار واحد قابل للقياس: **قصة ميدانية كاملة تُحفظ في WordPress كمسودة، مع ملف صوتي وصورة ووصف بديل وإنفوغراف، ثم تُراجع مع المستخدم قبل النشر.**

هذا المسار يختبر التحرير، الإتاحة، المساعد، والربط دون فتح نطاق المتجر أو الدفع أو الحجوزات قبل بنائها فعليًا.
