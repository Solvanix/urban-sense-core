# نموذج محتوى WordPress لمشروع SENSE

## قاعدة عامة

يُنشأ كل عنصر في WordPress كمسودة أولًا، ويحتوي على حالة تحرير ومصدر وموافقة وتاريخ مراجعة. لا تُستخدم الحقول لتعبئة الواجهة بمعلومات افتراضية.

## الحقول المشتركة

| الحقل | النوع | إلزامي | الغرض |
|---|---|---:|---|
| العنوان | نص | نعم | عنوان واضح غير مكرر |
| العنوان الفرعي | نص | نعم | توضيح إضافي لا يعيد العنوان |
| النوع | اختيار | نعم | قصة، خبر، مكان، مقابلة، منتج، مشروع، تحقق، مبادرة |
| الملخص | نص منسق | نعم | 2–3 جمل قابلة للقراءة الصوتية |
| المكان | نص/معرّف | نعم عند الصلة | ربط المادة بالبلدة أو الموقع |
| تاريخ الحدث | تاريخ | عند الصلة | فصل تاريخ الحدث عن تاريخ النشر |
| الكاتب/المحرر | مستخدم | نعم | المسؤولية التحريرية |
| حالة التحقق | اختيار | نعم | غير مراجع، قيد التحقق، مراجع، محدث |
| المصادر | روابط/ملاحظات | نعم للأخبار والادعاءات | حفظ الدليل |
| الموافقة | سجل | عند الأشخاص | نوع الموافقة وتاريخها ونطاقها |
| النص البديل | نص | للصور | وصف وظيفة الصورة ومحتواها |
| حالة البناء | اختيار | للمشروعات | مبني، قيد التجربة، قيد البحث، غير مبني بعد |
| تاريخ آخر مراجعة | تاريخ | نعم | منع تقادم المعلومات |

## نوع قصة ميدانية

- السؤال المركزي.
- المشهد الافتتاحي.
- الشخصيات أو أصحاب التجربة.
- الاقتباسات المؤكدة.
- السياق التاريخي أو الاجتماعي.
- الأدلة والمصادر.
- ما الذي تغير أو ما زال عالقًا؟
- الخطوة التالية أو السؤال المفتوح.
- 5–7 صور وتعليقاتها.
- تسجيل صوتي 1–3 دقائق.
- فيديو تحليلي 1–2 دقيقة.
- بوستر أو إنفوغراف.

## نوع خبر محلي

- الحدث.
- المنطقة.
- وقت الحدث.
- المصدر الأولي.
- مصدر ثانٍ عند الحاجة.
- درجة التحقق.
- التحديثات.
- ما لا نعرفه.
- صورة أو مرفق.

## نوع ملف مكان

- الاسم الحالي والأسماء السابقة إن توفرت بمصدر.
- قصة الاسم.
- الذاكرة المحلية.
- الموقع والخريطة.
- الوصول والقيود.
- ساعات الزيارة إن كانت مؤكدة.
- الصور.
- المصادر.
- آخر تحديث.

## نوع مشروع تقني

- المشكلة.
- المستخدمون.
- الحل.
- الحالة الحالية.
- المستودع أو الدليل.
- ما بُني فعلًا.
- ما لم يُبنَ بعد.
- صاحب التشغيل.
- المخاطر والخصوصية.
- الخطوة التالية.

## أوامر المساعد الأولية

- «حوّل هذا التسجيل إلى قصة ميدانية.»
- «استخرج من الملف عنوانًا ومقدمة ومصادر محتملة.»
- «أنشئ مسودة خبر محلي ولا تنشرها.»
- «اقرأ لي المسودة وأخبرني بما ينقصها.»
- «ارفع الصورة وأضف وصفًا بديلًا دقيقًا.»
- «حوّل المقال إلى ملخص صوتي ومنشور اجتماعي.»
- «ضع علامة قيد التحقق على هذه الفقرة.»
- «اعرض لي كل الادعاءات التي لا تملك مصدرًا.»

## حواجز الأمان

- إنشاء المسودة مسموح.
- رفع الوسائط مسموح بعد فحص النوع والحجم.
- النشر يحتاج تأكيدًا صريحًا.
- الحذف والعمليات الجماعية غير مفعلة في النسخة الأولى.
- لا يُخزن المستخدم كلمة المرور الأساسية داخل المساعد.
- تستخدم كلمة مرور تطبيق منفصلة قابلة للإلغاء عند ربط WordPress.
