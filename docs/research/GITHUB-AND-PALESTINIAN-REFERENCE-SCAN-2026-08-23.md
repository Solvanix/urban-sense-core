# مسح مراجع GitHub والمصادر الفلسطينية العلنية — 23 أغسطس 2026

**الحالة:** مسح مرجعي أولي؛ لا يعني تبني كود، ولا وجود شراكة، ولا نقل بيانات أو تشغيل نماذج على بيانات SENSE.

## 1. المنهج والحدود

جُمعت هذه المراجع لتقييم أربع طبقات مستقلة: بلاغات وخدمات بلدية، مساعدات ذكاء اصطناعي مقيدة للمستخدمين والمحللين المخولين، سلسلة تصميم إلى ملف آلة للتصنيع الرقمي، والتعلم القصصي المتفرع. لا يسمح أي مرجع بإزالة فصل بيانات Urban-Sense وSENSE Experience، أو بمنح نموذج لغوي صلاحية كتابة مباشرة في قاعدة بيانات أو تشغيل آلة.

### قاعدة الأمان المقترحة للمحلل المخوّل

1. لا يتصل النموذج بقاعدة Urban-Sense الإنتاجية بحساب مالك أو مسؤول كامل.
2. لكل دور قاعدة بيانات أو Views قراءة فقط تحدد البلدية والنطاق والحقول المسموحة قبل أن يرى النموذج أي مخطط.
3. يولد النموذج استعلامًا؛ يراجعه محلل في واجهة معاينة؛ يرفض الخادم غير `SELECT` أو أي جدول/عمود خارج قائمة مسموحة.
4. تسجل هوية المستخدم، السؤال، الاستعلام النهائي، نطاق البيانات، وقت التنفيذ، وعدد الصفوف، من دون نسخ نصوص حساسة في السجل.
5. تقدم إجابات مجمعة أو منزوعة الهوية للوحة الإدارة؛ لا تمكين بحث حر في بيانات المواطنين.

## 4. سلسلة التصميم إلى التصنيع الرقمي

| الطبقة | المرجع | الدور الصحيح |
|---|---|---|
| تصميم بارامتري | `FreeCAD/FreeCAD` | تحويل وصف متفق عليه إلى أبعاد ونموذج قابل للمراجعة وتصدير؛ لا ملف آلة مباشر من محادثة |
| مسارات ثنائية الأبعاد للّيزر/CNC | `sameer/svg2gcode` | تحويل SVG مُراجع إلى G-code مع سرعة وتفاوت وأوامر تشغيل/إيقاف محددة للآلة |
| CAM ومتعدد الآلات | `GridSpace/grid-apps` / Kiri:Moto | معاينة وتقطيع وإنتاج G-code للطباعة ثلاثية الأبعاد وCNC والليزر في المتصفح |
| طباعة ثلاثية الأبعاد | `OrcaSlicer/OrcaSlicer` | تقطيع STL/نماذج ثلاثية الأبعاد، اختيار ملف تعريف الطابعة، معاينة الطبقات ودعمها قبل التصدير |

### بوابة سلامة إلزامية قبل أي تشغيل آلة

`محادثة → مواصفات منظمة → تصميم بارامتري/SVG أو STL → معاينة هندسية → اختيار آلة ومادة وملف تعريف معتمد → محاكاة مسار → مراجعة مشغل → تنزيل G-code → تشغيل يدوي من المشغل`.

لا يرسل SENSE ملف G-code إلى طابعة أو CNC أو ليزر ولا يسمح بتشغيل تلقائي في أي مرحلة أولى. يجب أن يحمل كل ملف رمز تشغيل وإصدار التصميم وملف الآلة والمادة والمشغل الذي وافق عليه.

### تصميم SENSE المقترح

لا يحول الدرس إلى «قصة مولدة بالكامل». ينشئ المؤلف خريطة حالات معتمدة: مشهد، قرار، سبب صحة/خطأ، أثر قصصي، ومعلومة مرجعية. يمكن للنموذج فقط أن يعيد صياغة الحوار أو يختار تفاصيل ملائمة من مكتبة معتمدة، ولا يبتكر قانونًا أو تعليمات سلامة أو شهادة. المسار الخاطئ يبين أثر القرار ويتيح الإصلاح؛ والمسار الصحيح يفتح تحديًا أعلى أو دورًا جديدًا.

## 6. ما تحقق عن فلسطين والشرطة/المرور

المصدر العلني `moodle.police.sec.ps` يثبت وجود منصة تعليم إلكتروني للشرطة الفلسطينية تعرض مقررات منها الشرطة المجتمعية، إدارة الأزمات، ومدخل «الأمن الشخصي المعلوماتي والذكاء الاصطناعي». كما تظهر مصادر علنية أن شرطة المرور تنفذ توعية مدرسية وأنشطة في أسبوع المرور العربي.

وتؤكد صفحة إدارة المرور الرسمية أن العمل يشمل برامج توعية مرورية ونشرات إعلامية، وأن الإدارة تستخدم تقنيات مثل الرادار وفحص الكحول والربط الإلكتروني مع القضاء ووزارة المواصلات للغرامات والمخالفات. كما وثقت مصادر WAFA وEUPOL COPPS تدريبًا على السلامة المرورية والتحقيق في الحوادث وتصميم برامج توعوية للأطفال والسائقين الشباب. هذه أدلة على تعليم وتشغيل وتقنية مرور، وليست إثباتًا لمنصة قصص متفرعة أو مساعد ذكاء اصطناعي عام للمواطنين.

لم يثبت في المسح الحالي وجود منتج فلسطيني منشور للشرطة أو المرور يعتمد تحديدًا قصة متفرعة مولدة بالذكاء الاصطناعي أو محاكاة تفاعلية للإجابات. وُجدت إشارات إلى محاكاة واقعية لمسرح جريمة وشواهد لتوعية مرورية تفاعلية، لكنها ليست وثائق هندسية تسمح بنسبة نموذج رقمي محدد أو إعادة استخدامه. يلزم رابط أو اسم المبادرة الذي يقصده المالك للتحقق منه بدقة.
