# تنفيذ WordPress v1 — SENSE مع Blocksy

## القرار

القالب المعتمد: **Blocksy Free**.

التحرير: **Gutenberg / محرر WordPress الأصلي**.

الهدف: تحويل الموقع إلى نسخة أولى من منصة سياحية ومتجر إلكتروني وطني، مع إنجاز متطلبات مشروع الدبلوم داخل قسم القصة الرئيسية.

## نص الصفحة الرئيسية

### العنوان الرئيسي

**المكان الذي مررت بجانبه… يحمل قصة تنتظرك.**

### الوصف

اكتشف وجهات فلسطين من خلال قصص أماكنها، وتجارب أهلها، ومنتجات حرفييها. ابدأ من العيزرية، وخطط رحلتك بطريقة أقرب إلى المكان وأكثر احترامًا لقصته.

### الأزرار

- ابدأ اكتشافك
- خطط جولتك
- تسوّق من المكان

### بطاقات الاستخدام

1. **اكتشف وجهة** — معالم، قصص، صور، وخرائط.
2. **خطط جولتك** — مسارات حسب الوقت والاهتمام وإمكانية الوصول.
3. **عش تجربة محلية** — حرف، طعام، ورش، وأصوات من المكان.
4. **اشترِ بقصة** — منتجات محلية مرتبطة بحرفي ووجهة.

### قسم العيزرية

**العيزرية: لا تمرّ فقط. اكتشف.**

قد لا يكون ما تبحث عنه بعيدًا. أحيانًا تحتاج فقط إلى من يدلّك أين تنظر.

### قسم المتجر

**من المكان إلى يدك.**

منتجات محلية تحمل أثر الحرفة وقصة المنطقة. كل منتج يجب أن يوضح مصدره، وصانعه، وحالة توفره، وآخر تاريخ لتحديث معلوماته.

## المحتوى الأكاديمي

### القصة الرئيسية

العنوان: **الكنز الذي مررنا بجانبه**.

الفكرة: قصة إنسانية عن معلم أو تفصيل تاريخي في العيزرية يمر به الزائر دون أن يعرف قصته، ثم يتحول المكان من مبنى أو طريق إلى تجربة قابلة للاكتشاف.

### التقرير الرئيسي

العنوان: **لماذا لا تتحول المعالم المحلية إلى تجارب سياحية؟**

الفكرة: تقرير موثق عن فجوة المعلومات والمسارات والوصول والحرفيين، مع عرض SENSE كحل مقترح لا كإعلان تجاري.

### الوسائط المطلوبة

- نص رئيسي 900–1200 كلمة.
- فيديو 1–2 دقيقة لا يكرر النص.
- تسجيل صوتي 1–3 دقائق.
- قصة مصورة من 5–7 صور.
- بوستر أو إنفوغراف.
- مصادر وحقوق وموافقات.

## قاعدة النشر

لا ينشر أي سعر أو حجز أو وقت عمل أو معلومة تاريخية حساسة دون مصدر ومالك وتاريخ تحديث. لا ينشر الذكاء الاصطناعي تلقائيًا. يحفظ كل محتوى كمسودة قبل المراجعة البشرية.

## خطة التنفيذ داخل WordPress

1. إنشاء الموقع أو الدخول إلى الموقع الحالي.
2. تثبيت Blocksy Free وتفعيله.
3. ضبط اللغة العربية وRTL.
4. ضبط الألوان والخطوط والرأس والتذييل.
5. إنشاء الصفحات الأساسية.
6. إدخال نص الصفحة الرئيسية.
7. حفظ القصة والتقرير كمسودتين.
8. إضافة الوسائط والحقوق والنصوص البديلة.
9. اختبار الهاتف ولوحة المفاتيح وقارئ الشاشة.
10. نشر النسخة الأولى بعد المراجعة.

## حدود الإصدار الأول

لا نفعّل الدفع أو التوصيل أو الحجوزات أو المزامنة الآلية مع GitHub قبل وجود بيانات تشغيلية وموافقة وسياسة واضحة. GitHub يحفظ الكود والوثائق والمصادر، وWordPress يحفظ المحتوى المحرر والنشر.
