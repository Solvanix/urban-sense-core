# SENSE WordPress Package

هذه الحزمة تحفظ خطة تنفيذ موقع SENSE على WordPress باستخدام قالب Blocksy، مع المحتوى التحريري والهوية البصرية وبنية الصفحات.

## المحتويات

- `SENSE-WordPress-content-brand-plan.md`: خطة المحتوى والهوية.
- `SENSE-WordPress-implementation-v1.md`: مواصفات التنفيذ.
- `SENSE-WordPress-content-pack-v1.md`: نصوص الصفحة الرئيسية وبطاقات المحتوى.
- `SENSE-editorial-academic-pack.md`: القصة الرئيسية والتقرير السياحي والوسائط المطلوبة لمشروع الدبلوم.
- `wordpress-sense-site-structure.json`: شجرة الصفحات والروابط وحالات النشر.
- `sense-brand-tokens.json`: قيم الألوان والخطوط والهوية.
- `WORDPRESS-HANDOFF-v1.md`: خطوات الإدخال العملية في WordPress وضبط Blocksy والفحص قبل النشر.
- `wordpress-content-map.csv`: خريطة الصفحات والمقالات والآباء والتصنيفات وحالات النشر.
- `media-manifest.csv`: سجل الصور والأوصاف البديلة والحقوق وحالة كل أصل.

## حالة التنفيذ

هذه الحزمة مصدر محفوظ للخطط والمحتوى والأصول. لم تُرفع أسرار WordPress أو GitHub، ولم تُفعّل مزامنة تلقائية أو دفع أو حجوزات. الإصدار الحالي جاهز للإدخال اليدوي المنضبط في WordPress.

## قاعدة WordPress/GitHub

GitHub يحفظ المصدر والوثائق والأصول. WordPress يحفظ النسخة المحررة والمنشورة. لا تستخدم كلمة مرور الحساب في التكامل. عند الحاجة، استخدم Application Password محدودًا ومخزنًا في بيئة آمنة أو GitHub Secrets.

## الوسائط

الصور داخل `assets/wordpress-sense/` مولدة خصيصًا للتصميم والتحرير التصوري. لا تمثل توثيقًا ميدانيًا لمواقع العيزرية ولا تستبدل الصور الأصلية أو المرخصة في التقرير النهائي.
