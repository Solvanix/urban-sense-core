# SENSE — خارطة ما بعد الترقية والتبديل إلى Blocksy

## القرار

تستمر النسخة الحالية على WordPress.com Free لبناء المحتوى والهيكل دون دفع. بعد اعتماد الترقية، يكون المسار المقترح هو **WordPress.com Personal + Blocksy Free**. لا نشتري Blocksy Pro إلا إذا ظهرت حاجة تشغيلية واضحة بعد اختبار النسخة المجانية.

## ما أُنجز قبل الترقية

- إنشاء موقع WordPress باسم SENSE على النطاق المؤقت `sense133.wordpress.com`.
- ضبط اسم الموقع والوصف الوطني.
- إنشاء مسودة الصفحة الرئيسية.
- إنشاء مسودة صفحة «المتجر الوطني».
- حفظ المحتوى والهوية وخريطة الصفحات في GitHub.
- عدم تفعيل الدفع أو الشحن أو الطلبات قبل التحقق من المنتجات والشركاء.

## جدول التنفيذ بعد الترقية

| المرحلة | التوقيت | الإجراء | معيار الإنجاز |
|---|---|---|---|
| 1. الترقية | بعد اعتماد الميزانية | تفعيل WordPress.com Personal فقط | ظهور إمكانية رفع القوالب وتثبيت الإضافات |
| 2. النسخة الاحتياطية | مباشرة بعد الترقية | تصدير المحتوى وحفظ نسخة من الصفحات والمسودات | وجود نسخة قابلة للاستعادة قبل تبديل القالب |
| 3. تثبيت القالب | بعد النسخة الاحتياطية | تثبيت Blocksy Free وتفعيله | عمل الموقع دون فقد الصفحات أو الصور |
| 4. الهوية | اليوم نفسه | تطبيق RTL والألوان والخطوط وقيم `sense-brand-tokens.json` | اتساق الرأس والتذييل والأزرار والروابط |
| 5. الهيكل | المرحلة التالية | إنشاء الرئيسية، الوجهات، القصص، المتجر، الحرفيين، عن SENSE، تواصل معنا | قائمة تنقل واضحة وروابط سليمة |
| 6. التحرير | بعد الهيكل | نقل القصة الرئيسية والتقرير السياحي والمحتوى الموثق من الحزمة التحريرية | كل مادة لها مصدر وحالة تحريرية واضحة |
| 7. الوسائط | بعد مراجعة الحقوق | رفع الصور المرخصة أو الموثقة وإضافة Alt Text وتعليقاتها | لا توجد صورة بلا مصدر أو وصف بديل |
| 8. المتجر التجريبي | قبل التجارة | إنشاء بطاقات منتجات وقصص حرفيين بوضع «قيد التجهيز» | لا يوجد دفع أو طلب فعلي قبل اكتمال المتطلبات |
| 9. التجارة | بعد اعتماد الشركاء | اختيار WooCommerce أو خطة Commerce وإعداد الشحن والدفع والسياسات | اختبار طلب كامل دون نشر تجاري قبل المراجعة |
| 10. الإطلاق | بعد الفحص | نشر الصفحات المعتمدة ثم إطلاق الموقع العام | فحص الهاتف، RTL، الروابط، الوصول، والسرعة |

## شروط الانتقال إلى المتجر الحقيقي

لا نفعّل البيع قبل توفر قائمة المنتجات، بيانات الحرفيين، الأسعار، الصور والحقوق، مناطق الشحن، سياسة الاسترجاع، وسيلة الدفع، معلومات التواصل، وآلية معالجة الطلبات. أي صفحة متجر قبل ذلك تبقى تعريفية أو مسودة.

## قرار القالب البديل

إذا تعذر تثبيت Blocksy بعد الترقية، نستمر على **Twenty Twenty-Five** إن كان متاحًا، لأنه مجاني ويدعم محرر الموقع والأنماط والصفحات التحريرية. لا نستخدم Twenty Twenty-One كخيار نهائي إلا إذا كان هناك سبب تقني، لأنه أقل ملاءمة لمنصة سياحية ومتجر وطني.

## قواعد GitHub وWordPress

GitHub هو مصدر الخطط والنصوص وقيم الهوية وسجل التغييرات. WordPress هو النسخة المحررة والمسودة والمنشورة. لا تحفظ كلمات المرور أو رموز الدخول أو مفاتيح API في المستودع. أي مزامنة تلقائية مستقبلية تحتاج قرارًا منفصلًا، ويفضل أن تنشئ مسودات فقط قبل المراجعة.
