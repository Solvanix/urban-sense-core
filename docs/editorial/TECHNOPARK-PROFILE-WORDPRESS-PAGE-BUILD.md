# بناء صفحة WordPress لبروفايل فلسطين تكنوبارك

## المرجع البصري

المرفق `DOC-20261005-WA0052` يقدم صفحة سردية عربية مستقلة بعنوان «محمد التاج: حين يصبح القلم طريقًا إلى الحياة». قوته ليست في موضوعه فقط، بل في طريقة البناء:

- صفحة RTL كاملة.
- غلاف بصري كبير.
- عنوان واضح فوق صورة.
- مقدمة قصيرة تقود إلى القصة.
- عناوين فرعية متتابعة.
- بطاقات ومراحل.
- اقتباس بارز.
- شبكة صور مع تعليقات.
- ملاحظات تحقق وحقوق.
- فصل بين النص المنشور ولوحة التحرير الداخلية.

سنستخدم **منطق التصميم** نفسه لبروفايل تكنوبارك، لا المحتوى ولا الصورة ولا شريط التحرير.

## الهدف البصري

أن تبدو صفحة تكنوبارك كصفحة مجلة/ملف صحفي مؤسسي، لا كصفحة تقنية أو تقرير جامد.

### الهوية المقترحة

```text
اللون الرئيسي: تركوازي داكن #0d6870
لون النص: أزرق حبر #102f3a
لون الإشارة: ذهبي هادئ #c99a3b
الخلفية: ورق دافئ #f7f3ea
الخلفية الخارجية: أخضر رمادي فاتح #dfe5e3
```

### القاعدة

الغلاف يجذب القارئ، لكن الأدلة والمشاهد والمصادر تقود القراءة. لا نستخدم مؤثرات بصرية لتغطية نقص في المعلومة.

# الهيكل المرئي للصفحة

## 1. شريط تعريف صغير

يظهر فوق العنوان:

> **بروفايل مؤسساتي | فلسطين تكنوبارك | بيرزيت**

ويُضاف بجانبه وسم الحالة:

> **مادة محدثة — قيد المتابعة**

هذا أفضل من إخفاء أن نتائج الأثر طويلة المدى لم تُستكمل بعد.

## 2. الغلاف

### العناصر

- صورة غلاف أصلية أو مرخصة للمبنى أو مساحة العمل.
- طبقة تركوازية شفافة لضمان قراءة النص.
- العنوان:

> **فلسطين تكنوبارك: الفكرة لا تسكن المبنى وحده**

- العنوان الفرعي:

> **من مبنى للابتكار في بيرزيت إلى يوم تخرج ومعرض وظائف: كيف تنتقل المهارة من قاعة التدريب إلى العالم المهني؟**

- بيانات صغيرة:

```text
ملف مؤسساتي بسرد ميداني
آخر تحديث: [التاريخ]
إعداد: [اسم الكاتب/المحرر]
```

### WordPress

يُنفذ باستخدام:

1. Cover block.
2. Image من Media Library.
3. عنوان H1.
4. فقرة العنوان الفرعي.
5. سطر بيانات صغير.

لا نضع صورة Base64 ضخمة داخل HTML. تُرفع الصورة إلى مكتبة WordPress مع المصدر والنص البديل.

## 3. مقدمة على هيئة بطاقة افتتاحية

توضع المقدمة في صندوق بلون الورق أو بخط أكبر قليلًا:

> في 26 سبتمبر 2026، لم يكن مبنى فلسطين تكنوبارك في بيرزيت يستضيف حفل تخرج فقط. كان المكان يجمع خريجين أنهوا مسارًا تدريبيًا، وشركات تبحث عن مهارات قابلة للاستخدام، وأشخاصًا يحاولون معرفة الخطوة التالية بعد الشهادة.

وظيفتها أن تدخل القارئ إلى المشهد قبل تعريف المؤسسة.

## 4. بطاقة المؤسسة

بعد المقدمة، نضع بطاقة مختصرة بعنوان:

### بطاقة سريعة

| العنصر | المعلومة |
|---|---|
| الاسم | فلسطين تكنوبارك |
| الموقع | بيرزيت |
| التأسيس | 2016، وفق المصدر الرسمي |
| الطبيعة | شركة غير ربحية ومركز بحث وابتكار |
| الشراكة المؤسسة | جامعة بيرزيت وTech Forum |
| الوظيفة المعلنة | وصل البحث والابتكار وريادة الأعمال والقطاع الخاص |

تظهر البطاقة بصريًا، لكن كل معلومة تبقى مرتبطة بالمصدر في أسفل الصفحة.

## 5. قسم «المبنى الذي يفتح على منظومة»

يستخدم تخطيطًا ثنائي الأعمدة على سطح المكتب، ويتحول إلى عمود واحد على الهاتف:

- العمود الأول: وصف المؤسسة والمبنى.
- العمود الثاني: اقتباس أو حقيقة مختصرة.

الاقتباس المقترح:

> **المساحة لا تصبح منظومة تلقائيًا؛ المنظومة تبدأ عندما تتصل المعرفة بالتطبيق والناس بالسوق.**

هذا اقتباس تحليلي للكاتب، وليس اقتباسًا منسوبًا إلى مسؤول.

## 6. قسم «من المختبر إلى التجربة»

يظهر على شكل ثلاث بطاقات:

```text
المختبر
تجربة الأفكار وبناء النماذج الأولية

البرنامج
تدريب وإرشاد واحتضان

السوق
لقاء مهني يحتاج إلى متابعة
```

تحت البطاقات يكتب تنبيه صغير:

> هذه البطاقات تلخص بنية الفرص كما تعرضها المصادر؛ ولا تثبت وحدها عدد الوظائف أو النماذج التي استمرت.

## 7. خط المسار المؤسسي

هذا هو الإنفوغراف المركزي داخل المقال:

```text
المدخلات
جامعة + مكان + برامج + شركاء + خريجون
          ↓
العمليات
تدريب + تجريب + إرشاد + احتضان + لقاءات
          ↓
المخرجات
شهادة + مشروع + نموذج + سيرة + مقابلة
          ↓
الأثر
تدريب لاحق + وظيفة + عقد + عميل + استمرارية
```

يُلون كل مستوى بلون مختلف، ويُضاف تحت «الأثر»:

> يحتاج إلى متابعة بعد 30 و90 و180 يومًا.

## 8. قسم يوم 26 سبتمبر

يُعرض على شكل بطاقة زمنية:

```text
26 سبتمبر 2026
فعالية تخرج
↓
معرض وظائف
↓
مراجعة سير ذاتية ومقابلات تجريبية
↓
تواصل بين خريجين وشركات
↓
نتيجة تحتاج متابعة
```

تُذكر بوضوح عبارة:

> الرصد الميداني يثبت طبيعة اللقاء، لكنه لا يثبت أن كل لقاء تحول إلى وظيفة.

## 9. القصة المصورة

تضاف 5–7 صور بعد استكمال الحقوق. لكل صورة:

- صورة أصلية أو مرخصة.
- تعليق يضيف معلومة لا يكرر الصورة.
- مصدر وحقوق في سجل داخلي.
- نص بديل وصفي.

### أمثلة للتعليقات

- **المبنى:** «مساحة مؤسسية تحاول الجمع بين العمل والتعلم والبحث، وفق الوصف الرسمي للمكان.»
- **المختبر:** «الأداة لا تعني أثرًا وحدها؛ القيمة تظهر في ما ينتجه المستخدم وكيف يواصل بعد التجربة.»
- **الفعالية:** «لقاء مهني بين خريجين وشركات في 26 سبتمبر 2026؛ النتيجة اللاحقة تحتاج متابعة.»

لا نستخدم صورًا أرشيفية بوصفها صورًا للفعالية الأخيرة.

## 10. الصوت والفيديو

### الصوت

يوضع بعد قسم يوم التخرج، داخل بطاقة بلون خفيف:

> **اسمع القصة من صاحبها**

مدة التسجيل: 1–3 دقائق.

المطلوب: خريج أو ممثل برنامج أو شركة، بموافقة واضحة. لا نضع صوتًا مولدًا أو اقتباسًا مختلقًا مكان الشهادة الحقيقية.

### الفيديو

يوضع قرب نهاية المقال، قبل قسم الأثر:

> **فيديو توضيحي: من المهارة إلى اللقاء المهني**

مدة الفيديو: 60–90 ثانية.

بنيته:

1. المكان.
2. التدريب أو المختبر.
3. السير الذاتية أو التحضير.
4. اللقاء المهني.
5. السؤال عن الخطوة التالية.

الفيديو لا يكرر المقال كاملًا، ولا يستخدم فيديو قديمًا على أنه توثيق لفعالية 26 سبتمبر.

## 11. لوحة «ما نعرفه وما يحتاج متابعة»

هذه من أقوى أفكار المرفق، وتناسب القصة مؤسسيًا:

| الحالة | أمثلة |
|---|---|
| مثبت بمصدر | تأسيس المؤسسة، تعريفها، برامجها المعلنة |
| رُصد ميدانيًا | انعقاد فعالية 26 سبتمبر، لقاء خريجين وشركات |
| يحتاج تثبيتًا | الرقم النهائي للشركات، عدد المقابلات، نتائج المتابعة |
| لا ندعيه | أن كل خريج توظف، أو أن كل لقاء أصبح عقدًا |

## 12. الخاتمة والنداء

الخاتمة تكون داخل مساحة هادئة، ثم يظهر نداء غير دعائي:

> **إذا كانت المهارة هي البداية، فالأثر هو ما يحدث بعد مغادرة القاعة.**

ثم روابط:

- موقع فلسطين تكنوبارك.
- صفحة جامعة بيرزيت.
- مصدر الفعالية.
- صفحة GitHub الخاصة بالمادة.
- رابط تحديث لاحق عند توفر نتائج المتابعة.

# ما نأخذ من الكود المرفق وما نتركه

## نأخذ

- RTL.
- نظام الألوان.
- الغلاف البصري.
- البطاقات.
- الاقتباس البارز.
- شبكة الصور.
- لوحة التدقيق.
- الفصل بين المنتج العام ولوحة التحرير.
- النص البديل الموسع للصور.

## لا نأخذ

- صورة Base64 ضخمة داخل الصفحة.
- شريط `editor-bar` الداخلي.
- زر «إغلاق» الخاص بالمحرر.
- ادعاء أن الصفحة تفاعلية إذا كانت مجرد HTML ثابت.
- أي صورة أو نص من قصة محمد التاج داخل بروفايل تكنوبارك.

# التنفيذ العملي في WordPress

## النسخة الأولى الآمنة

1. تحرير المنشور #167.
2. وضع العنوان والغلاف والمقدمة.
3. إدخال بطاقة المؤسسة باستخدام جدول WordPress.
4. إدخال المسار المؤسسي باستخدام Group/Columns أو صورة إنفوغراف.
5. إدخال المقال النهائي في عناوين H2 واضحة.
6. إضافة صورة غلاف من Media Library مع نص بديل.
7. إضافة صندوق «ما نعرفه وما يحتاج متابعة».
8. إضافة مصادر وروابط في نهاية الصفحة.
9. حفظ كمسودة ثم مراجعة الهاتف وقارئ الشاشة.
10. نشر بعد اكتمال الفيديو والصوت أو وسمهما بوضوح كعناصر قيد الإضافة.

## قاعدة WordPress

لا نلصق صفحة HTML كاملة تحتوي على `<html>` و`<head>` و`<body>` داخل محرر المقال. WordPress يحتاج محتوى داخل الصفحة، لا وثيقة HTML مستقلة. نستخدم Gutenberg blocks، ونستعمل Custom HTML فقط للعناصر الصغيرة التي لا يوفرها المحرر.

## النتيجة المطلوبة

صفحة تشبه نموذج المرفق في إحساسها، لكنها أفضل تحريريًا لتكنوبارك:

```text
غلاف مجلة
→ مقدمة ميدانية
→ بطاقة مؤسسة
→ قصة ومشهد
→ مسار مؤسسي مرئي
→ صور وصوت وفيديو
→ جدول تحقق
→ مصادر وحقوق
```

بهذا تصبح الصفحة **بروفايلًا مؤسساتيًا مقروءًا ومشاهدًا ومسموعًا**، لا مجرد تحليل نصي أو كود تقني.
