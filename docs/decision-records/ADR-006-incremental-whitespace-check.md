# ADR-006: فحص المسافات البيضاء على التغيير المقدّم

**الحالة:** معتمد  
**التاريخ:** 15 أغسطس 2026

## السياق

كان فحص Repository Baseline يستخدم فرق Git بين الشجرة الفارغة ورأس المستودع. لذلك كان يفحص التاريخ الكامل في كل دفع ويفشل بسبب مسافات بيضاء قديمة في ملفات قالب وأدوات وملفات توثيق، حتى عندما لا تمسها التغييرات الجديدة.

## القرار

يفحص GitHub Actions الآن التغيير الذي قُدّم فقط:

| الحدث | نطاق الفحص |
|---|---|
| طلب دمج | من قاعدة الطلب إلى `HEAD` |
| دفع اعتيادي | من مرجع الدفع السابق إلى `HEAD` |
| أول دفع إلى فرع | من الشجرة الفارغة إلى `HEAD` |

يبقى فحص منع ملفات البيئة وحصر وثائق الأساس دون أي تغيير. هذا لا يعفي أي تعديل جديد من فحص المسافات البيضاء؛ بل يمنع خطأ تاريخيًا من إخفاء نتيجة التغيير الحالي.

تجلب خطوة checkout التاريخ الكامل عمدًا، لأن المقارنة مع مرجع الدفع السابق أو قاعدة طلب الدمج لا يمكن أن تعمل بصورة موثوقة في نسخة عمل سطحية لا تحتوي المرجع المقارن.

## العواقب

لا يصبح تنظيف الملفات التاريخية شرطًا لإصدار تحسينات آمنة، لكنه يظل عمل صيانة منفصلًا يمكن تنفيذه لاحقًا مع مراجعة واضحة. كل دفع جديد وطلب دمج سيستمر في الفشل عند إدخال مسافات بيضاء غير سليمة ضمن فرق التغيير الخاص به.
