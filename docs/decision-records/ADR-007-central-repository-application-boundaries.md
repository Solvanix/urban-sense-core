# ADR-007: مستودع مركزي، تطبيقات مستقلة

**الحالة:** مقبول  
**التاريخ:** 15 أغسطس 2026

## السياق

الهدف هو أن يبقى GitHub السجل التنفيذي الواحد لمنظومة SENSE، مع الحفاظ على الاختلاف الجوهري بين البلاغات البلدية ومنصة المزودين والتجربة السياحية والتجارة المستقبلية.

## القرار

تعيش التطبيقات تحت مستودع مركزي واحد، لكن تبنى في مجلدات تطبيقات مستقلة، وتملك كل منها قاعدة بيانات ومستخدمين وصلاحيات وبيئة نشر وعقود API خاصة بها. يبدأ التطبيق السياحي في `apps/sense-experience` ولا يعدل نطاق `apps/web` أو مخطط Urban‑Sense أو بياناته.

## النتائج

يبقى تاريخ العمل، مراجعات GitHub، والوثائق في مكان واحد. وفي الوقت نفسه يمنع هذا القرار الخلط بين البلاغات المدنية وملفات المزودين، ويتيح اختبار ونشر كل تطبيق على حدة. أي استخدام مشترك مستقبلي يمر بقرار معماري وعقد تكامل محدود ومختبر.
