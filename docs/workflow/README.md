# SENSE Workflow Archive

هذا المجلد هو السجل المركزي لدورة عمل SENSE. يجمع القرارات والوثائق التي تشرح كيف انتقل المشروع من فكرة سياحية محلية إلى نموذج وطني قابل للتوسع، مع فصل واضح بين ما نُفّذ فعليًا وما هو قيد البحث وما هو مقترح لاحقًا.

## طريقة القراءة

ابدأ بملف [خريطة دورة العمل](./00-workflow-map.md). ثم راجع [الحالة التنفيذية](./01-state-register.md) لمعرفة الفرق بين الملفات المنشورة والقرارات غير المنفذة. تُحفظ القرارات المؤرخة في [سجل القرارات](./02-decision-log.md)، بينما تُحفظ الأعمال اللاحقة في [خارطة التطوير](./03-forward-roadmap.md).

## نطاق السجل

يغطي السجل خمس طبقات مترابطة:

1. **السابق:** الفرضيات، Problem Statement Canvas، Value Proposition Canvas، والقرار بأن العيزرية مختبر وليست حدود المنتج.
2. **الحالي:** SENSE Routes، عقد الوجهات الوطني، الفهرس الوطني، بطاقات الثقة، وصفحات الوجهات، وGitHub Actions.
3. **الحوكمة:** ملكية القصة، مراجعة المسار، العزل البلدي، وحقوق التصحيح والانسحاب.
4. **اللاحق:** Pilotات العنقود الأول، مركز المراجعة، التكامل مع WordPress، وMABA Bridge.
5. **الحدود:** ما لا ندعيه، وما يحتاج إلى مصدر أو مالك أو موافقة قبل نشره.

## قاعدة التوثيق

كل وثيقة جديدة يجب أن تذكر تاريخها، حالتها، مالك القرار المقترح، والملفات أو المسارات التي تتأثر بها. لا تُسجّل الشراكة أو الاعتماد أو الحجز كحقيقة إلا بعد وجود دليل قابل للمراجعة.
