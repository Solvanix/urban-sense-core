# بوابات الجودة الآلية

**التاريخ:** 18 سبتمبر 2026

**الحالة:** منفذة.

## الهدف

تمنع بوابة الجودة نشر عقد وجهات غير صالح أو صفحة تعتمد على JavaScript غير قابل للتحليل. وهي طبقة فحص تقنية، وليست بديلًا عن المراجعة المحلية أو الموافقة المؤسسية.

## الفحوصات

يعمل [Workflow التحقق](../../.github/workflows/national-contract.yml) عند تغيير عقد الوجهات أو أداة التحقق أو ملف Workflow نفسه. ويفحص:

- صحة JSON.
- إصدار العقد.
- وجود معرفات فريدة.
- اكتمال الحقول الأساسية.
- انتماء الحالة إلى قاموس الحالات.
- عدم وجود تاريخ مراجعة مستقبلي.
- وجود حقائق ومعلومات مالك للمحتوى.
- صلاحية تحليل ملفات JavaScript.

## ما لا يثبته الاختبار

نجاح الاختبار لا يثبت صحة القصة ميدانيًا، ولا يثبت شراكة أو اعتمادًا أو سلامة موقع. هذه الأمور تحتاج مالكًا ومراجعًا ومصدرًا وتاريخًا وخطوة موافقة مناسبة.

## التشغيل المحلي

```bash
python3 -m json.tool public-index/national/destinations.json >/dev/null
python3 scripts/validate_national_contract.py
node --check public-index/national/national.js
node --check public-index/national/destination.js
```

## قاعدة الإصلاح

إذا فشل الاختبار، لا نتجاوز البوابة بتعديل Workflow فقط. يجب إصلاح البيانات أو الكود أولًا، ثم تسجيل القرار إذا تغيرت حالة وجهة أو نطاقها.
