# خريطة دورة عمل SENSE

**الإصدار:** 1.0

**التاريخ:** 18 سبتمبر 2026

**الحالة:** وثيقة تشغيلية مرجعية.

## الخلاصة

تعمل SENSE وفق دورة تمنع القفز من قصة محلية إلى وعد سياحي غير مثبت. تبدأ الدورة بمصدر أو قصة، ثم تمر عبر عقد بيانات وملف وجهة، وتنتج تجربة محدودة ببطاقة ثقة. لا تنتقل الوجهة إلى مرحلة أعلى قبل تحقق شروطها.

```text
مصدر محلي أو قصة
  → بحث وتحديد ملكية
  → عقد وجهة
  → قصة تحريرية
  → مسار أو تجربة
  → بطاقة ثقة
  → مراجعة محلية
  → Pilot محدود
  → قياس وتصحيح
  → نشر أو إيقاف أو توسع
```

## المراحل

### المرحلة 0: فرضية أو إشارة

قد تكون البداية سؤالًا عن الوجهة، أو فجوة في عرضها، أو قصة غير ممثلة، أو صاحب تجربة محلي. هذه الإشارة ليست دليلًا ولا وعدًا. تُسجل بوصفها فرضية تحتاج إلى اختبار.

### المرحلة 1: البحث والملكية

يُجمع المصدر وتُحدد طبيعته وتاريخه ومالكه ومراجعته المحتملة. تُسجل مخاطر الخصوصية والوصول والاعتراض. لا تُنقل ادعاءات وجهة إلى وجهة أخرى.

### المرحلة 2: عقد الوجهة

تُمنح الوجهة معرفًا مستقلًا وتُسجل منطقتها وعنقودها ونوعها وحالتها. الملف الحالي هو `public-index/national/destinations.json`. وجود السجل لا يعني أن الوجهة منشورة أو معتمدة.

### المرحلة 3: القصة التحريرية

تشرح القصة لماذا تستحق الوجهة الانتباه. يمكن أن تظهر في WordPress أو في مادة إعلامية مستقلة. لا تتحول القصة وحدها إلى حجز أو مسار مضمون.

### المرحلة 4: التجربة التشغيلية

يُحدد المسار والمدة والصعوبة والوصول والمضيف وحدود المعرفة. لا يُضاف حجز قبل وجود مزود وسعة وسعر وسياسة وتواصل.

### المرحلة 5: بطاقة الثقة

توضح البطاقة المصدر والمالك وتاريخ المراجعة وحالة الوصول وما ينقص. يجب أن يفهم الزائر الفرق بين `candidate` و`pilot` و`public`.

### المرحلة 6: المراجعة وPilot

تُراجع المعلومات من مالك المحتوى والمراجع المناسب. يبدأ Pilot محدودًا لا بتغطية وطنية كاملة. العيزرية هي Pilot 01، والوجهات الأخرى في العنقود الأول مرشحة أو قيد البحث.

### المرحلة 7: القياس والتعلم

نقيس فهم الزائر للبطاقة، جودة المصدر، التصحيحات، الاعتراضات، الوصول، والمنفعة المحلية. لا يكفي قياس المشاهدات أو عدد البطاقات.

### المرحلة 8: القرار

النتيجة واحدة من ثلاث: رفع الحالة، إبقاء الوجهة في البحث، أو الإيقاف/التحديث. قرار التوسع يحتاج دليلًا محليًا وليس مجرد رغبة في زيادة عدد الوجهات.

## الفصل بين الطبقات

| الطبقة | وظيفتها | لا تعني |
|---|---|---|
| WordPress | قصة وتقرير وسياق | حجزًا أو اعتمادًا |
| GitHub | عقد ونسخ وحالة تقنية | سجلًا حكوميًا |
| SENSE Routes | مسارات وتجارب قابلة للعرض | توفرًا ميدانيًا دائمًا |
| بطاقة الثقة | تفسير الجاهزية والمصدر | شهادة رسمية |
| البلدية | مراجعة نطاقها عند التفويض | ملكية روايات كل المدن |
| MABA | جسر تقني مؤجل أو تجريبي | تشغيل أجهزة أو أموال حاليًا |

## بوابة الانتقال

لا تُرفع الوجهة من `candidate` إلى `pilot` دون حد أدنى من: معرف مستقل، مالك محتوى، مصدر قابل للمراجعة، تجربة محدودة، حدود وصول، وسجل مخاطر. لا تُرفع إلى `public` دون مراجعة وتاريخ تحديث وحدود نشر واضحة.
