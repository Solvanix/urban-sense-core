## قالب قرار جديد

انسخ السطر التالي عند الحاجة:

```text
التاريخ:
القرار:
المشكلة أو السؤال:
البدائل التي روجعت:
الاختيار:
السبب:
الأثر على البيانات:
الأثر على WordPress:
الأثر على البلديات أو أصحاب التجارب:
الدليل أو رابط الملف:
الحالة:
```

## قاعدة صلاحية القرار

قرار المنتج لا يثبت شراكة. وقرار الحالة لا يثبت اعتمادًا. وأي قرار يغير نطاق الوجهة أو صلاحيات المراجعة أو وعد الحجز يحتاج دليلًا إضافيًا قبل نشره للزائر.
