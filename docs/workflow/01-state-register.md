## ما لا ينبغي ادعاؤه

لا توجد في هذا السجل شراكة بلدية مثبتة، أو قاعدة وطنية مكتملة، أو حجوزات وطنية، أو اعتماد رسمي، أو تشغيل NFC/دفع. GitHub Pages هو واجهة نموذجية وسجل تقني، وليس سجلًا رسميًا للملكية أو المعالم.

## قاعدة التحديث

عند تغير حالة عنصر، يجب تحديث هذا الملف وعقد البيانات وسجل القرار المتعلق به في نفس الدفعة. يجب أن يذكر التحديث تاريخ التغيير وسببه ودليله.
