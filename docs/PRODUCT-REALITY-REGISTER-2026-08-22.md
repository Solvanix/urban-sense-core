# سجل حقيقة المنتج — SENSE وUrban‑Sense

**آخر تحقق:** 22 أغسطس 2026.  
**الغرض:** منع تسمية الواجهة الاستكشافية «منصة عاملة»، أو تسمية كود قابل للبناء «خدمة إنتاجية»، أو تقديم تصور متجر أو موقع فريق بوصفه منتجًا منشورًا.

> التطبيق الفعلي هو خدمة يستطيع مستخدم مخول أن ينجز فيها الإجراء الأساسي مع خادم وبيانات وصلاحيات واضحة. أما الواجهة الاستكشافية فتعرض المسار أو تشرح القرار، لكنها لا تنفذ خدمة خلفية ذات بيانات تشغيلية.

## التصنيف الحالي

| الأصل | التصنيف الصريح | ما يعمل فعليًا | ما ليس موجودًا أو لا يجوز الادعاء به |
|---|---|---|---|
| **Urban‑Sense** في `apps/web` | **تطبيق وظيفي في بيئة عرض مُدارة؛ قابل للنشر المستقل** | إنشاء البلاغ ومتابعته، دورة مراجعة وإسناد وأدلة وإغلاق، أدوار وصلاحيات وتدقيق، خادم وMySQL، وفحوص المصدر. | ليس بعد خدمة رسمية تملك الجهة استضافتها ونطاقها وOIDC وقاعدة إنتاجها. |
| **بوابة SENSE** عند جذر النسخة الحية | **واجهة توجيه/تعريف تفاعلية** | اختيار الرحلة، الانتقال إلى Urban‑Sense، إظهار الحالة والحدود والروابط. | ليست في ذاتها منصة إدارة أو متجرًا أو قاعدة بيانات موحدة أو حساب شريك. |
| **فهرس GitHub Pages** في `public-index` | **فهرس ثابت منشور** | يعرّف الزائر بالمنظومة ويقوده إلى المصادر والمسارات المتاحة. | لا يشغّل Express أو MySQL أو تسجيل دخول أو معاملات. |
| **SENSE Experience** في `apps/sense-experience` | **نواة تطبيق مستقلة قابلة للبناء؛ غير منشورة خدمةً عامة** | واجهة عربية، عقد اهتمام وانضمام، API ومخطط `sx_*`، مراجعة مستقلة مقيدة بالدور، اختبارات. | لا استقبال حقيقي لمزودين حتى نشر الخدمة المستقلة، قاعدة بياناتها، هوية المراجعين، سياسة احتفاظ وموافقة جاهزية. |
| **دليل الميزات المستند إلى الاستبانة** | **واجهة تفاعلية تعليمية/استكشافية داخل نواة SENSE Experience** | يشرح للمزود والزائر والمراجع كيف تتحول المعلومة إلى بطاقة عامة أو بيانات خاصة أو ادعاء يحتاج دليلًا. | لا ملف مزود، لا دليل سياحي حي، لا حجز، لا شهادة، لا مزودون أو تقييمات مصطنعة. |
| **المتجر والمدفوعات والمحاسبة** | **مسار مقترح فقط** | توجد حدود معمارية ووثائق قرار، ولا يوجد تشغيل في المصدر المركزي. | لا كتالوج، لا سلة، لا دفع، لا فاتورة، لا مخزون، لا سياسة إرجاع، ولا محاسبة تشغيلية. |
| **موقع أو بروفايل فريق مستقل** | **غير مبني كمنتج مستقل بعد** | بوابة SENSE تقدم تعريفًا محدودًا بالمنظومة ومساراتها. | لا موقع فريق رسمي منفصل، ولا صفحة خدمات/تواصل موثقة، ولا دومين أو بريد مهني معتمد. |
| **رؤية حاسوبية/YOLO ومدن ذكية** | **بحث وهندسة مرجعية مقيدة** | تدقيق مصدر وخريطة حوكمة وقرار منع تشغيل غير مرخص أو غير موافق عليه. | لا كاميرات، لا بث، لا تحليل ميداني، لا استدلال إنتاجي، ولا خدمة مراقبة. |
| **الإتاحة المتخصصة** | **خط أساس داخل الواجهات** | RTL وتباين أعلى وتقليل حركة وأساس دلالي. | لا تطبيق إتاحة أو خدمة مخصصة أو بحث مستخدمين مكتمل. |

## معنى ذلك للمستخدم

بوابة SENSE والفهرس العام وصفحات التقدم ودليل الميزات **ليست عرض PowerPoint**؛ فهي واجهات ويب حقيقية وروابط وتفاعل وحالات ونصوص مبنية من العقود. لكنها تؤدي وظيفة **التعريف والتوجيه واستكشاف القرار**، لا وظيفة المنتج التشغيلي نفسه. من الخطأ تقديمها كمتجر أو منصة مزودين أو تطبيق فريق قائم.

في المقابل، Urban‑Sense ليس عرضًا تقديميًا: لديه منطق خادم وقاعدة بيانات وصلاحيات ودورة عمل واختبارات. وSENSE Experience ليس مجرد تصميم بصري أيضًا؛ فيه عقد خادم ومخطط بيانات ومراجعة واختبارات، لكنه ما زال **نواة غير منشورة** وليس خدمة مزودين حية. هذا فرق جوهري بين «كود منتج حقيقي غير مطلق» و«عرض يشرح منتجًا مقترحًا».

## بوابات التحويل إلى منتجات تشغيلية

| المنتج المقصود | أقل ما يلزم قبل تسميته خدمة فعلية | القرار أو الاعتماد المطلوب |
|---|---|---|
| Urban‑Sense الرسمي | خادم مملوك للجهة، تشغيل Docker موثق، MySQL مُدار، OIDC، تخزين أدلة، نسخ احتياطي، نطاق وTLS، مراقبة | اختيار الجهة للخادم والنطاق ومزود الهوية، ثم اختبار تشغيل حقيقي. |
| SENSE Experience للمزودين | نشر API وواجهة، قاعدة `sx_*` مستقلة، هجرة مخطط، هوية مراجع حقيقية، سياسة خصوصية واحتفاظ وحذف، موافقة جاهزية، أول مزود حقيقي بموافقته | مالك خدمة، مراجعون، وسياسة بيانات قبل فتح التسجيل. |
| دليل سياحي للزائر | مزودون وافقوا على الظهور، حقائق خدمة محدثة، سياسة ادعاءات وأدلة، خطة تحديث، جهة مسؤولة عن الإشراف | لا ينشر ببطاقات بديلة أو تقييمات مزيفة. |
| متجر | قرار نموذج تجارة، كتالوج حقيقي وحقوق صور، شريك دفع/Shopify أو بديل، مخزون أو تنفيذ، ضرائب/فواتير، إرجاع وخدمة عملاء | قرار مالك صريح بشأن المتجر والمنصة والمشغل القانوني. |
| موقع فريق رسمي | هوية/اسم معتمد، وصف خدمات لا يبالغ، معلومات اتصال مفوضة، محتوى فريق بموافقته، دومين وبريد عند القرار | اعتماد الاسم والدومين والمواد قبل النشر. |
| منصة تعلم أو تمكين | منهج مرخص أو أصيل، مالك محتوى، تعريف إنجاز/دليل، سياسة بيانات، مدربون أو تشغيل واضح | تحليل المسار السياحي الذي سيقدمه المالك ثم قرار نطاق. |

## القرار العملي التالي

لا ينبغي أن نضيف مزيدًا من صفحات «مستقبلية» قبل تثبيت المنتج الذي نريد تشغيله أولًا. الخياران الحقيقيان الآن هما: **(1)** جعل Urban‑Sense خدمة رسمية مستقلة عن بيئة العرض، أو **(2)** إطلاق برنامج SENSE Experience محدودًا بمزودين حقيقيين بعد استكمال التشغيل والخصوصية. أما المتجر وموقع الفريق والتعلم المتكامل فهي مشاريع مستقلة تحتاج قرار منتج ومالك تشغيل، لا إضافات إلى بوابة تعريفية.
