# نموذج الوصول الفردي — SENSE وUrban‑Sense

## المبدأ

تُحفظ قاعدة البيانات والمناطق التشغيلية خلف تسجيل دخول فردي. لا توجد كلمات مرور مشتركة، ولا حساب «admin» جماعي، ولا كلمة مرور افتراضية. كل شخص يستخدم هويته الخاصة، ثم يمنحه مدير المنصة الدور والنطاق اللازمين فقط.

تستعمل التطبيقات المصادقة المدمجة الحالية لتحديد الهوية. لا تخزن المنصة كلمة المرور نفسها؛ تدير خدمة الهوية تسجيل الدخول. هذا يقلل احتمال مشاركة كلمة مرور أو بقائها بعد مغادرة عضو من الفريق.

## طبقات الوصول

| الطبقة | من يملكها | ما تسمح به | ما لا تسمح به |
|---|---|---|---|
| الزائر العام | أي زائر | فتح الصفحات والفهرس العامين. | البيانات التشغيلية أو حسابات المستخدمين أو المستودع الخاص. |
| المستخدم | حساب فردي موثق | تقديم بلاغه ومتابعته وتقييم بلاغه المغلق فقط. | بلاغات الآخرين أو إدارة أعضاء أو بيانات بلدية. |
| الموظف البلدي | حساب فردي مع عضوية بلدية نشطة | مراجعة أو إسناد أو تنفيذ أو تحقق بحسب الدور البلدي. | إدارة المنصة أو بلديات أخرى بلا عضوية. |
| المطور | حساب فردي يعيّنه مدير المنصة | وصول تقني منفصل يحدد خارج التطبيق، مع عدم وراثة صلاحيات بلدية تلقائيًا. | البلاغات أو الصلاحيات البلدية لمجرد حمل دور المطور. |
| مدير المنصة | حساب فردي فقط | إدارة الحسابات والأدوار، وإنشاء البلديات، وسجل التدقيق. | إزالة أو إيقاف حساب المالك المؤسس. |

## قواعد التحكم

1. يرقّى حساب المالك المعتمد فقط تلقائيًا إلى `platform_admin` عند تسجيل الدخول.
2. لا يمكن لمدير المنصة إيقاف حساب المالك أو خفض دوره، ولا يمكنه إيقاف حسابه أو خفض دوره بنفسه.
3. يسجل كل تغيير دور أو حالة حساب في سجل التدقيق مع الفاعل والحالة السابقة والحالة الجديدة.
4. الحساب الذي تكون حالته `isActive = false` يرفض عنه كل إجراء محمي حتى يعيد مدير المنصة تفعيله.
5. تبقى الأدوار البلدية ونطاق البلدية مستقلين عن دور المطور وعن الوصول إلى مستودع GitHub.

## منح الوصول

1. يطلب الشخص الوصول بحسابه الفردي؛ لا يرسل كلمة مروره إلى الفريق أو عبر الدردشة.
2. يسجل دخولًا واحدًا ليُنشأ سجله بالحد الأدنى من الدور `citizen`.
3. يعيّن مدير المنصة الدور والحالة من إدارة الوصول، ثم — إن لزم — يضيف عضوية البلدية والدور البلدي المحدد.
4. يمنح الوصول إلى مستودع GitHub الخاص بدعوة مستقلة لحساب GitHub الفردي وبأقل صلاحية مناسبة؛ هذا منفصل عن حساب التطبيق.
5. عند انتهاء المهمة، يوقف مدير المنصة الحساب أو يسحب عضوية البلدية أو وصول GitHub، مع بقاء أثر التدقيق.

## حدود مقصودة

لا يعني دور المطور وصولًا تلقائيًا إلى البيانات الشخصية أو البلاغات. ولا يعني نشر فهرس GitHub Pages نشر المستودع أو قاعدة البيانات. أما بيانات العمل الحقيقية فتدخل فقط بعد تعيين الحسابات والموافقة التشغيلية المناسبة.
