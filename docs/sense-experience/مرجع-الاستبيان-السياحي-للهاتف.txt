1) فكرة المرجع
----------------
هذا ليس نموذج Google جديدًا، وليس طلب تمويل أو اعتمادًا رسميًا. هو مرجع عملي يحول أسئلة الاستبيانات السياحية وريادة الأعمال والابتكار إلى ملف مشروع واحد يمكن استخدامه في:

- بطاقة عرض المشروع للزائر.
- مقابلة الشريك أو صاحب المشروع.
- تقرير الجاهزية والتطوير.
- قصة WordPress بعد التحرير والموافقة.
- تجهيز طلبات البرامج والتحديات والتمويل.

القاعدة: نملأ المعلومات مرة واحدة، ثم نعيد استخدامها في مخرجات مختلفة بدل إعادة تعبئة نماذج طويلة.

10) مؤشر الجاهزية الإرشادي
--------------------------
قيّم كل عدسة من 0 إلى 4:

0 = غير موجود أو غير معروف.
1 = فكرة أو وصف أولي.
2 = ممارسة جزئية أو دليل محدود.
3 = ممارسة واضحة يمكن شرحها وإثباتها.
4 = ممارسة موثقة قابلة للتكرار والتحسين.

التفسير التقريبي:
0–34%   قصة تحتاج تأسيسًا.
35–59%  مشروع في طور البناء.
60–79%  جاهزية عرض أولي.
80–100% جاهزية قوية للمراجعة، وليست نشرًا تلقائيًا.

8. ما النتيجة التي تريدون قياسها بعد سنة؟

13) قواعد الخصوصية والثقة
--------------------------
- لا تضع رقم الهوية أو كلمات المرور في الملف العام.
- لا تنشر رقم الهاتف أو البريد دون موافقة.
- لا تستخدم كلمة «موثق» أو «معتمد» دون دليل ومراجعة.
- لا تعد بسعر أو توافر أو حجز حي دون نظام فعلي.
- لا تنشر قصة أو صورة دون موافقة.
- لا تخلط بيانات المشروع السياحي مع بيانات البلاغات البلدية.
- هذا المؤشر إرشادي وليس شهادة أو قرار تمويل.
