# عقد خدمة وبيانات SENSE Experience

## الهدف

ينقل هذا العقد طلبات الاهتمام من مخزن المتصفح المحلي إلى خدمة مستقلة قابلة للنشر. لا تستخدم الخدمة اتصال قاعدة بيانات Urban‑Sense، ولا تستورد جداولها أو مستخدميها أو أسرارها.

## متغيرات البيئة

تستخدم الخدمة متغيرًا واحدًا مستقلًا في البداية: `SENSE_EXPERIENCE_DATABASE_URL`. لا يكتب هذا المتغير في الكود أو GitHub أو وثائق عامة. إذا لم يكن متاحًا، ترفض الخدمة بدء مسار البيانات الحقيقية بدل أن تعود تلقائيًا إلى تخزين متصفح أو قاعدة Urban‑Sense.

## الجداول

| الجدول | المحتوى | مستوى الوصول |
|---|---|---|
| `sx_provider_interest` | هوية العلامة ونوعها ومنطقتها وقناة اتصال خاصة ووصف قصير وموافقة المراجعة وحالة الطلب. | مزود الطلب ومراجع مخول فقط. |
| `sx_interest_review_decision` | قرار المراجع، سببه، معرّف المراجع، ووقت القرار. | مراجع مخول ومدير فقط. |
| `sx_audit_event` | حدث إداري مصغر يثبت إنشاء الطلب أو القرار من دون تخزين نسخة عامة من بيانات الاتصال. | مدير ومراجع مخول فقط. |

لا يوجد جدول ملف عام في هذه الدفعة. دعوة الاهتمام لاستكمال الملف ليست نشرًا، ولا تتحول تلقائيًا إلى مزود عام.

## حالات الطلب

```text
interest_submitted
  ├── invited_to_onboard
  └── not_in_current_pilot
```

لا يغير الحالة إلا دور `reviewer` أو `administrator`، ومعه سبب لا يقل عن ثمانية أحرف. لا يعيد مزود أو عميل عام فتح القرار عبر API.

## سطح API الأولي

| الإجراء | من يستدعيه | السلوك |
|---|---|---|
| `providerInterest.submit` | زائر/مزود | ينشئ اهتمامًا مع موافقة المراجعة؛ لا يعيد بيانات الاتصال لعميل آخر. |
| `providerInterest.listForReview` | مراجع أو مدير موثق | يعرض قائمة خاصة للمراجعة فقط. |
| `providerInterest.decide` | مراجع أو مدير موثق | يسجل قرارًا وسببًا وحدث تدقيق؛ لا ينشر ملفًا. |

## بوابة استقبال بيانات حقيقية

لا تفعّل واجهة الإرسال على بيئة عامة حتى تتوفر خدمة منشورة، وTLS، وحسابات مراجعين حقيقية، وأدوار موثقة، وترحيلات مطبقة على قاعدة منفصلة، وسجل تدقيق، وسياسة احتفاظ وحذف، واختبار قبول لمسار الخطأ والنجاح. هذه الوثيقة تصمم البوابة ولا تدعي تحققها بعد.
