# تسليم هندسي حي — SENSE Experience

> **استخدم هذه الوثيقة قبل كتابة أي سطر جديد.** هي نقطة الحالة الهندسية الواحدة لتطبيق SENSE Experience داخل `urban-sense-core`: ما هو موجود في المستودع، وما ينتظر تفعيلًا تشغيليًا، وما لم يبدأ، وما لا يجوز فعله قبل بوابة قرار واضحة.

## 1. قاعدة القراءة السريعة

لا تعني كلمة «مبني» أن القدرة منشورة أو تستقبل بيانات حقيقية. يوضح الجدول التالي معنى الحالة المستخدمة في هذه الوثيقة.

| الحالة | معناها للمطور | الإجراء الصحيح |
|---|---|---|
| **مبني ومختبر** | يوجد مصدر واختبارات محلية، ويمكن تطويره داخل المستودع. | اقرأ العقد والاختبارات ثم وسّعها من دون تغيير حدود الخصوصية. |
| **مبني وينتظر تفعيلًا** | يوجد مخطط/إجراء/واجهة، لكن لا توجد بيئة تشغيل معتمدة أو بيانات حقيقية. | لا تفعّله قبل اجتياز بوابة التفعيل المحددة. |
| **مصمم فقط** | توجد حدود أو قرار منتج، لا تنفيذ تشغيلي. | ابدأ بالعقد والسياسة والاختبارات السالبة، لا بواجهة أو تكامل حي. |
| **محجوب بقرار** | يحتاج مصدر بيانات أو شريكًا أو موافقة قانونية/تشغيلية. | لا تضع مفاتيح أو مزودًا بديلًا أو بيانات تجريبية واقعية. |

## 2. البداية العملية للمطور

| خطوة | الأمر أو الملف | لماذا؟ |
|---|---|---|
| 1 | `cd apps/sense-experience && pnpm install --frozen-lockfile` | تثبيت اعتماديات التطبيق السياحي المستقل فقط. |
| 2 | `pnpm check && pnpm test && pnpm build` | يجب أن تمر الأنواع والاختبارات والبناء قبل أي تعديل أو طلب دمج. |
| 3 | `pnpm dev` | تشغيل واجهة Vite المحلية لمسارات الواجهة والمسوّدات المحلية. |
| 4 | [`apps/sense-experience/README.md`](../../apps/sense-experience/README.md) | أوامر التشغيل، الفصل عن Urban-Sense، والوثائق الملزمة. |
| 5 | [`todo.md`](../../todo.md) | المصدر التنفيذي للبنود المفتوحة؛ لا تحذف البنود السابقة، حدّث حالتها فقط. |

> **حد معماري ثابت:** لا تشارك SENSE Experience قاعدة بيانات أو OAuth أو أدوار أو بيانات بلاغات مع Urban-Sense. لا تتعامل مع مجلد `apps/web/` كبديل عن طبقة SENSE Experience.

## 4. ما لم يُبنَ أو لا يجوز تفعيله بعد

| القدرة | الحالة | سبب عدم البدء/التفعيل | أول مخرج مطلوب قبل الكود التشغيلي |
|---|---|---|---|
| رفع ملفات المزوّد | **مصمم فقط** | لا توجد سياسة احتفاظ أو تصنيف حساسية أو مخزن مرجعي معتمد. | عقد ملف خاص: مالك، نوع، حجم، سياسة حذف، حالة فحص ومراجع مسؤول. |
| مساعدة ذكاء اصطناعي لملفات وأسئلة متابعة | **مصمم فقط** | لا موافقة معالجة ولا سياسة إدخال/مخرجات ولا مراجعة بشرية. | تدفق مسودة صريح وموافقة مزود وإسقاط يمنع النشر الذاتي. |
| صور مولّدة أو صور مزودين | **محجوب بقرار** | حقوق استخدام وموافقة إزالة ومراجعة محتوى غير معتمدة. | سياسة حقوق وصاحب حق وحالة موافقة لكل أصل. |
| خريطة التجارب والموقع | **محجوب بقرار** | لا مصدر خرائط مرخّص ولا سياسة دقة للموقع. | عقد منطقة عامة مقابل موقع دقيق، مصدر مرخّص، وتاريخ تحديث. |
| نقل وحركة ومسارات وصول | **محجوب بقرار** | لا شريك تشغيل أو مصدر نقل موثوق أو تحقق ميداني. | مصدر بيانات أو شريك، وحدود دقة وتحذيرات قبل الزيارة. |
| حجز أو دفع | **محجوب بقرار** | لا مالك عملية أو سياسة إلغاء أو دعم أو التزامات قانونية. | قرار أعمال موثق ثم عقد طلب حجز مستقل. |
| متجر ومنتجات | **محجوب بقرار** | لا مصدر حقيقة للمنتج أو سياسات شحن/استرجاع. | اعتماد Shopify أو مصدر مستقل وسياسات تشغيل صريحة؛ لا تنقل المتجر من مشروع آخر تلقائيًا. |
| دليل زوار عام لمزوّدين | **غير مبني** | لا بيانات مزود حقيقية ولا مسار نشر معتمد. | إتمام التفعيل والمراجعة ثم عقد نشر مستقل؛ لا تبنِ قوائم وهمية أو تقييمات مختلقة. |
| اختبار إتاحة تشاركي | **غير منفذ** | لا جلسات مع مستخدمين ذوي إعاقة ومختصين بعد. | خطة اختبار تشاركي، ملاحظات موافق عليها، وإصلاحات قابلة للتتبع. |
| تحسين حجم الحزمة | **جاهز للبناء** | البناء ينجح مع تحذير JavaScript أكبر من 500KB. | تقسيم ديناميكي للمسارات وقياس قبل/بعد على أجهزة فعلية. |

## 5. بوابة تفعيل سجل الادعاءات

يمنع الكود الحالي استقبال بيانات مزودين حقيقية ما لم تتحقق الجاهزية. لا يختصر أي مطور هذه الخطوات بمجرد تغيير واجهة أو ضبط متغير محلي.

| الترتيب | المطلوب | الدليل المتوقع |
|---|---|---|
| 1 | إنشاء **قاعدة بيانات SENSE Experience مستقلة** وإعداد `SENSE_EXPERIENCE_DATABASE_URL`. | اسم/اتصال مستقلان عن Urban-Sense، ولا أسرار في Git. |
| 2 | مراجعة `0003_condemned_cerise.sql` وتطبيقه على تلك القاعدة فقط. | مراجعة SQL موثقة ثم جداول `sx_provider_claim` و`sx_claim_evidence` و`sx_claim_review_decision`. |
| 3 | إعداد OIDC للمراجعين وتعيين مراجع نشط. | هوية مراجع وحالة دور نشطة وفق عقد الهوية. |
| 4 | اعتماد قبول البيانات الحقيقية. | قيمة تشغيلية صريحة وموافقة جاهزية مكتوبة، لا تفعيل صامت. |
| 5 | تشغيل اختبار تكاملي ببيانات تجريبية غير حقيقية. | تصريح، دليل مرجعي، قرار مراجع، وسجل تدقيق من دون قائمة عامة. |
| 6 | قرار نشر منفصل بعد التحقق. | موافقة قائمة عامة وإسقاط حقول بيضاء فقط؛ لا دليل خاص ولا سبب قرار ولا هوية مراجع. |

## 7. قائمة منع الأخطاء الشائعة

لا تنشئ مزودين أو شهادات أو تقييمات أو حجوزات وهمية لأغراض العرض. لا تستخدم بيانات حقيقية في `localStorage` أو الاختبارات. لا ترفع أصلًا إلى التخزين قبل قراءة سياسة الملف وعقده. لا تربط SDK للخرائط أو النقل أو الدفع أو الذكاء الاصطناعي قبل قرار المصدر والسياسة. لا تخلط تنفيذ الواجهة المحلية مع تفعيل API الإنتاج، ولا تفسّر اجتياز الاختبار على أنه موافقة قانونية أو تحقق ميداني.
