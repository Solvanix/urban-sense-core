# مرجع محلي: جواز جاهزية المشروع السياحي

> هذا الملف هو المرجع التشغيلي المحلي لتحويل الاستبانات والنماذج السياحية إلى **ملف مشروع قابل للعرض والتحسين** داخل SENSE Experience. لا يُعامل كنموذج Google، ولا كطلب تمويل، ولا كاعتماد رسمي.

## قرار المنتج

لا نطلب من صاحب المشروع إعادة تعبئة استبانة طويلة لكل استخدام. يُنشئ ملفًا واحدًا، ثم تعيد المنصة استخدامه في أربع مخرجات مختلفة:

| المخرج | الاستخدام |
|---|---|
| بطاقة العرض العامة | تعريف الزائر بالتجربة دون كشف بيانات حساسة أو وعود غير متحققة. |
| ملخص المقابلة | أسئلة قصيرة ومباشرة للتحضير لمقابلات الشركاء أو الباحثين. |
| مخطط قصة WordPress | عنوان، زاوية تحريرية، فقرات، وأفكار صور قابلة للتحرير قبل النشر. |
| خريطة فجوات التمويل | ما يحتاجه المشروع من توثيق أو تطوير قبل تقديمه إلى برنامج أو تحدٍ. |

## طبقات الملف

### 1. الهوية والعرض

- اسم المشروع أو العلامة.
- البلدية والموقع.
- القطاع السياحي: ثقافي، طبيعي، زراعي، طعام، صحي، ديني، تعليمي، إقامة أو غيره.
- الخدمات: إقامة، طعام، نقل، جولات، أنشطة خارجية، ورش، منتجات محلية، فعاليات أو برامج تفسيرية.
- وصف قصير للتجربة.

### 2. المكان والوصول

- وجود تراث ثقافي أو طبيعي أو ميزة تمييزية أخرى.
- تفاصيل الموقع التي يمكن نشرها.
- قيود الوصول: المواصلات، المشي، ذوو الإعاقة، اللغة، الموسم، السلامة.
- ما يجب أن يعرفه الزائر قبل الوصول.

### 3. القدرة التشغيلية والجودة

- عدد العاملين وحجم التشغيل بشكل تقريبي.
- موسم العمل.
- وجود إجراءات جودة.
- آلية جمع رضا الزوار.
- وضوح الحجز والسعة والأسعار ووقت الاستجابة.

### 4. الاستدامة والابتكار

- الطاقة، الماء، النفايات، البلاستيك، التوريد المحلي، وحماية المكان.
- الشهادات أو الأنظمة، إن وجدت، مع منع الادعاء غير الموثق.
- التجارب أو المنتجات الجديدة التي جُرّبت.
- ما الذي يجعل الحل قابلًا للتنفيذ وليس فكرة فقط.

### 5. الوصول الرقمي والتسويق

- موقع رسمي.
- قنوات التواصل الاجتماعي وحجم الحضور بصورة تقريبية.
- الإدراج في بوابات السياحة.
- التسويق الرقمي.
- الحجز أو طلب التواصل الإلكتروني.
- المواد التي يمكن تحويلها إلى قصة أو مقابلة أو صفحة WordPress.

### 6. الجاهزية للمشروع والتمويل

- المشكلة أو الحاجة التي يعالجها المشروع.
- الفئة المستفيدة.
- دليل الطلب أو العملاء أو الزوار.
- نموذج الإيرادات والتكاليف الأساسية.
- نقطة التعادل أو منطق الاستدامة المالية.
- الفريق والمهارات والشركاء.
- المراحل والنتائج القابلة للقياس.
- المخاطر وما يحتاج تحققًا.

## طريقة احتساب الجاهزية

النسخة الأولية تستخدم سبع عدسات متساوية الوزن، وكل عدسة تسجل من 0 إلى 4:

| الدرجة | المعنى |
|---:|---|
| 0 | غير معروف أو غير موجود. |
| 1 | فكرة أو وصف أولي. |
| 2 | ممارسة جزئية أو دليل محدود. |
| 3 | ممارسة واضحة يمكن شرحها وإثباتها. |
| 4 | ممارسة موثقة وقابلة للتكرار والتحسين. |

النتيجة الإجمالية لا تعني اعتمادًا أو شهادة. هي مؤشر توجيهي:

- **0–34%**: قصة تحتاج تأسيسًا.
- **35–59%**: مشروع في طور البناء.
- **60–79%**: جاهزية عرض أولي.
- **80–100%**: جاهزية قوية للمراجعة، لا للنشر التلقائي.

## قواعد الخصوصية والثقة

- لا تُحفظ أرقام الهواتف أو أرقام الهوية أو بيانات مالية تفصيلية في النسخة العامة.
- لا تُعرض حالة «موثق» إلا إذا وُجد دليل ومراجعة مستقلة.
- لا تنتج المنصة وعدًا بالسعر أو التوافر أو الحجز دون تكامل تشغيلي فعلي.
- يمكن تصدير المخرجات كمسودات، لكن يظل النشر إلى WordPress أو أي قناة خارجية خطوة تحريرية منفصلة.
- تبقى بيانات السياحة منفصلة عن بيانات البلاغات والبلديات في Urban‑Sense.

## كيف نستخدم نتائج الاستبانات المرفقة؟

استبانة ريادة الأعمال تغذي طبقات المشكلة، السوق، التمويل، التدفق النقدي، نقطة التعادل، الفريق، والمخاطر. استبانة العمال تغذي وضوح الأجر، إثبات المهارة، الاتفاق الإلكتروني، الثقة، الشكاوى، وحماية البيانات عند بناء فرص العمل أو الخدمات. نموذج التدويل السياحي يغذي القطاعات، التراث، الوصول، الحجم، العملاء، الجودة، رضا الزوار، الاستدامة، الابتكار، التسويق، الحجز، البوابات، والاتصالات. تحدي الابتكار يغذي مكوّن الفريق، الدافع، الأثر، النموذج الأولي، الالتزام، والإقرار.

## الاستخدام المقترح في SENSE

1. يبدأ المزود بملف قصير لا يتجاوز دقائق قليلة.
2. يحصل فورًا على درجة إرشادية وثلاث فجوات ذات أولوية.
3. يراجع بطاقة العرض العامة قبل النشر.
4. يستخدم ملخص المقابلة في الاجتماعات.
5. ينسخ مخطط القصة إلى WordPress بعد التحرير البشري.
6. يضيف الأدلة لاحقًا بدل إعادة تعبئة البيانات.

هذه هي الطريقة التي نستفيد بها من النماذج: **نحوّلها إلى طبقة تشغيل وإظهار جودة، لا إلى عبء إداري جديد.**

## المرحلة الجديدة: مخرجات قابلة للحفظ والمشاركة

أصبح جواز المشروع ينتج ملفات محلية مباشرة من واجهته. يمكن تنزيل المخرج الحالي بصيغة Markdown، نسخ النص إلى محرر WordPress بعد مراجعته، أو تنزيل الملف الكامل بصيغة JSON لاستكماله لاحقًا. يحفظ التطبيق التغييرات تلقائيًا في المتصفح بعد توقف قصير عن الكتابة، مع بقاء النشر الخارجي خطوة منفصلة تتطلب مراجعة وموافقة.
