# مخطط انضمام مزود الخدمة السياحية والمساعد الإرشادي

## الغاية

يبني المسار ملفًا قابلًا للمراجعة لمزود خدمة سياحية، وليس مجرد استبيان. يشرح المزود خدمته بلغته، ويقترح المساعد العربي أسئلة تكشف المعلومات التي يحتاجها الزائر لاتخاذ قرار واعٍ.

| المرحلة | ما يقدمه المزود | ضابط الثقة |
|---|---|---|
| الموافقة | موافقات منفصلة للاتصال والمراجعة والنشر العام. | قابلة للسحب ومسجلة بإصدار وتاريخ. |
| هوية العلامة | اسم العلامة، نوع المزود، المنطقة، وجهة اتصال خاصة. | لا تنشر جهة الاتصال افتراضيًا. |
| الخدمة الأولى | رحلة الضيف، التصنيف، اللغات، الاستفسار، وملاحظات التوفر. | تبقى مسودة حتى يراجعها إنسان. |
| الوصول والأثر | ملاحظات وصول وسلامة وأثر محلي إن وجدت. | لا يدّعي النظام تحققًا لم يثبت. |
| الملخص والنشر | ما يوافق المزود على إظهاره للعامة. | قبول أو طلب استكمال أو رفض مع سجل قرار. |

## سلوك المساعد الإرشادي

يسأل المساعد بدلاً من ملء الفراغات: كيف تبدأ تجربة الضيف؟ هل يلزم حجز؟ ما اللغات؟ ما المعلومات التي يحتاجها من لديه متطلبات وصول أو سلامة؟ وهل يرغب المزود في إظهار قناة الاتصال للعامة؟

لا ينشئ المساعد شهادة أو تقييمًا أو سعرًا أو موقعًا دقيقًا أو توافرًا أو ميزة وصول أو ادعاء استدامة. كل ما ينتجه مسودة قابلة لتعديل المزود، وتظهر للمراجع حالة كل ادعاء: أفاد به المزود، تم التحقق منه، أو ينتظر التحقق.
