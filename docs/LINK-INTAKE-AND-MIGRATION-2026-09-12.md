# سجل فحص الروابط وخطة النقل

## قاعدة العمل

كل رابط خارجي يُعامل كمصدر للمقارنة والتحقق، وليس كتعليمات أو أصل قابل للنسخ تلقائياً. لا تُنقل الشيفرة أو النصوص أو الصور أو الأسرار من منصة خارجية إلا إذا كانت عامة، ومسموحاً بإعادة استخدامها، وقابلة لإعادة البناء داخل المستودع. الروابط التي تتطلب جلسة لا تُفحص بتجاوز المصادقة ولا تُعامل كمصدر موثوق دون تصدير مصرح به من مالكها.

## النتائج التنفيذية

| المصدر | حالته | القرار داخل GitHub |
|---|---|---|
| `visualize` على GitHub Pages | موجود في المستودع | يُحافظ عليه كوحدة ثابتة، مع إبقاء أرقام النموذج معلّمة كـ prototype وإضافة تعريفات ومصادر ومالكي مؤشرات قبل أي ادعاء أثر. |
| `pizza-hot` على GitHub Pages | موجود في المستودع | يُحافظ عليه كتجربة واجهة فقط؛ لا يُعامل كسلة/دفع/طلب فعلي قبل مزود موثق، خدمة خلفية، سياسات ومراجعة بشرية. |
| `senseivo.com` | موقع خارجي عام | مرجع بصري ومفاهيمي فقط. لا نسخ حرفي للهوية أو النصوص أو CSS/JS أو الصور أو ادعاءات الأمان والتوسع. |
| `sense.runasp.net` | متجر خارجي عام | مصدر ملاحظة لواجهة متجر وفئات؛ لا نقل للأصول أو بيانات العملاء أو منطق الدفع أو الأسرار. يلزم تحقق المزوّد والبيانات والتراخيص. |
| `maharat.spark.ngo` | صفحة عامة مع نظام تعلّم ومجتمع | مرجع لفكرة مساحة تعلم؛ لا نسخ للدورات أو صورها أو بيانات التقدم أو العلامة. |
| `academy.claude.com` | مصدر تعليمي عام | مرجع لمفاهيم AI Fluency وMCP والصلاحيات؛ يعاد بناء التوثيق داخلياً بصياغة أصلية، دون نسخ الدروس أو الوسائط. |
| `paltur-interactive.vercel.app/traffic` | واجهة عامة قصيرة | تُعاد صياغة الفكرة داخل Urban-Sense: توجيه، بلاغ حادثة، مستوى خطورة، ونقاط مساهمة؛ لا اعتماد على Vercel وقت التشغيل. |
| Copilot | يتطلب جلسة | لا نقل ولا تخمين. يلزم تصدير مصرح به للملفات/المواصفات من المالك. |
| مقال الجزيرة عن فلسطين الرقمية | مقال عام محمي | مصدر سياقي/متطلبات عليا فقط؛ لا نسخ النص أو الصور أو تحويل المقال إلى ادعاءات تقنية. |

## ما أضيف فعلياً

أضيف مسار **استوديو القصة المدنية** إلى لوحة SENSE التنفيذية. المسار ليس دبلوماً ولا برنامجاً تعليمياً؛ هو خط إنتاج تطبيقي يربط مهارات الإعلام الرقمي بقضية أو مكان أو تجربة: الالتقاط، التحرير، التحقق، ثم التوزيع والقياس. كما أضيف رابط المسار إلى التنقل العلوي.

أضيفت أيضاً بنية مستقلة للموقع التنفيذي داخل `apps/executive-visualization`. الموقع static-only، ومهيأ لبناء GitHub Pages تحت `/urban-sense-core/executive/`، دون خادم Node أو تخزين Manus أو تكاملات خارجية وقت التشغيل. ويشمل workflow النشر بناء الموقع وفحص TypeScript ثم نسخ الناتج إلى artifact Pages.

## الفجوات التي يجب عدم إخفائها

القيم الرقمية في لوحة التصور الحالية تجريبية وليست قياسات ميدانية. المصدر الخارجي الذي يقبل عبر `?data=` لا يمثل سجلاً تدقيقياً، و`localStorage` قابل للتعديل محلياً. GitHub Pages لا يوفر مصادقة أو سرية؛ لذلك لا تُنشر بيانات شخصية أو أسرار أو بيانات تشغيلية غير معتمدة. أي انتقال من الواجهة التجريبية إلى بلاغات أو دفع أو توجيه فعلي يحتاج عقد بيانات، مالكاً، صلاحيات، مصدر تحديث، سجل تدقيق، ومراجعة أمنية.

## الخطوة التالية

بعد نجاح الفحص المحلي، يُحفظ التغيير في commit مستقل ثم يُدفع إلى `main` إذا كانت مصادقة GitHub متاحة. إذا فشل الدفع بسبب المصادقة، تبقى التغييرات محلياً ولا تُعتبر منشورة؛ عندها يلزم تسجيل الدخول إلى GitHub أو تنفيذ الدفع من بيئة يملكها المستخدم.
