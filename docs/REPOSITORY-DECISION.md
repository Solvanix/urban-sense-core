# قرار المستودع المرجعي

اعتبارًا من 23 أغسطس 2026، يعد **`Solvanix/urban-sense-core`** المستودع المرجعي الوحيد لتطوير منظومة SENSE الحالية.

| المستودع | القرار | السبب |
|---|---|---|
| `urban-sense-core` | مستودع العمل المرجعي | يضم تطبيق `apps/sense-experience` الفعلي، وعقود الانضمام، وقاعدة بيانات المراجعين، واختبارات الحوكمة. |
| `sense-hub` / «مركز الاستشعار» | لا تطوير جديد | مستودع خاص أُنشئ أثناء الاستكشاف وكرر جزءًا من نطاق الموقع ومسار المزوّد. لا يعد مصدرًا مرجعيًا لهذه المنظومة. |
| `sense-experience-platform` | لا تطوير جديد | مستودع خاص موجود، لكن فرعه الحالي لا يحمل التطبيق الفعلي. |

لا تنقل التغييرات أو تدمج أو تحذف المستودعات غير المرجعية تلقائيًا. أي نقل لاحق لقطعة محددة يحتاج قرارًا من مالك المستودع ومراجعة فرق واضحة، مع الحفاظ على تاريخ Git والاختبارات وحدود البيانات.
