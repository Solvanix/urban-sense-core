# فهرس الروابط المنشورة — SENSE Visualizer والإعلام والمرور

آخر مراجعة: 14 سبتمبر 2026.

هذا الفهرس يجمع الروابط التي ظهرت في محادثات ومخرجات Manus أو تم التحقق منها عبر صفحات منشورة. الروابط التي تحمل بيانات نموذجية أو تجريبية موضحة بذلك، ولا تُعد قياسات ميدانية أو اعتمادًا مؤسسيًا.

## ملاحظة تشغيلية

المصدر الحالي يميز بين **نموذج الواجهة** و**النتيجة الموثقة**. قبل تقديم أي رقم أو ادعاء أثر، يجب تسجيل المصدر والمالك والتعريف وتواتر التحديث وسجل الموافقة. كما يجب عدم إدراج صور أو شهادات مولدة بالذكاء الاصطناعي بوصفها أدلة ميدانية.
