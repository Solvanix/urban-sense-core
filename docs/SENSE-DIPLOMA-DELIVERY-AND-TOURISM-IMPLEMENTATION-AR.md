# دليل تتبّع التسليم وتوظيفه في منصة SENSE السياحية

## الغرض

يوثق هذا الملف الانتقال من مشروع الدبلوم النهائي إلى تطبيق عملي داخل منظومة SENSE، ويساعد أي مشروع Manus لاحق على تتبع المصدر وفهم موقع الدبلوم وإتقان التسليم دون خلط المسودة بالتسليم النهائي.

## 1. سجل الدبلوم

بوابة الدبلوم:

```text
https://arabic-digital-media-diploma.tam-mansour.chatgpt.site/
```

المشروع: **SENSE — العيزرية ليست محطة عبور**

المشارك: **علي أحمد صالح خطيب**

رمز العودة المستخدم للمشروع: `AXXQZ-S62MN`

الحالة التي ظهرت في البوابة: **تم تسليم المشروع**.

حالة التأمل الفردي بعد الإكمال: **20/20 — تمت رحلتك**.

> الرمز `HUTDY-X8N5Q` ظهر لمسودة جديدة، وليس هو سجل التسليم الذي يجب الرجوع إليه.

## 2. مسار الوصول داخل الموقع

```text
FIN المشروع النهائي
→ ابدأ التسليم عبر الموقع
→ افتح المسودة/السجل المحفوظ
→ راجع الأقسام
→ المراجعة
```

التأمل الفردي:

```text
01 ابدأ التجربة أو FIN المشروع النهائي
→ رحلة التأمل الفردية
→ أجب عن الوقفات الأربع
→ الوقفة الأخيرة
→ أنشئ بطاقتي
→ نعم، هذا قريب من تجربتي
```

## 3. دليل الحالة الظاهر في الموقع

لقطة المتصفح المحفوظة أثناء التحقق تُظهر النصوص التالية:

```text
✓ تمت رحلتك
20 / 20
المشروع النهائي بيورجينا شو بنيت
MY HUMAN–AI JOURNEY
```

كما أظهرت البطاقة أن الذكاء الاصطناعي ساعد في فهم المشكلة وترتيبها وبناء الاستراتيجية، وأن القرار البشري بقي حاسمًا في تعديل الاقتراحات وتحديد ما لا ينبغي استخدامه.

## 4. المستودع التنفيذي الصحيح

المستودع المركزي:

```text
https://github.com/Solvanix/urban-sense-core
```

التطبيق السياحي الفعلي:

```text
apps/sense-experience/
```

أهم المسارات الموجودة:

```text
apps/sense-experience/src/ui/TourismPublicSite.tsx
apps/sense-experience/src/ui/TourismLaunchpadPage.tsx
apps/sense-experience/src/ui/TourismCampaignLabPage.tsx
apps/sense-experience/src/ui/ClaimRegistryWorkspace.tsx
```

أما `tourism/` فهو نسخة قديمة/تجريبية محفوظة كمرجع بصري، وليس مصدر المنتج الحالي. والمستودع `sense-experience-platform` منفصل واحتوى عند الفحص على README فقط، لذلك لا يُعامل كمصدر التنفيذ دون ملفات إضافية.

## 5. تحويل مشروع الحملة إلى تطبيق سياحي

| قرار الحملة | التطبيق العملي |
|---|---|
| العيزرية ليست محطة عبور | موقع اكتشاف يربط القصة بالمسار بدل قائمة معالم فقط |
| جواز رحلة من الزيتونة إلى الطريق والمغارة والاقتصاد المحلي | موقع عام وخطة يوم محلية قابلة للحفظ |
| لا نشر دون تحقق وموافقة | حالات مثل «قيد التحقق المحلي» و«بانتظار اعتماد المسار» وسجل ادعاءات |
| دعم أصحاب التجارب دون ادعاء اعتماد | `TourismLaunchpadPage` وملف جاهزية المزود |
| اختبار الفكرة قبل اعتمادها | `TourismCampaignLabPage` بأدوار استراتيجي وناقد ومحاكاة جمهور |
| فصل المدني عن السياحي | عزل `apps/sense-experience` عن `apps/web` وبيانات البلاغات المدنية |

## 7. الحدود التشغيلية

المنتج الحالي لا يدّعي حجزًا أو دفعًا أو توافرًا حيًا. طلب المراجعة في النسخة التجريبية مسودة آمنة، ولا يُنشر ملف مزود أو وسيلة اتصال عامة قبل موافقته ومراجعة بشرية. الأسعار والسعة والإتاحة والشراكات والادعاءات التاريخية غير المؤكدة تبقى بحالة واضحة حتى التحقق منها.

## 8. أوامر التحقق ونتيجتها

```bash
cd apps/sense-experience
pnpm check
pnpm test
pnpm build
```

نتيجة التحقق في 2026-09-16:

- TypeScript: ناجح.
- الاختبارات: 13 ملفًا و42 اختبارًا ناجحًا.
- Build: ناجح.
- التحذير الوحيد غير المانع: حجم حزمة JavaScript أكبر من 500 kB بعد التصغير.

## 9. قاعدة التسليم لأي مشروع Manus

1. افصل رابط التدريب عن رابط المنتج.
2. افصل رمز المسودة عن رمز التسليم.
3. أثبت الحالة من واجهة الموقع، لا من الذاكرة أو من وجود صفحة فارغة.
4. اربط كل قرار بحذره التشغيلي ومصدره.
5. حدّد المستودع والتطبيق والمسار قبل دفع الكود.
6. شغّل `check` و`test` و`build` قبل إعلان الجاهزية.
7. اذكر بوضوح ما تم تسليمه، وما بقي مسودة، وما يحتاج موافقة بشرية.

هذا الملف مرجع تشغيلي وتعليمي، وليس ادعاءً بأن الحجز أو الدفع أو الاعتماد المحلي مفعّل.

## فصل المشاريع قبل أي تقديم

مشروع SENSE هو مشروع سياحي/تحريري عن العيزرية وضواحي القدس، ويشمل القصص المكانية، WordPress، GitHub Pages، التحقق من المفهوم وفق UrbanUp، ومنتج SENSE Routes.

أما `docs/delivery/digital-marketing-electricity/` فهو مجلد مستقل لحملة دراسية بعنوان **ترشيد استهلاك الكهرباء وتقليل الهدر**. وجوده داخل المستودع لا يعني أنه جزء من SENSE، ولا يجوز استخدامه كدليل على تسليم SENSE أو تقديمه إلى تكنوبارك ضمن ملف UrbanUp.

حالة حزمة الكهرباء تبقى **Ready for Review** إلى أن تكتمل أسماء المشاركين وأدلة استخدام الذكاء الاصطناعي والتأملات الفردية وحقوق الأصول ورابط التسليم الرسمي. لا تُسمى **Submitted** قبل تنفيذ الإرسال وتسجيل التأكيد.
