# خط أساس الإتاحة المشترك

## الهدف العملي

تلتزم تطبيقات SENSE الجديدة بالتخطيط نحو **WCAG 2.2 مستوى AA** بوصفه هدفًا قابلًا للاختبار، لا شارة تسويقية. تغطي WCAG 2.2 محتوى الويب لمجموعة واسعة من احتياجات الإعاقة، وتؤكد أن الاختبارات الآلية لا تكفي وحدها؛ إذ تجمع الإرشادات بين معايير قابلة للاختبار وتقييم بشري.[1]

لا يبدأ المشروع ببناء «قارئ شاشة» بديل للمتصفح أو لنظام التشغيل. يبدأ بتحسين ما يصل إليه قارئ الشاشة الموجود بالفعل: HTML دلالي، تسلسل قراءة صحيح، أسماء عناصر واضحة، لوحة مفاتيح كاملة، ونصوص بديلة ومحتوى مفهوم. ويوفر دليل ARIA للمؤلفين أنماطًا وأمثلة للأدوار والحالات وواجهات لوحة المفاتيح، ويؤكد أهمية الأسماء والأوصاف والمناطق الدلالية.[2]

## القواعد المشتركة

| المجال | خط الأساس في كل تطبيق | دليل القبول |
|---|---|---|
| اللغة والاتجاه | `lang="ar"` و`dir="rtl"` في الصفحات العربية، مع تبديل واضح للغات. | تسلسل قراءة وعناوين وحقول صحيحة في RTL. |
| لوحة المفاتيح | كل رابط وزر وحقل ومسار متعدد الخطوات قابل للوصول والتنفيذ بالمفاتيح. | اختبار Tab وShift+Tab وEnter وEscape يدويًا. |
| الدلالة | عناصر HTML الأصلية أولًا؛ ARIA فقط عندما يحتاج مكوّن مخصص إلى وصف إضافي. | عناوين متسلسلة وأسماء برمجية للمدخلات والأزرار. |
| النماذج | تسمية ظاهرة لكل حقل، خطأ قابل للقراءة، وعدم طلب معلومات متكررة بلا سبب. | مراجعة تدفق إدخال كامل وقابل للتصحيح. |
| البصر والحركة | تباين كافٍ، تركيز مرئي، وعدم الاعتماد على اللون وحده، واحترام تفضيلات تقليل الحركة. | تدقيق آلي ومراجعة بصرية. |
| المحتوى والوسائط | نص بديل وصفي، نصوص مكتوبة للفيديو/الصوت حيث تنطبق، ولغة واضحة. | مراجعة محتوى قبل النشر. |
| الاختبار مع الناس | جلسات مراجعة مع مستخدمين ذوي خبرة مع تقنيات مساعدة قبل إعلان أي ميزة إتاحة كبيرة. | ملاحظات موثقة وقرارات إصلاح معلنة. |

## أدوات الإتاحة المستقبلية

تُبنى أدوات الإتاحة في موجتين. أولًا: حزمة مشتركة تفحص العناوين والأسماء واللغة والتركيز، وتوفر مكونات نماذج وسير خطوات قابلة للوصول. ثانيًا، وبعد بحث احتياجات ومشاركة مستخدمين، يمكن بناء أدوات مساعدة اختيارية مثل قارئ مبسط للمحتوى، تبديل أحجام النص، أو واجهة إعدادات وصول. لا تقدم هذه الأدوات نفسها كبديل لقارئات الشاشة الناضجة ولا تجمع بيانات إعاقة حساسة بلا موافقة واضحة.
