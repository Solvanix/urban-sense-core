# سجل واقع المدن في منظومة SENSE

**آخر مراجعة:** 23 أغسطس 2026.  
**الغرض:** منع الخلط بين مدينة نريد أن نخدمها أو ترد في قصة الفريق، وبين وجود بيانات أو منتج أو شراكة أو خدمة عاملة فيها.

> وجود اسم مدينة في الحديث أو في مادة مصدرية لا ينشئ ملفًا محليًا، ولا مزودًا، ولا متجرًا، ولا تفويضًا بلديًا، ولا حق جمع بيانات عنها.

## 1. قاعدة مشتركة لكل المدن

| المسار | ما هو موجود الآن | ما هو غير موجود لأي مدينة في هذا السجل |
|---|---|---|
| Urban-Sense | تطبيق بلاغات بلدية عامل في بيئة عرض، بدورة بلاغ وصلاحيات وأدلة وسجل تدقيق؛ يحتفظ بهويات ونطاقات بلدية مستقلة عند التشغيل | لا بلدية فعلية من عكا أو حيفا أو رام الله أو بيرزيت أو غزة أو نابلس أو سلفيت أو روابي موصولة بالخدمة، ولا بيانات مواطنين أو بلاغات محلية حقيقية لهذه المدن |
| SENSE Experience | نواة مستقلة لمسار اهتمام مزود ومراجعة مقيدة، وحقل منطقة عام داخل العقد | لا دليل سياحي محلي، لا مزودون منشورون، لا حجوزات أو تقييمات أو خرائط أو قوائم تجارب حقيقية لأي مدينة |
| المتجر | لا تطبيق متجر أو كتالوج أو دفع | لا منتجات، لا مخزون، لا طلبات، لا شحن، لا تسعير أو فواتير محلية |
| النمو والتعلم | رحلة عامة تفاعلية للنمو الفردي ثم التعاون الاختياري في بوابة SENSE؛ لا تجمع بيانات | لا دورات منشورة، لا تسجيل، لا مدربون، لا شهادات، ولا برنامج تابع لأي مدينة أو أكاديمية |
| التصنيع الرقمي | عقد بحثي لمسار تصميم → معاينة → مراجعة مشغل → G-code | لا مركز تشغيل، لا طابعة أو CNC أو ليزر موصول بالمنظومة، ولا وظائف تصنيع أو ملفات آلات محلية |

## 2. المدينة-بمدينة

| المدينة | ما بُني بالفعل لها | ما هو موجود كسياق أو مصدر فقط | ما لم يُبنَ أو يُعتمد |
|---|---|---|---|
| **عكا** | لا يوجد مكون، بيانات، أو رحلة محلية مخصصة | لا يوجد في سجل المصدر المركزي الحالي مصدر محلي مفهرس باسمها | لا دليل سياحي، مزودون، متجر، خدمة بلدية، دورات، أو مسار تصنيع محلي |
| **حيفا** | لا يوجد مكون، بيانات، أو رحلة محلية مخصصة | لا يوجد في سجل المصدر المركزي الحالي مصدر محلي مفهرس باسمها | لا دليل سياحي، مزودون، متجر، خدمة بلدية، دورات، أو مسار تصنيع محلي |
| **رام الله** | لا توجد خدمة بلدية أو سياحية أو تجارية محلية موصولة بالمدينة داخل SENSE | تظهر رام الله/سردا في وثيقة استراتيجية خاصة لأرض كنعان، وتوجد مواد تحريرية/بصرية سابقة خارج مسار المنتج؛ ليست بيانات تشغيلية | لا شراكة نافذة، لا برنامج تعلم مسجل، لا مزودون أو متجر أو قاعدة بيانات مدينة |
| **بيرزيت** | لا يوجد تكامل مع جامعة أو بلدية أو منصة محلية | تظهر في سياقات ومصادر سابقة فقط، من دون عقد تشغيل أو بيانات تطبيق | لا حسابات جامعة، لا دورات، لا خدمات طلابية، لا ملفات مشاريع أو تدريب منشورة باسمها |
| **غزة** | لا يوجد تطبيق محلي أو قاعدة بيانات أو مسار مزودين مستقل | ترد في قصة التوزع الجغرافي لفريق SENSE، لا كدليل أن خدمة منشورة تعمل فيها | لا بيانات مواطنين، لا بلدية شريكة، لا دليل سياحي/متجر/برنامج تعلم أو تصنيع محلي |
| **نابلس** | لا يوجد ربط تقني أو بلدية مشغلة أو بيانات مدينة داخل Urban-Sense | ملف تحديات خاص يصف مشكلة وضوح مسارات العمل في بلدية نابلس؛ استُخدم مرجع مشكلة لتحسين منطق التتبع فقط | لا ادعاء شراكة أو حل رسمي، ولا بلاغات حقيقية أو لوحة نابلس أو متجر أو دليل سياحي |
| **سلفيت** | لا يوجد مكون محلي في SENSE | وردت في مصدر عام خارجي حول تدريب مروري للشرطة، لا في منتج SENSE | لا برنامج شرطة، لا بلدية، لا منصة سياحية/تجارية/تعليمية محلية |
| **روابي** | لا يوجد مكون، بيانات، أو رحلة محلية مخصصة | لا يوجد في سجل المصدر المركزي الحالي مصدر محلي مفهرس باسمها | لا دليل مكان، مزودون، متجر، تكامل مدينة ذكية، أو خدمة بلدية محلية |

## 3. ما تستطيع البنية الحالية قبوله لاحقًا

لا يعني ذلك أن المدن خارج التصميم. البنية الحالية تستطيع استقبال توسع حقيقي فقط بالترتيب الصحيح:

1. **بلدية:** اتفاق تجربة، نطاق خدمة، مسؤول بيانات، حسابات بأدوار محلية، قاعدة إنتاج مستقلة، وسياسة أدلة وحذف؛ عندها يصبح Urban-Sense تطبيقًا محليًا فعليًا.
2. **تجارب/سياحة/حرف:** مزود حقيقي يوافق على المعالجة والمراجعة، ثم ملف مستقل ودليل للادعاءات قبل نشر بطاقة زائر؛ عندها يمكن إنشاء دليل مدينة بلا قوائم وهمية.
3. **تعلم وتمكين:** مالك محتوى ومدرب/مشغل وشروط برنامج وموافقة بيانات؛ عندها تتحول رحلة النمو العامة إلى اهتمام ثم قبول مقيد، سواء لفرد أو فريق.
4. **تصنيع:** موقع ومشغل وآلة ومادة وإجراءات سلامة وملف معاينة؛ عندها يتحول المخرج إلى مسار تصنيع لا إلى زر يرسل G-code تلقائيًا.
5. **تجارة:** كيان مشغل وكتالوج وحقوق صور ومخزون/تنفيذ ودفع وإرجاع؛ عندها فقط يصبح للمدينة منتجات أو طلبات حقيقية.

## 4. الفرق بين «جاهز للاستقبال» و«مبني للمدينة»

حقل المنطقة في SENSE Experience، وعقود الصلاحيات في Urban-Sense، ورحلة النمو العامة، هي **بنية قابلة لاستقبال مدينة أو فرد أو مزود لاحقًا**. ليست ملفات محلية ولا خدمات مشغلة للمدن المذكورة. لا ينشأ أي سجل باسم مدينة إلا من جهة حقيقية وافقت على نطاقها وبياناتها ومصدرها.
