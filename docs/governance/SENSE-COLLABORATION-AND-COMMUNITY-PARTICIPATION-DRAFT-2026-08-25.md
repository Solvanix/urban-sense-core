# مسودة اتفاق تعاون ومشاركة مجتمعية للاستمرارية المدنية — SENSE

**الحالة:** مسودة مراجعة فقط؛ لا تنشئ التزامًا قانونيًا أو تفويضًا أو شراكة حتى تستكمل بيانات الأطراف والملاحق، وتراجع قانونيًا، ويوقعها ممثلون مخولون.
**الاستخدام:** لتنظيم تجربة مدنية محددة في المعرفة أو المهارة أو الإتاحة أو الذاكرة أو مراجعة نموذج.
**الحظر:** لا تستخدم مع الأمم المتحدة أو الأونروا أو للعمل في مرافقهما أو باسم أي جهة أممية أو على بياناتهما أو مستفيديهما.

## 1. بيانات الاتفاق

| البند | يستكمل قبل التوقيع |
|---|---|
| الطرف الأول | الاسم القانوني أو اسم العمل، العنوان، الممثل المخول والصفة |
| الطرف الثاني | الاسم القانوني/المجموعة/الخبير، وسيلة اتصال آمنة، والممثل المخول إن وجد |
| خلية الاستمرارية | مصدر، مهارة، وصول، ذاكرة، أو مختبر نموذج |
| المخرج المحدد | وصف قصير قابل للفحص وتاريخ مراجعة/انتهاء |
| حالة العلاقة | `consultation` أو `written_partner_agreement` أو `official_authorization` وفق السجل |
| الملاحق | نطاق، خطة بيانات وحذف، حقوق المخرج، ونفقات إن وجدت |

## 2. الغرض والنطاق

يتعاون الطرفان في **[مخرج استمرارية مدنية محدد]** لكي يبقى مصدر أو مهارة أو مسار وصول أو معرفة مجتمعية قابلة للاستعمال والمراجعة. لا يخول الاتفاق التمثيل أو التعاقد باسم الآخر أو جمع أموال أو إعلان شراكة أو استعمال اسم أو شعار أو بيانات خارج النطاق المكتوب.

| داخل النطاق | خارج النطاق دائمًا |
|---|---|
| أرشفة مصدر عام أو مادة يملك الطرف حقها | استقبال طلبات مساعدة أو تسجيل مستفيدين أو إدارة حالات |
| مخرج مهارة أو مراجعة نموذج أو واجهة معرفة متاحة | توزيع أو إحالة إنسانية بمقابل أو تقديم علاج/مأوى/حماية |
| تشاور محدود بموافقة وحق انسحاب | بيانات لاجئين أو عائلات أو صحة أو مال أو حماية أو سياسة حساسة |
| قرار نشر أو حجب موثق | عمل في مرفق أممي أو استعمال اسم/شعار جهة أممية |

## 3. حقوق القرار وواجبات الأطراف

يسمي كل طرف نقطة اتصال مخولة. يملك مجلس قرار SENSE حق وقف النشاط عند فقدان حق أو موافقة أو أمان أو عند محاولة تحويل التجربة إلى بديل إنساني. ويملك الطرف الثاني حق وقف استعمال مادته أو اسمه ضمن آلية الإنهاء.

| القرار | من يقترحه | من يعتمده | الدليل |
|---|---|---|---|
| تغيير النطاق | أي طرف | الطرفان كتابة | أثر التغيير في الوقت والبيانات والحقوق |
| قبول مخرج للنشر | مالك البرنامج | صاحب الحق + مراجع جودة | مصدر وحق استعمال وحالة علاقة |
| جمع أو تغيير مادة | مسؤول البيانات | مالك المادة والأطراف حسب السياسة | ضرورة وموافقة ومدة وحذف |
| استعمال الاسم/العلامة | أي طرف | صاحب الاسم كتابة | نص الاستعمال والوسيط والمدة |
| تعليق العمل | أي طرف أو مسؤول البيانات | يسجل في محضر قصير | ضرر أو حق مفقود أو خطر تمثيل |

## 4. المشاركة والموافقة

يُعرّف الهدف بلغة مفهومة قبل المشاركة. المشاركة اختيارية ولا تمنح عضوية أو تمثيلًا أو منفعة أو وظيفة أو توصية. تتضمن الموافقة الغرض ووسيط النشر واللغة والنسبة ومدة الحفظ وطريقة سحبها. الأصل هو عدم جمع روايات الصدمة أو وثائق العائلات أو بيانات اللاجئين أو المعلومات الصحية والمالية والسياسية الحساسة؛ أي استثناء يحتاج بروتوكولًا مستقلًا ومراجعة قانونية وحماية متخصصة خارج هذه المسودة.

## 5. البيانات والخصوصية والذاكرة

تخزن المادة، إن لزم، في المسار المخصص وبأقل وصول ومدة معلنة. لا تنقل بين Urban‑Sense وSENSE Experience والأرشيف. وتظل ذاكرة الاستمرارية في مستوى المصدر وحقه وسياقه، لا في مستوى ملفات الأفراد.

| نوع المادة | المعالجة | القيد |
|---|---|---|
| مصدر عام | يسجل بالرابط والتاريخ وحق الاستعمال | لا يعني علاقة أو تفويضًا |
| تشاور غير معرف | يلخص بموافقة ومن دون علامات شخصية | لا ينسب لجماعة كاملة |
| مادة أو مخرج يملكه المشارك | اتفاق نسبة واستعمال ومدة وحذف | لا يعاد استخدامه خارج النطاق |
| بيانات شخصية لازمة وغير حساسة | أقل قدر، وصول مقيد، حذف معلن | لا تسويق أو بناء ملف أو غرض ثانٍ |
| إنسانية/أسر/صحة/مال/حماية | خارج الاتفاق | لا تجمع ولا تخزن ولا تدمج |

## 6. المعرفة والملكية والاتصالات العامة

يبقى ما قبل الاتفاق ملكًا لصاحبه. يحدد الملحق الملكية الجديدة وحق الاستعمال والإسناد. لا تعني الإشارة إلى موقع أو جهة أو برنامج اعتمادًا أو شراكة. وكل رسالة عامة تراجع كتابيًا مع الطرف الذي يذكر اسمه أو مادته، وتلتزم بالحالة الواقعية في سجل العلاقات. لا تجيز المسودة تصريحًا سياسيًا أو دبلوماسيًا أو تفاوضيًا باسم المجتمع أو القيادة أو أي جهة دولية.

## 7. المقابل وتضارب المصالح

توثق أي أتعاب أو نفقات أو مساهمة عينية في ملحق مستقل. لا ينشئ الاتفاق تمويلًا أو عمولة أو منفعة مستقبلية مفترضة، ولا يتصل المقابل بإحالة إنسانية أو ببيانات مستفيدين أو بتبرعات باسم جهة أممية. يفصح كل طرف عن تضارب المصالح، ويستبعد منه صاحب القرار المتأثر عند الحاجة.

## 8. عدم التدخل في الأمم المتحدة والأونروا

لا ينشأ بموجب هذه المسودة وكيل أو منشأة أو حساب أو قاعدة أو تكامل أو سير عمل أو علامة أو حملة يلامس مرافق الأمم المتحدة أو الأونروا أو موظفيها أو مستفيديها أو عملياتها أو امتيازاتها وحصاناتها. تظل المواد الرسمية المتاحة مصدرًا عامًا ضمن شروطها؛ لا تتحول إلى علاقة أو تفويض أو تصريح تشغيل.

## 9. التعليق والإنهاء

يعلق العمل فورًا عند خطر على شخص أو نقص موافقة أو حق استعمال أو أمن بيانات أو محاولة إحلال خدمة إنسانية. ويجوز الإنهاء بإشعار **[عدد الأيام]** أو فورًا عند خرق جوهري. بعد الإنهاء يوقف استعمال الاسم والمواد الجديدة وترد أو تحذف المادة وفق خطة البيانات، مع حفظ الحد الأدنى اللازم لتوثيق قرار الإنهاء.

## 10. القانون والتوقيع

تحل الخلافات أولًا بحوار موثق بين نقطتي الاتصال، ثم بوسيط أو محامٍ يتفق عليه الطرفان. يحدد القانون الواجب التطبيق والاختصاص بعد تحديد الولاية والشكل القانوني ومراجعة قانونية مستقلة.
