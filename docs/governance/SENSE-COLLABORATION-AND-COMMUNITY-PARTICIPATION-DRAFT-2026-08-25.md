# مسودة اتفاق تعاون ومشاركة مجتمعية — مركز SENSE المقترح

**الحالة:** مسودة للمراجعة فقط؛ لا تنشئ التزامًا قانونيًا، ولا تفويضًا، ولا شراكة، ولا حقًا في الاسم أو البيانات أو التمويل ما لم تُستكمل بيانات الأطراف، ويوقعها مخولون، ويعتمدها مستشار قانوني مؤهل.  
**المرجع الحاكم:** [سجل العلاقات والصلاحيات](./RELATIONSHIP-AND-AUTHORIZATION-REGISTER-2026-08-25.md).

> تستخدم هذه المسودة لتنظيم علاقة محددة مع شريك محتمل أو مجموعة مجتمعية أو خبير/ة. لا تستخدم مع الأمم المتحدة أو الأونروا أو أي جهة أممية، ولا تفتح أي عمل في مرافقها أو باسمها أو ببياناتها أو مع مستفيديها.

## 1. بيانات الاتفاق

| البند | البيانات التي تستكمل قبل التوقيع |
|---|---|
| الطرف الأول | الاسم القانوني أو اسم العمل، العنوان، الممثل المخول، وصف الصفة |
| الطرف الثاني | الاسم القانوني/المجموعة/المشارك، العنوان أو وسيلة اتصال آمنة، الممثل المخول إن وجد |
| اسم المبادرة | اسم المسار أو التجربة المحددة فقط |
| تاريخ السريان والمدة | تاريخ البدء، تاريخ الانتهاء أو نقطة مراجعة، آلية التجديد |
| حالة العلاقة | `consultation` أو `written_partner_agreement` أو `official_authorization` وفق سجل العلاقات |
| المرفقات | نطاق عمل، سياسة بيانات، ميزانية إن وجدت، وسياسة استخدام الاسم/العلامة |

## 2. الغرض والنطاق

يتفق الطرفان على التعاون في **[وصف محدد وقصير للتجربة أو الاستشارة]** من أجل إنتاج **[المخرج المحدد]**. يقتصر النطاق على الأنشطة والمخرجات والمدة المبينة في الملحق (أ). ولا يخول هذا الاتفاق أي طرف لتمثيل الآخر، أو التعاقد باسمه، أو جمع أموال باسمه، أو استعمال اسمه أو شعاره أو بياناته خارج النطاق المكتوب.

| ضمن النطاق | خارج النطاق |
|---|---|
| بحث أو تصميم أو مراجعة أو اختبار محدد في الملحق | تشغيل خدمة عامة أو إنسانية أو مالية من دون تفويض وعقد مستقلين |
| مشاركة معرفة يملك الطرف حق مشاركتها | نقل أسرار أو بيانات شخصية أو وثائق عائلية أو ملفات مستفيدين |
| مخرج موثق قابل للمراجعة | تصريح صحفي أو حملة أو إعلان شراكة قبل موافقة مكتوبة |
| قرار قبول أو رفض مسبب | ضمان تمويل أو توظيف أو اعتماد أو شهادة أو نتيجة سوقية |

## 3. أدوار الطرفين وحقوق القرار

يلتزم كل طرف بتعيين شخص اتصال مخول وبديل عند الحاجة. يملك مجلس قرار SENSE حق إيقاف النشاط الذي يفتقد مصدرًا أو موافقة أو حماية بيانات أو شرط سلامة. ويملك الطرف الآخر حق رفض استعمال مادته أو اسمه أو وقف مشاركته ضمن آلية الإشعار أدناه.

| القرار | من يقترحه | من يعتمده | الدليل المطلوب |
|---|---|---|---|
| تعديل نطاق العمل | أي طرف | الطرفان كتابةً | وصف التعديل وأثره في البيانات والوقت |
| قبول مخرج للنشر | مالك البرنامج | الطرف ذو الحق في النشر + مراجع الجودة | دليل/مصدر وحق استعمال |
| فتح أو تغيير بيانات | مسؤول البيانات | مالك البيانات والطرفان حسب السياسة | ضرورة، موافقة، مدة، وصول وحذف |
| استعمال الاسم أو العلامة | أي طرف | صاحب الاسم/العلامة كتابةً | نص الاستعمال والسياق والمدة |
| تعليق أو إيقاف | مسؤول البيانات أو أي طرف | يثبت في محضر قصير | خطر أو نقص حق أو ضرر محتمل |

## 4. المشاركة المجتمعية والموافقة

إذا اشتمل النشاط على مشاركة أفراد أو مجموعات محلية، يكون الهدف واضحًا قبل الدعوة، وتقدم لغة مفهومة عن ما سيحدث وما سيستخدم. المشاركة اختيارية؛ ولا ترتب تلقائيًا عضوية أو تعيينًا أو منفعة أو توصية أو تمثيلًا.

يلتزم الطرفان بالحصول على موافقة مناسبة قبل تسجيل أي صوت أو صورة أو اقتباس أو مساهمة مكتوبة أو بيانات تعريف. وتحدد الموافقة: الغرض، ووسيط النشر إن وجد، واللغة، ونطاق النسبة، ومدة الحفظ، وطريقة السحب. لا تجمع هذه المسودة روايات صدمة أو ملفات عائلية أو بيانات لاجئين أو معلومات صحية أو مالية أو سياسية حساسة إلا عبر بروتوكول مستقل ومراجعة قانونية وحماية متخصصة؛ والأصل هو عدم جمعها.

## 5. البيانات والخصوصية والأمن

يلتزم الطرفان بمبدأ الحد الأدنى: يجمعان فقط ما يحتاج إليه نطاق محدد، ويخزنانه في قاعدة تخص المسار المعني، ويقيدان الوصول بحسب الدور، ويحددان تاريخ مراجعة وحذف. ولا تنقل بيانات Urban‑Sense إلى SENSE Experience أو العكس، ولا تستخدم بيانات المشاركة المجتمعية للتسويق أو الإحالة أو بناء ملف شخصي بلا موافقة مستقلة.

| نوع المادة | المعالجة الافتراضية | الحظر أو القيد |
|---|---|---|
| مصدر عام ورابط | يسجل في أرشيف المصادر مع حق الاستخدام | لا يحول إلى علاقة أو تفويض ضمني |
| ملاحظة تشاور غير معرفة | تلخص بعد موافقة، مع حذف العلامات الشخصية | لا تنسب لشخص أو مجتمع كلي من دون موافقة |
| دليل ادعاء خدمة | يحتفظ به مقيدًا للمراجع المخول | لا ينشر تلقائيًا أو يتحول إلى تقييم معلن |
| بيانات شخصية غير حساسة لازمة | تحفظ بأقل قدر ومدة معلنة | لا تستخدم لغرض ثان أو تنقل لمسار آخر |
| بيانات إنسانية/مستفيدين/أسر/صحة/مال | خارج نطاق الاتفاق | لا تجمع ولا تخزن ولا تدمج |

## 6. المعرفة والملكية والنسبة

يبقى ما كان يملكه كل طرف قبل الاتفاق ملكًا له. يبين الملحق (ب) ملكية كل مخرج جديد وحق استعماله ووسم المصدر. لا ينقل هذا الاتفاق ملكية تلقائية لاسم أو شعار أو نص أو صورة أو تصميم أو بيانات. ولا يعاد استخدام محتوى الطرف أو المجتمع خارج نطاقه إلا بعد إذن مكتوب منفصل.

لا تستخدم أسماء المواقع أو الجهات أو البرامج أو الشعارات بوصفها اعتمادًا أو شراكة. وعند الإشارة إلى مصدر عام، تكون الإحالة دقيقة وتذكر أن المصدر لا يساوي علاقة.

## 7. المقابل والتمويل والمصالح

تسجل أي تكلفة أو أتعاب أو تعويض مشاركة أو مساهمة عينية بوضوح في الملحق (ج). لا ينشئ الاتفاق وعدًا بتمويل أو عمولة أو منفعة مالية مستقبلية ما لم يذكر صراحة. ولا تتصل أي مبالغ بإحالة إنسانية أو ببيانات مستفيدين أو بتبرعات باسم جهة أممية أو بترتيب غير معلن لظهور مزود.

يفصح كل طرف عن أي تضارب مصالح معقول قبل بدء العمل. ويجوز لمجلس القرار طلب مراجع مستقل أو استبعاد صاحب المصلحة من القرار المتأثر.

## 8. الاتصالات العامة والتمثيل

تسبق أي رسالة عامة مراجعة خطية من الطرف الذي يذكر اسمه أو شعاره أو مادته. وتلتزم الرسالة باللغة المحددة في سجل العلاقات: مصدر عام، تشاور، اتفاق مكتوب، أو تفويض رسمي ضمن نطاقه. ولا تجيز هذه المسودة إصدار تصريحات سياسية أو دبلوماسية أو تفاوضية باسم المجتمع أو القيادة الرسمية أو أي جهة دولية.

## 9. الحماية وعدم التدخل في الجهات الأممية

لا ينشأ بموجب هذا الاتفاق أي نشاط أو حساب أو قاعدة أو مسار يمس مرافق الأمم المتحدة أو الأونروا أو موظفيها أو مستفيديها أو عملياتها أو امتيازاتها وحصاناتها. ولا تستخدم أسماؤها أو شعاراتها أو مصادرها في صياغة توحي بالشراكة أو التفويض أو الانتماء. تبقى المواد الرسمية المتاحة مصدرًا عامًا ضمن شروط استعمالها، لا أكثر.

## 10. التعليق والإنهاء والتعامل مع المواد

يجوز لأي طرف تعليق العمل فورًا عند خطر على شخص أو نقص جوهري في الموافقة أو حق الاستخدام أو أمن البيانات. ويجوز لأي طرف إنهاء الاتفاق بإشعار مكتوب مدته **[عدد الأيام]**، أو فورًا في حال خرق جسيم لا يمكن معالجته. عند الإنهاء، يوقف استعمال الاسم والمواد الجديدة، وترد أو تحذف البيانات وفق الملحق (د) وسياسة الحفظ، مع الاحتفاظ فقط بما يلزم قانونًا أو لتوثيق قرار الإنهاء.

## 11. تسوية الخلافات والقانون الواجب التطبيق

يسعى الطرفان أولًا إلى حوار موثق بين نقطتي الاتصال خلال **[عدد الأيام]**. فإن لم يحل الخلاف، يحال إلى **[وسيط/محامٍ/آلية محلية يتفق عليها الطرفان]**. يحدد القانون الواجب التطبيق والاختصاص القضائي بعد تحديد الولاية القضائية والشكل القانوني ومراجعة قانونية مستقلة؛ لا يترك هذا البند افتراضًا عند التوقيع.
