# خطة تشغيل مركز SENSE للاستمرارية المدنية — 30/60/90 يومًا

**الحالة:** خطة قرار داخلية قابلة للمشاركة؛ لا تعني إطلاق خدمة عامة أو إنسانية أو تأسيس مقر أو دخول علاقة مع أي طرف.
**المرجع:** [ورقة التأسيس](../SENSE-ENTITY-CREATION-PAPER-2026-08-25.md)، [التقرير المؤسسي](../SENSE-INSTITUTIONAL-STRATEGIC-REPORT-2026-08-25.md)، و[سجل أدلة الاستمرارية](../research/INSTITUTIONAL-CONTINUITY-EVIDENCE-2026-08-25.md).

> **هدف الدورة:** إثبات قدرة فريق صغير على تشغيل خلية استمرارية مدنية واحدة: مصدر أو مهارة أو وصول أو ذاكرة أو نموذج؛ من دون فتح استقبال مساعدات أو إدارة حالات أو بيانات مستفيدين أو عمل في مرافق أممية.

## مبادئ الدورة

تبدأ الخطة من حقيقة أن الخدمات قد تستمر بصورة مقيدة ومتقطعة؛ لذلك لا تسمي نفسها بديلًا إنسانيًا. تبني ما يستطيع المجتمع امتلاكه وتشغيله ضمن الحق: معرفة موثقة، مهارة قابلة للنقل، مسار رقمي متاح، تشاور بموافقة، ومخرج موثق. كل مخرج يحتاج مالك قرار، وحق استعمال، وحد حذف، وقدرة إيقاف.

| المبدأ | التطبيق الملزم |
|---|---|
| الاستمرارية لا الإحلال | لا تستقبل مساعدة أو توزعها أو تدير مأوى أو عيادة أو إحالة مقابل منفعة |
| مصدر قبل الادعاء | كل واقعة أو رقم أو اسم له رابط وتاريخ وحالة ثقة، أو يبقى محجوبًا |
| أصغر بيانات ممكنة | لا تجمع بيانات أفراد إلا إذا كانت ضرورية وغير حساسة وموافقًا عليها ومحددة الحذف |
| مسار واحد | لا يعمل الفريق في عدة أزمات أو مواقع أو برامج خلال الدورة الأولى |
| الإتاحة قبل التوسع | العربية، لوحة المفاتيح، وضوح الخطوة، وبديل منخفض البيانات متطلبات قبول |
| حق الإيقاف | يوقف مالك القرار أو مسؤول البيانات أي نشاط يفقد حقًا أو موافقة أو أمانًا |

## اختيار خلية واحدة

| الخلية | تجربة أولى مناسبة | خارج النطاق |
|---|---|---|
| مرصد المصدر والحق | سجل محدود لمصادر عامة موثقة حول موضوع أو خدمة | ملفات عائلية أو معلومات عن مستفيدين أو مرافق حساسة |
| مسار المهارة | مخرج فردي قصير مع معيار مراجعة | شهادة أو توظيف أو تدريب باسم شريك بلا إذن |
| الوصول والإتاحة | صفحة عربية خفيفة لمسار معرفة واضح ومحدث | وعد عبور أو حماية أو خدمة ميدانية |
| الذاكرة والمعرفة | فهرس مصدر/تاريخ/حق لمادة يملكها المشارك | مقتنيات أو صور أشخاص أو روايات صدمة بلا بروتوكول حماية |
| مختبر النموذج | مواصفة ومراجعة نموذج خدمة محلية | تشغيل الخدمة أو جمع مزودين أو عملاء أو أموال |

| الأسبوع | المخرج | معيار القبول | شرط الإيقاف |

| 1–2 | مجلس قرار: مالك تجربة، بيانات/حقوق، جودة، إتاحة | أدوار وحق إيقاف ونصاب قرار محفوظة | غياب مالك مسؤول أو تضارب غير معالج |
| 2 | مراجعة سجل المصادر والواقع | كل ادعاء له تاريخ ونطاق أو وسم `unverified_claim` | إدراج رقم أو خبر غير موثق في خطاب عام |
| 2–3 | اختيار خلية واحدة ونطاق مخرج واحد | منفعة مدنية واضحة وبيانات قليلة ومشغل محتمل إن لزم | اختيار مسارات متوازية أو قضية إنسانية تشغيلية |
| 4 | ورقة نطاق وقرار بيانات | الغرض، المخرج، المشاركة، الحذف، الإتاحة، ونهاية التجربة | حاجة إلى بيانات مستفيدين أو عمل في مرفق أممي |

### بوابة اليوم 30

لا ينتقل الفريق إلا إذا كان يستطيع شرح التجربة بجملة واحدة: «سننتج **[مخرجًا مدنيًا محددًا]** عبر **[نطاق محدود]** مع **[مالك قرار]**، ومن دون **[نوع تدخل أو بيانات محظورة]**.» عند العجز عن هذه الجملة يبقى العمل بحثًا وأرشفة.

## الأيام 31–60: تصميم لا يضاعف الضرر

| الأسبوع | المخرج | معيار القبول | شرط الإيقاف |
|---|---|---|---|
| 5 | رحلة وصول أو بروتوكول مخرج | نقطة دخول وخروج وحالة انسحاب واضحة | فرض معلومات أو اتصال لا حاجة له |
| 5–6 | بروتوكول مشاركة مجتمعية | موافقة، حق سحب، نسبة، استعمال، حذف | اعتبار المشاركة تمثيلًا لمجتمع كامل |
| 6 | سجل أدلة ومراجعة ادعاءات | مراجع جودة مستقل عن صاحب الادعاء | تحويل قول ذاتي إلى حقيقة منشورة |
| 6–7 | مراجعة إتاحة وخصوصية | عربية، لوحة مفاتيح، بيانات أقل، وصول مقيد وحذف | مسار مربك أو خطر أو يكشف شخصًا بلا حاجة |
| 7 | محاكاة داخلية بمادة عامة أو اصطناعية | اجتياز المخرج بلا جمع أفراد أو اتصال خارجي | خلط قواعد Urban‑Sense وSENSE Experience أو الأرشيف |
| 8 | قرار جاهزية محدود | قبول مشروط أو رفض مسبب | غياب حق استعمال أو مشاركة أو مشغل مطلوب |

### بوابة اليوم 60

تظل العلاقة مع المجتمع أو الخبير في `consultation` ما لم يظهر اتفاق مكتوب. وتبقى الجهات الأممية والأونروا في `public_source` و`blocked` تشغيليًا؛ لا تفتح هذه الخطة علاقة معها أو مسارًا في مرافقها.

## قرار اليوم 90

تختار المؤسسة تكرار خلية واحدة محسنة، أو توسعًا محدودًا بعقد مناسب، أو توقفًا موثقًا. ولا يفتح التسجيل أو المقر أو الحملة العامة إلا إذا ظهر التزام تشغيلي ثابت يبرر مراجعة قانونية ومحاسبية مستقلة.
