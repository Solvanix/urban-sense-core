# سجل العلاقات والصلاحيات — مركز SENSE للاستمرارية المدنية

**الحالة:** سجل حوكمة داخلي؛ لا ينشئ حقوقًا أو علاقات قانونية بذاته.
**القاعدة:** لا يخرج اسم جهة أو مكان أو مجتمع أو برنامج إلى واجهة أو عرض أو رسالة خارجية إلا بحالة ودليل ومالك وتاريخ مراجعة في هذا السجل.

## قاموس الحالات الملزم

| الحالة | تعريفها العملي | اللغة المسموح بها | ما يحظر |
|---|---|---|---|
| `official_authorization` | تفويض مكتوب يحدد النطاق والمدة والبيانات والمسؤولية | «مفوض ضمن نطاق محدد» | تعميم أو توسيع التفويض |
| `written_partner_agreement` | اتفاق موقع يحدد الأدوار والحقوق والبيانات والإنهاء | «شراكة» ضمن الاتفاق فقط | تمثيل الشريك أو تفويض عام |
| `consultation` | حوار محدد الغرض مع موافقة على استعماله | «تشاورنا مع» عند موافقة الطرف | نسبة تأييد أو عضوية أو تمثيل |
| `public_source` | مادة عامة موثقة برابط وتاريخ | «مصدر رسمي/عام» | استعمال اسم أو شعار كأنها علاقة |
| `unverified_claim` | قول أو رقم أو رواية بلا تحقق كافٍ | سؤال بحثي داخلي فقط | نشره كحقيقة أو أساس تشغيل |
| `blocked` | نشاط أو علاقة يفتقد حقًا أو حماية أو بنية | شرح سبب الحجب داخليًا | تنفيذه أو تسويقه |

## قاعدة نموذج الاستمرارية المدنية

لا تسمى الاستمرارية المدنية «بديلًا للأونروا» أو «خدمة إنقاذ» أو «شبكة إغاثة». تعمل SENSE في المعرفة والمهارة والوصول والذاكرة والنمذجة. وكل ما يمس المساعدة أو المستفيدين أو المرافق أو التشغيل الإنساني يبقى `blocked` حتى لو كانت الحاجة عالية.

## السجل الأولي

| الطرف أو المجال | الحالة | اللغة المسموح بها | المالك | خطوة التغيير |
|---|---|---|---|---|
| خلايا الاستمرارية المدنية داخل SENSE | `blocked` تشغيليًا حتى اعتماد دورة 90 يومًا | «نموذج مقترح قيد الاختبار الداخلي» | مجلس القرار | ميثاق، مالك تجربة، نطاق وقرار بيانات |
| البلديات والجهات العامة | `blocked` | «نواة قابلة للتقييم لخدمة عامة» | مجلس القرار | تفويض رسمي للبيانات والاستضافة والنطاق |
| مزودو SENSE Experience | `blocked` | «لا دليل مزودين عام مفتوح» | مالك SENSE Experience | موافقة ومراجع وسياسة احتفاظ وتشغيل مستقل |
| الأمم المتحدة/الأونروا | `public_source` و`blocked` تشغيليًا | «مصدر أممي رسمي» | مسؤول المصادر والحقوق | خارج هذه الخطة؛ أي علاقة تحتاج تفويضًا رسميًا مستقلًا |
| مركز تدريب قلنديا | `public_source` | «منشأة تدريب أممية نشطة وفق بيان الأونروا» | مسؤول المصادر والحقوق | إذن مكتوب مستقل قبل أي تعاون أو استعمال اسم/صور/موقع |
| مخيمات جنين وطولكرم ونور شمس | `public_source` | «سياق موثق للإغلاق والتهجير والوصول المقيد» | مسؤول المصادر والحقوق | لا يفتح برنامجًا أو جمع بيانات؛ أي مشاركة تحتاج بروتوكولًا واتفاقًا مناسبًا |
| المجتمع المحلي والخبراء | `blocked` | «مشاركة مقترحة بالموافقة» | مالك البرنامج | بروتوكول مشاركة وحقوق نشر وحذف |
| القيادة الرسمية والقوى السياسية | `blocked` | «أطراف في بيئة القرار العامة» | مجلس القرار | دعوة أو تفويض أو تشاور موثق |
| جهات دبلوماسية أو دولية | `public_source` / `blocked` | «مصدر عام» | مجلس القرار | اتصال مخول أو اتفاق؛ لا ادعاء دعم |
| مادبا/جهات السياحة الأردنية | `public_source` | «عدسة بحث لحق المصدر والتجربة المحلية» | مسؤول المصادر والحقوق | اتفاق جهة مخولة قبل حضور أو تشغيل |

## حماية الأمم المتحدة والأونروا

استنادًا إلى اتفاقية امتيازات وحصانات الأمم المتحدة، يحظر السجل على SENSE إنشاء أو تشغيل وكيل أو منشأة أو حساب أو قاعدة أو تكامل أو سير عمل أو نظام استقبال أو حماية أو علامة أو حملة أو ادعاء خدمة يلامس مقار الأمم المتحدة أو الأونروا أو أصولها أو أرشيفها أو موظفيها أو مستفيديها أو تقديمها للمساعدة. تستخدم بياناتها الرسمية مصدرًا عامًا فقط، ولا تتحول إلى إذن أو علاقة أو تفويض.[1]

## مراجعة وتصعيد

يراجع مجلس القرار السجل قبل النشر أو العرض أو أي اتصال خارجي. يبقى كل صف `unverified_claim` أو `blocked` خارج الخطاب العام. وعند تعارض رغبة تسويقية مع حق الطرف أو سلامته أو تفويضه، يتقدم الحق والسلامة ويبقى النشاط محجوبًا.
