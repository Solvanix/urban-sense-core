## نموذج الأدوار: طبقتان لا تختلطان

### أدوار حساب المنصة

| الدور | ما يستطيع فعله | ما لا يمنحه |
|---|---|---|
| `citizen` | استخدام مسار الزائر/المواطن ضمن حدود الخدمة الفعّالة | إدارة الحسابات أو المستودع أو نطاق بلدية أخرى |
| `developer` | وصول تقني حسب دعوة GitHub ودوره، ويمكن أن يمنح حسابًا تشغيليًا منفصلًا عند الحاجة | إدارة المنصة أو أسرار الخادم تلقائيًا |
| `platform_admin` | إدارة الحسابات وحالات تفعيلها والأدوار عبر `?view=access` مع تسجيل تدقيقي | تعطيل حساب المالك أو خفض دوره، أو مشاركة كلمة مرور إدارية |

### أدوار دورة العمل البلدية

هذه مسؤوليات عمل داخل تجربة البلدية وليست حسابًا موحدًا لمنظومة SENSE كلها:

| المسؤولية | المسار العملي |
|---|---|
| المواطن | تقديم بلاغ ومتابعته ضمن البلدية المشاركة |
| موظف الخدمة | مراجعة البلاغ وتصنيفه وإسناده |
| الفريق الميداني | تنفيذ المهمة وإضافة الأدلة |
| المشرف | التحقق من الإنجاز والإغلاق قبل إتاحة التقييم |

## الإتاحة وذوو الاحتياجات

المدخل العام والبوابة يدعمان العربية RTL، وتحتوي البوابة التفاعلية على خياري **تباين أعلى** و**تقليل الحركة**. كما يفرض خط أساس الإتاحة استخدام HTML دلالي، ووصول لوحة المفاتيح، وتركيز مرئي، واحترام تفضيلات تقليل الحركة. لا يوجد بعد منتج مستقل لقارئ الشاشة أو تطبيق متخصص؛ أي خدمة من هذا النوع تحتاج بحث مستخدمين وموافقة ونطاقًا مستقلاً قبل إعلانها كخدمة متاحة.

## ما الذي اكتمل، وما الذي لم يكتمل؟

### مكتمل في هذه المرحلة

1. أصبح المستودع عامًا، وأصبح الفهرس العام منشورًا في GitHub Pages.
2. أصبح الفهرس يقود إلى المسارات الحية الصحيحة بدل روابط داخلية لا يمكن لموقع GitHub Pages تشغيلها.
3. يوجد تطبيق Urban‑Sense قابل للبناء والاختبار، ونجحت فحوص النوع والبناء و34 اختبارًا بعد اختبار روابط الفهرس.
4. توجد حزمة تشغيل Docker ودليل تسليم للفريق ومسار OIDC اختياري للتشغيل المستقل.

### غير مكتمل بعد

1. تشغيل حزمة Docker على خادم رسمي تملكه الجهة وربطها بدومين وTLS وهوية وقاعدة إنتاج مستقلة.
2. نشر SENSE Experience كخدمة مستقلة مزودة بهوية مراجعين وتسجيل مزودين حقيقيين.
3. بناء المتجر والمدفوعات والمحاسبة والكتالوج الحقيقي وسياسات الإرجاع.
4. بناء أدوات إتاحة متخصصة أو منتجات موجهة لذوي الاحتياجات تتجاوز أساس الإتاحة الموجود.
5. تشغيل الرؤية الحاسوبية أو YOLO في الميدان؛ ما زال هذا مسارًا بحثيًا مقيدًا بالترخيص والموافقة.

## الخطوة التشغيلية التالية

إذا كان الهدف هو مشروع وظيفي مستقل عن Manus، فالخطوة ليست إنشاء صفحة جديدة؛ بل **اختيار خادم باسم الجهة وتشغيل `apps/web/ops/bootstrap-server.sh` عليه** من نسخة GitHub، ثم تهيئة OIDC وقاعدة MySQL والنطاق الرسمي خارج Git. عند نجاح ذلك يصبح رابط هذا الخادم هو بوابة Urban‑Sense الرسمية، بينما يبقى GitHub Pages فهرسًا عامًا للمسارات والوثائق.
