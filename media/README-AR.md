# حزمة الوسائط التوضيحية — SENSE

**الحالة:** أصول مولدة بالذكاء الاصطناعي لأغراض التصميم والتحرير التوضيحي فقط.

هذه الصور لا تثبت شكل موقع محدد، ولا تمثل أشخاصًا أو ورشًا أو خرائط حقيقية، ولا يجوز تقديمها على أنها تصوير ميداني للعيزرية أو دليل على حالة الوصول أو التوفر.

## قاعدة النشر

- يوضع وسم واضح: **صورة توضيحية مولدة بالذكاء الاصطناعي — ليست تصويرًا ميدانيًا**.
- تستبدل الصورة بصور ميدانية مرخصة عند توفرها.
- لا تستخدم الصورة الثالثة لعرض ازدحام أو طريق أو حدود أو نقطة جغرافية حقيقية.
- لا تستخدم الصورة الثانية لإثبات وجود حرفي أو منتج أو سعر أو مصدر.
- لا تنشر أي صورة داخل WordPress قبل توفر صلاحية التحرير والمراجعة التحريرية.
