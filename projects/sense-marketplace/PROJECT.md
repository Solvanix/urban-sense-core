# SENSE Marketplace

## المهمة

منتج تجارة مستقل لعرض منتجات أو خدمات حقيقية وبيعها ضمن مشغل واضح ومسؤوليات تشغيلية ومالية معلنة.

| البند | الوضع الحالي |
|---|---|
| المصدر التنفيذي | غير موجود. |
| الكتالوج | لا توجد منتجات أو مخزون أو حقوق صور أو أسعار تشغيلية داخل المستودع. |
| الدفع والمحاسبة | غير مفعّلان؛ لا Stripe ولا Shopify ولا نظام فواتير أو إرجاع. |
| حالة المنتج | مشروع مقترح، لا متجر حالي. |

## أول شريحة إطلاق

فئة واحدة من منتجات حقيقية، مشغل متجر محدد، صور وحقوق استخدام، كتالوج مملوك، سياسة دفع وإرجاع، اختيار تكامل متجر، وحسابات تشغيلية. لا يبدأ من تصميم واجهة أو بطاقات تجريبية.

## بوابة القرار التالية

تسمية المشغل التجاري وتحديد نوع البيع والكتالوج الأول، ثم اختيار Shopify أو بديل بموافقة صريحة قبل تهيئة أي دفع.
