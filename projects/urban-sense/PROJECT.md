# Urban‑Sense

## المهمة

منصة بلاغات بلدية عربية تدير رحلة البلاغ من إدخاله إلى المراجعة والإسناد والدليل والتحقق والإغلاق، مع أدوار ونطاق بلدي وسجل تدقيق.

| البند | الوضع الحالي |
|---|---|
| المصدر التنفيذي | [`apps/web/`](../../apps/web/) |
| العرض الحالي | [بوابة Urban‑Sense في بيئة العرض](https://urbansense-dzfbcdz5.manus.space/?view=urban) |
| حالة المنتج | تطبيق وظيفي في بيئة عرض مُدارة؛ ليس نشرًا رسميًا مملوكًا للجهة بعد. |
| البيانات | مخطط MySQL وتشغيل منفصل عن SENSE Experience. لا توجد بيانات تشغيلية في GitHub. |
| فحوص المصدر | `pnpm check && pnpm test && pnpm build` من `apps/web/` |

## أول شريحة إطلاق رسمية

بلدية تجريبية واحدة، مستخدمون حقيقيون بأدوار مفعلة، خادم مملوك للجهة، MySQL مُدار، OIDC، تخزين أدلة، نسخ احتياطي، نطاق وTLS، ثم دورة بلاغ مكتملة موثقة. لا يكفي وجود رابط عرض أو حزمة Docker وحدهما.

## بوابة القرار التالية

اختيار خادم مملوك للجهة ومزود هوية ونطاق رسمي، ثم تنفيذ تشغيل Docker الأول وتوثيق فحص الصحة قبل فتح تجربة بلدية فعلية.
