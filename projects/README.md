# Projects — محفظة SENSE التشغيلية

هذا المجلد يربط كل مشروع بمصدره التنفيذي، وميزته الحالية، وخلفيته، ومسار تشغيله. كود التطبيقات يبقى في `apps/`؛ هنا يجد الفريق القرار الذي يفتح الشريحة التالية، وطريقة التحقق منها.

| المشروع | المصدر | ما يعمل الآن | الخلفية أو الاعتماد التالي |
|---|---|---|---|
| Urban‑Sense | [`apps/web/`](../apps/web/) | بلاغ مواطن، مراجعة، إسناد، أدلة، تحقق، إغلاق، سجل تدقيق. | خادم جهة مالكة، MySQL مُدار، OIDC، وتفعيل بلدية تجريبية. |
| SENSE Experience | [`apps/sense-experience/`](../apps/sense-experience/) | واجهة مزود، مرجع متابعة خاص، قرار مراجع مسبب، و`/healthz` مع حزمة MySQL مستقلة. | OIDC مستقل، أول مراجع مفعّل، سياسة بيانات، ونطاق خدمة قبل فتح القبول. |
| موقع فريق SENSE | لا يوجد مصدر تطبيق بعد | مهمة إطلاق محددة: تعريف الفريق، المنتجات، والتواصل. | اعتماد الاسم والدومين ومحتوى الفريق وصلاحيات النشر. |
| SENSE Marketplace | لا يوجد مصدر تطبيق بعد | مهمة إطلاق محددة: فئة كتالوج واحدة ومسار طلب. | مشغل تجارة، منتجات حقيقية، حقوق صور، سياسة تنفيذ ودفع. |
| SENSE Learning & Provider Enablement | لا يوجد مصدر تطبيق بعد | مهمة إطلاق محددة: مسار واحد يرفع جاهزية مزود حقيقي. | رابط المنهج، حقوق الاستخدام، وصاحب برنامج واضح. |

## قاعدة العمل

كل مشروع جديد يبدأ بميزة قابلة للاختبار، مصدر بيانات محدد، مالك تشغيل، وشرط قبول. يضاف رابط العرض بعد أن يمر المسار الكامل: **بيانات حقيقية أو مدخلة بموافقة → خدمة خلفية → واجهة → اختبار → تشغيل محدود**.
