# Projects — مداخل المشاريع الفعلية في SENSE

هذا المجلد هو طبقة **المشاريع** في المستودع: كل مشروع له تعريف مستقل، وحدود، ومصدر كود، وحالة تشغيل، وأول شريحة إطلاق قابلة للاختبار. لا يعيد هذا المجلد نسخ كود التطبيقات الموجودة في `apps/`؛ فنسخ المصدر في مكانين يربك البناء والنشر. بدلًا من ذلك، يربط كل سجل بالمصدر التنفيذي الحقيقي ويحجز لكل منتج جديد مساحة مشروعه الخاصة.

> لا يعني وجود مجلد مشروع أن الخدمة مطلقة. حالة كل مشروع مكتوبة صراحةً داخل سجلّه وفي [صفحة المشاريع العامة](https://solvanix.github.io/urban-sense-core/projects/).

| المشروع | سجل المشروع | مصدر التنفيذ الحالي | الحالة الصريحة |

| Urban‑Sense | [الملف](./urban-sense/PROJECT.md) | [`apps/web/`](../apps/web/) | تطبيق وظيفي في بيئة عرض مُدارة؛ يحتاج تشغيلًا رسميًا مملوكًا للجهة. |

| SENSE Marketplace | [الملف](./sense-marketplace/PROJECT.md) | لم يبدأ مصدر متجر مستقل | مشروع مستقل غير مبني بعد. |

## قاعدة التنفيذ

أي مشروع جديد يتجاوز مجرد توثيق الحالة يبدأ داخل مجلده هنا بسجل `PROJECT.md`، ثم يضيف مصدر التطبيق في مسار واضح يحدده الفريق، ويضاف له رابط تشغيل وفحوص واختبارات. المشاريع الموجودة أصلًا في `apps/` تبقى هناك إلى أن يقرر الفريق هجرة هندسية صريحة؛ لا تُنقل لمجرد تغيير الاسم أو تنظيم الشجرة.

لا يُضاف متجر أو كتالوج أو مزود أو تقييم أو شهادة تجريبية لتجميل أي مدخل مشروع. المسار هو: **قرار منتج → مصدر بيانات حقيقي → حوكمة → تنفيذ → اختبار → تشغيل محدود → نشر مسؤول**.
