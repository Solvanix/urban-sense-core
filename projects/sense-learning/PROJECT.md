# SENSE Learning & Provider Enablement

## المهمة

مسار تمكين مستقل يحول احتياجات المزود الحقيقية إلى خطوات تعلم وفعل ودليل تقدم، ولا يخلط التعليم بملف الزائر العام أو بمراجعة اعتماد.

| البند | الوضع الحالي |
|---|---|
| المصدر التنفيذي | غير موجود؛ يوجد فقط دليل جاهزية وتجارب إرشادية داخل SENSE Experience. |
| مصادر المنهج | استبانة CReSInMed محللة؛ رابط المسار السياحي المحدد لم يصل بعد. |
| حقوق المحتوى | لا تُنسخ مواد تدريبية خارجية أو تمنح شهادات قبل تحليل المصدر والإذن. |
| حالة المنتج | مشروع تمكين غير مبني بعد. |

## أول شريحة إطلاق

رحلة واحدة مقتضبة تختارها أولوية مزود حقيقية، هدف واضح، نشاط أو دليل إكمال، مراجعة إن لزم، وخصوصية بيانات المتعلم. لا تبدأ بمكتبة دروس أو نسب إنجاز شكلية.

## بوابة القرار التالية

تحليل المسار التعليمي الذي سيرسله المالك، ثم تحديد ما يمكن استلهامه أو ربطه وما يحتاج محتوى أصليًا قبل بناء أي وحدة.
