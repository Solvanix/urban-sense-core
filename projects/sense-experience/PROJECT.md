# SENSE Experience

## المهمة

خدمة مستقلة لمزودي التجارب والخدمات: تبدأ بطلب اهتمام محدود، ثم دعوة إلى ملف خاص، ومراجعة أدلة، وموافقة نشر منفصلة قبل ظهور أي ملف للزائر.

| البند | الوضع الحالي |
|---|---|
| المصدر التنفيذي | [`apps/sense-experience/`](../../apps/sense-experience/) |
| معاينة الفكرة | [دليل الميزات في المصدر](../../apps/sense-experience/src/ui/SurveyFeatureGuidePage.tsx) |
| حالة المنتج | نواة واجهة وAPI ومخطط `sx_*` واختبارات؛ غير منشورة لخدمة مزودين حقيقية. |
| بيانات عامة | لا يوجد مزودون منشورون أو حجوزات أو تقييمات أو شهادات مصطنعة. |
| فحوص المصدر | `pnpm check && pnpm test && pnpm build` من `apps/sense-experience/` |

## أول شريحة إطلاق

برنامج صغير بدعوات حقيقية فقط: مراجعون مستقلون ذوو هوية مفعلة، قاعدة بيانات `sx_*` منفصلة، سياسة موافقة واحتفاظ وحذف، وطلب اهتمام حقيقي واحد على الأقل يمر بالمراجعة من دون نشر تلقائي.

## ما يغذيه الآن

استبانة CReSInMed تحولت إلى خريطة بيانات وميزات وخصوصية، لا إلى نموذج منسوخ. المسار التعليمي السياحي سيحدد لاحقًا رحلة التمكين الخاصة بالمزود، لا صفحات تدريب وهمية.

## بوابة القرار التالية

استكمال مصدر المنهج، اعتماد سياسة البيانات ومالك المراجعة، ثم اختيار مكان نشر مستقل للخدمة وقاعدتها قبل فتح الانضمام.
