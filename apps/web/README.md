# Urban‑Sense Core App

هذا المجلد يحتوي على التطبيق الكامل لمنصة البلاغات البلدية العربية. يتضمن React وExpress وtRPC وDrizzle وقاعدة البيانات وإدارة المستخدمين.

## النواة المنفذة

- واجهات عربية RTL للمواطن وطاقم العمليات.
- بلاغات ضمن نطاق بلدي مع دورة حالة محكومة على الخادم.
- أدوار: مواطن، موظف خدمة، عامل ميداني، مشرف، مدير بلدية، ومدير منصة.
- أدلة ميدانية قبل/بعد بتفويض رفع آمن.
- سجل تدقيق ملحق ببصمات SHA-256 لكشف العبث.
- اختبارات للتفويض ودورة البلاغ وسجل التدقيق.

## أوامر التطوير

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
```

لا تُرفع ملفات `.env` أو التبعيات أو مخرجات البناء إلى المستودع.
