# Urban‑Sense

> **منصة بلاغات بلدية عربية RTL.** هذا التطبيق هو المنتج المنشور حاليًا داخل منظومة SENSE، ويعالج دورة البلاغ من التقديم إلى التحقق والإغلاق ضمن صلاحيات ونطاق بلدي محكوم.

[العودة إلى فهرس رحلة المستخدم](../../INDEX.md)

## روابط سريعة

| الوجهة | الرابط أو المصدر | الحالة |
|---|---|---|
| الموقع العام | [urbansense-dzfbcdz5.manus.space](https://urbansense-dzfbcdz5.manus.space/) | منشور |
| بوابة SENSE الموحدة | [/?view=sense](https://urbansense-dzfbcdz5.manus.space/?view=sense) | منشورة؛ هذا هو رابط النشر المستقر |
| المكوّن المصدر للبوابة | [`client/src/pages/SensePortal.tsx`](client/src/pages/SensePortal.tsx) | موجود ومختبر |
| منطق الرابط | [`client/src/lib/sensePortalRoute.ts`](client/src/lib/sensePortalRoute.ts) | موجود ومختبر |
| اختبارات البوابة | [`client/src/pages/SensePortal.test.ts`](client/src/pages/SensePortal.test.ts) | موجودة |

> تستخدم البوابة العامة الاستعلام `?view=sense` لأن بيئة النشر تخدم الجذر باستقرار، بينما لا تعيد توجيه جميع المسارات الفرعية لتطبيق SPA بصورة مضمونة. يظل `/sense` مفيدًا في التطوير المحلي، لكنه ليس رابط النشر العام المعتمد.

## ما الذي يعمل الآن؟

تتضمن النواة المنفذة واجهات عربية RTL للمواطن وفريق العمليات، ودورة بلاغ محكومة على الخادم، وتفويضًا حسب الدور والنطاق البلدي، وأدلة قبل/بعد عبر مسار رفع آمن، وتحقق مشرف، وإغلاقًا مضبوطًا، وسجل تدقيق ملحق ببصمات SHA‑256. تتوفر أيضًا صفحات عامة لشرح سير العمل، والبلديات، والدعوة التجريبية، وبوابة SENSE القائمة على المسارات والأدوار.

| المسار العام | الغرض |
|---|---|
| `/` | صفحة Urban‑Sense العامة. |
| `/?view=sense` | بوابة SENSE الموحدة المنشورة. |
| `/كيف-تعمل` | شرح دورة البلاغ وحدود الاستخدام. |
| `/للبلديات` | توضيح مسار البلدية والأدوار. |
| `/التجربة` | دعوة تجريبية صادقة ضمن نطاق محدد. |
| `/بلاغ-جديد` و`/بلاغاتي` | مسارات المواطن بحسب حالة الدخول والنطاق. |
| `/?view=operations` أو `/العمليات` | عمليات البلدية؛ محمية بالدور والنطاق. |

## ما لا يفعله Urban‑Sense

Urban‑Sense **ليس** منصة سياحة أو متجرًا أو بوابة دفع أو نظام محاسبة أو مساعدًا ذكيًا متصلًا أو خدمة كاميرات حية. كما لا تُنشأ تقييمات مواطنين أو بلاغات أو مزودون اصطناعيون لإظهار تقدّم ظاهري؛ التقييمات الحقيقية تنتظر تجربة تشغيلية حقيقية.

## البنية التقنية

| الطبقة | التقنية أو الموضع |
|---|---|
| الواجهة | React + TypeScript + Tailwind، العربية RTL وخط Cairo داخل `client/src/`. |
| الخادم | Express + tRPC داخل `server/`. |
| البيانات | Drizzle مع MySQL/TiDB، ومخطط وترحيلات مستقلة للتطبيق. |
| الهوية | Manus OAuth وإجراءات خادم محمية بحسب الدور والنطاق. |
| الاختبارات | Vitest لمسارات الصلاحيات ودورة البلاغ والبوابة. |

## الجودة والتطوير المحلي

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
pnpm dev
```

لا تُرفع أسرار البيئة أو ملفات `.env` أو `node_modules` أو مخرجات البناء. وتُراجع أي تعديلات تتعلق بالبلاغات أو الصلاحيات أو التحولات قبل دمجها؛ فالأمن ومسؤولية السجل جزء من المنتج لا تحسين لاحق.
