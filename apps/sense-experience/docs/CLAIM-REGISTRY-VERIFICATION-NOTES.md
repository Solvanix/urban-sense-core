# ملاحظات تحقق حي — سجل الادعاءات

**التاريخ:** 23 أغسطس 2026

تم فتح المسار `/سجل-الادعاءات` في معاينة Vite الحية. ظهرت واجهة عربية قابلة للوصول تتضمن رقم متابعة ورمز وصول خاصين، نوع الادعاء، تصريح المزوّد، مرجع دليل خاص، ملخص دليل، وأزرار منفصلة لحفظ المسودة محليًا أو الإرسال للمراجعة أو فتح قائمة المراجعة.

استخدم الفحص بيانات تركيبية محلية فقط: رقم متابعة تجريبي، رمز تجريبي، تصريح وصول أولي، ومرجع دليل محلي. لم يُنقر زر الإرسال، ولم تُرسل هذه القيم إلى خادم أو قاعدة بيانات. تؤكد واجهة الفحص بصريًا ونصيًا أن مرجع الدليل لا يظهر للزائر، وأن مسار المراجع يتطلب جلسة مراجع مخوّل ولا ينشئ صفحة عامة.

ما زال التحقق التشغيلي الكامل — تقديم فعلي، إضافة دليل، مراجعة عبر هوية OIDC، وتطبيق ترحيل MySQL — محجوبًا عمدًا إلى حين إعداد قاعدة بيانات SENSE Experience مستقلة واعتماد قبول البيانات الحقيقية.
