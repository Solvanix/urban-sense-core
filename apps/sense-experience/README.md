# SENSE Experience

تطبيق مستقل داخل المستودع المركزي لمنصة مزودي الخدمات والتجارب السياحية العربية. لا يقرأ أو يكتب بيانات تطبيق Urban‑Sense للبلاغات البلدية.

## النواة الحالية

تعرّف النواة عقد انضمام مزود، وموافقات منفصلة، وادعاءات قابلة للمراجعة، وقاعدة نشر تمنع ظهور بيانات الاتصال أو الادعاءات غير المتحققة للعامة. وتضم الآن معاينة ويب عربية لمسار المزود والدعوة التجريبية وواجهة مراجعة توضح حالة ما أفاد به المزود وما تحقق منه، إضافة إلى منطق قرار مراجع واختبارات تمنع تجاوز الدور أو النشر الخفي أو اعتبار تسجيل الاهتمام ملفًا عامًا.

## أوامر الجودة

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm test
pnpm build
```

## الحدود

لا توجد قاعدة بيانات أو مزودون أو حجوزات أو مدفوعات حية في هذه النواة. يضاف ذلك لاحقًا بترحيلات مستقلة ومراجعة خصوصية وشركاء فعليين.
