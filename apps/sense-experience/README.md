# SENSE Experience

تطبيق مستقل داخل المستودع المركزي لمنصة مزودي الخدمات والتجارب السياحية العربية. لا يقرأ أو يكتب بيانات تطبيق Urban‑Sense للبلاغات البلدية.

## النواة الحالية

تعرّف النواة عقد انضمام مزود، وموافقات منفصلة، وادعاءات قابلة للمراجعة، وقاعدة نشر تمنع ظهور بيانات الاتصال أو الادعاءات غير المتحققة للعامة. وتضم الآن معاينة ويب عربية لمسار المزود والدعوة التجريبية، ومخزن اهتمام محليًا في المتصفح، ولوحة مراجعة محلية تفرض سببًا وقرارًا صريحين. كما تضم اختبارات تمنع تجاوز الدور أو النشر الخفي أو اعتبار تسجيل الاهتمام ملفًا عامًا.

تضيف الواجهة العامة ثلاث صفحات تصورية قابلة للعرض: `/` بوابة «مكان · مسار · أثر»، و`/اكتشف` لبنية دليل التجارب المستقبلية، و`/للشركاء` لشرح الموافقات والمراجعة وحدود النشر. لا تعرض هذه الصفحات مزودين أو تقييمات أو أسعارًا أو حجوزات؛ فالتصنيفات فيها بنية منتج فقط حتى توجد ملفات مزودين حقيقية ومراجعة مستقلة.

## أوامر الجودة

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm test
pnpm build
```

## الحدود

لا توجد قاعدة بيانات أو حسابات مراجعين أو مزودون أو حجوزات أو مدفوعات حية في هذه النواة. مخزن المتصفح مناسب لمعاينة تدفق واحد على جهاز واحد فقط، ولا يجوز استخدامه مع بيانات مزودين حقيقية. يضاف التخزين التشغيلي لاحقًا بترحيلات مستقلة، وخدمة مستقلة، ومراجعة خصوصية، وشركاء فعليين. لا يعني ظهور «المتجر» أو «الدليل» في رؤية المنتج أن أيًا منهما أصبح خدمة تشغيلية.

تتضمن النسخة الآن مخطط Drizzle وترحيل SQL وخدمة tRPC/Express مستقلة، لكنها مقفلة افتراضيًا. راجع [`REAL-DATA-READINESS.md`](../../docs/sense-experience/REAL-DATA-READINESS.md) قبل ضبط أي متغير بيئة أو تطبيق أي ترحيل.
