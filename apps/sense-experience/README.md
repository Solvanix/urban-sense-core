# SENSE Experience

> **تطبيق عربي مستقل لمسار مزودي الخدمات والتجارب والمراجعة البشرية.** يشارك Urban‑Sense المستودع ومعايير الجودة فقط؛ ولا يقرأ أو يكتب بلاغاته أو مستخدميه أو أدواره أو قاعدة بياناته.

[العودة إلى فهرس رحلة المستخدم](../../INDEX.md)

## المنتج الحالي بصراحة

| المجال | الحالة |
|---|---|
| الواجهة العامة ومسار الجاهزية | موجودان في الكود وقابلان للتشغيل محليًا. |
| اكتشاف المسارات وخطة اليوم | موجودان في الواجهة العامة مع حفظ محلي ومسودة طلب مراجعة آمنة. |
| API، مخطط البيانات، وترحيلات الخدمة | موجودة داخل التطبيق وبحدود مستقلة. |
| هوية المراجع وعقد أدواره | موجودان في الكود مع قيود وتدقيق مستقلين. |
| سجل الادعاءات والأدلة والمراجعة | موجود في الكود والاختبارات؛ ترحيله مولّد ولم يطبق، ولا يقبل بيانات حقيقية بعد. |
| رابط إنتاج مستقل | غير موجود بعد. |
| استقبال بيانات مزودين حقيقية | غير مسموح قبل تشغيل مستقل وهوية مراجع نشطة وضوابط احتفاظ وموافقة جاهزية مكتوبة. |
| دليل عام حقيقي أو حجوزات أو أسعار أو تقييمات | المسارات الحالية مقترحة وموسومة بحالة التحقق؛ لا يوجد حجز أو سعر أو توافر حي. |

## التشغيل والمسارات المحلية

| المسار | الغرض | الحد التشغيلي |
|---|---|---|
| `/` | منصة SENSE السياحية: صورة المكان، المسارات، وخطة اليوم. | محتوى مقترح واضح الحالة؛ لا توافر حي. |
| `/اكتشف` أو `/discover` | دليل المسارات والفلاتر. | يحفظ اختيارات الزائر محليًا. |
| `/حجزي` أو `/booking` | خطة اليوم ومسودة طلب المراجعة. | لا إرسال خادمي ولا دفع نهائي في النسخة التجريبية. |
| `/للشركاء` أو `/partners` | تعريف أصحاب التجارب بمسار الشراكة. | يبدأ من `/انضم` عند تفعيل الخدمة المستقلة. |
| `/جواز-المشروع` أو `/tourism-readiness` | ملف جاهزية سياحية قابل لإعادة الاستخدام. | يحفظ محليًا ويولد بطاقة عرض، مقابلة، قصة WordPress، وفجوات تطوير. |
| `/انضم` أو `/providers` | مسار انضمام/جاهزية مزود. | لا يُعامل كفتح تسجيل إنتاجي. |
| `/مراجعة` | واجهة قائمة المراجعة. | يتطلب إعداد هوية مراجع مستقلة عند التشغيل الفعلي. |
| `/سجل-الادعاءات` أو `/claims` | مسودة ادعاء/دليل خاصة وطابور مراجعة مقيد. | لا رفع ملفات ولا نشر تلقائي ولا بيانات حقيقية قبل التفعيل. |

## الفصل عن Urban‑Sense

لا يوجد حساب موحد، ولا قاعدة بيانات مشتركة، ولا وصول مشترك إلى البلاغات أو عضويات البلديات. أي عملية قبول أو مراجعة أو نشر في SENSE Experience يجب أن تستخدم هوية ومخزنًا وسجل تدقيق وعقد بيانات خاصًا بالخدمة.

## البنية داخل هذا المجلد

| الموضع | الغرض |
|---|---|
| `src/ui/` | الموقع العام، الدعوة، وتجربة واجهة الجاهزية. |
| `src/onboarding/` | عقود ومسار انضمام ومراجعة مزودين. |
| `server/` | Express/tRPC، هوية المراجع، وخدمات المراجعة المستقلة. |
| `drizzle/` | مخطط وترحيلات قاعدة البيانات الخاصة بالخدمة. |
| `tests/` | اختبارات الانضمام، المسارات، المراجعة، الهوية، ومنع تجاوز الصلاحيات. |

## الجودة والتشغيل المحلي

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build
pnpm dev
pnpm dev:api
```

قبل إضافة متغيرات بيئة أو تطبيق ترحيلات أو إدخال بيانات حقيقية، راجع بوابات الجاهزية أدناه. لا تستخدم التخزين المحلي أو إعدادات التطوير مع بيانات مزودين حقيقية.
