# Pizza hot — نسخة مستقلة

هذه نسخة Manus مستقلة وظيفياً من نموذج Pizza hot الذي بُني داخل Stunning. تعمل كواجهة ثابتة بلا خادم أو أسرار: يمكن فتح `index.html` مباشرة أو تشغيلها عبر خادم ملفات محلي.

## التشغيل المحلي

```bash
cd apps/pizza-hot
python3 -m http.server 4173
# افتح http://localhost:4173
```

لا تستخدم `file://` لأن المتصفح قد يمنع تحميل `catalog.json` عبر `fetch`.

## الوظائف الحالية

تتضمن النسخة صفحة مزود عربية، كتالوج Pizza hot، الأسعار المؤكدة، سلة محلية، نموذج طلب للمراجعة البشرية، ومساعداً نصياً يجيب من الكتالوج ولا يخترع بيانات التوصيل أو المكونات أو ساعات العمل. المنتجات التي لا يوجد لها سعر موثق تظهر بعبارة «يحتاج تأكيد» ولا يمكن إضافتها إلى السلة.

## المصدر والحدود

المصدر المرجعي للكتالوج هو [SENSE Store — Pizza hot — Provider ID 10](https://sense.runasp.net/Providers/Details/10). الأسعار المسجلة في `catalog.json` تحتاج اعتماد المزود قبل اعتبارها بيانات تشغيلية. العنوان، الهاتف، ساعات العمل، منطقة التوصيل، المكونات، الحساسية والمخزون ما زالت حقول تحقق.

## ما يلزم قبل الإنتاج

هذه النسخة لا ترسل WhatsApp ولا تنفذ دفعاً ولا تخزن الطلبات على خادم. قبل الإنتاج يجب إضافة API وقاعدة بيانات، مصادقة للمالك، مسار موافقة بشرية، سياسة خصوصية، تكامل توصيل، ومفاتيح بيئة تُحفظ خارج GitHub.

## النشر

يمكن نشر المجلد كصفحة ثابتة عبر GitHub Pages أو أي استضافة ملفات ثابتة. تشغيل الطلبات الفعلي يحتاج Backend منفصلاً؛ لا ينبغي اعتبار نموذج السلة الحالي نظام طلبات إنتاجياً.
