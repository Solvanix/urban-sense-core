## كيف تختار المدخل الصحيح؟

ابدأ من [بوابة SENSE الموحدة](https://urbansense-dzfbcdz5.manus.space/?view=sense) إذا كان هدفك فهم المسارات والأدوار. اذهب إلى Urban‑Sense عند العمل على البلاغات البلدية. اذهب إلى SENSE Experience عند العمل على مسار مزودي الخدمات والتجارب؛ وهو مسار مستقل يحتاج تشغيلًا وموافقة جاهزية قبل استقبال بيانات حقيقية.

## قاعدة الفصل

أي تغيير يربط التطبيقين يحتاج عقد تكامل موثقًا وموافقة أمنية وتشغيلية. لا تُنقل بلاغات المواطنين، أو عضويات البلديات، أو هويات المراجعين، أو بيانات المزودين بين التطبيقين عن طريق قاعدة مشتركة أو صلاحيات مشتركة.

## التحقق المحلي

يشغّل كل تطبيق أوامر الجودة من مجلده الخاص، لا من جذر المستودع:

```bash
cd apps/web && pnpm check && pnpm test && pnpm build
cd ../sense-experience && pnpm check && pnpm test && pnpm build
```

راجع [`../docs/README.md`](../docs/README.md) لخريطة الوثائق والقرارات وبوابات التشغيل.
