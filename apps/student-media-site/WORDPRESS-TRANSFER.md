# الانتقال إلى WordPress

هذه الصفحة هي نقطة الانتقال بين نسخة الموقع المحفوظة في GitHub وموقع WordPress الذي تُكتب فيه التقارير والقصص.

## الروابط

- **نسخة الواجهة والتصميم:** [مجلد student-media-site](https://github.com/Solvanix/urban-sense-core/tree/main/apps/student-media-site)
- **خطة WordPress:** [WORDPRESS-GRADUATION-PLAN.md](../../docs/editorial/WORDPRESS-GRADUATION-PLAN.md)
- **الموقع التحريري المتوقع:** [salehmasharq06.wordpress.com](https://salehmasharq06.wordpress.com)
- **لوحة WordPress:** [wordpress.com/home](https://wordpress.com/home)

## كيف نستخدم المسارين؟

يُحفظ هنا التصميم، وخطة العمل، وقوالب المقالات، وبيانات المصادر. أما WordPress فهو مكان إدخال التقرير أو القصة، رفع الصورة، تضمين الفيديو، إضافة الرابط التشعبي، معاينة المقالة، ثم نشرها.

```text
GitHub
  ↓ يجهز النص والمصادر والوسائط
WordPress
  ↓ يحرر المقال ويعاينه
نشر القصة
```

## قالب النقل

قبل نقل أي مادة إلى WordPress، نملأ البيانات التالية:

```text
عنوان القصة:
اسم الطالب:
التصنيف:
المقدمة:
المصدر أو المقابلة:
رابط المصدر:
الصورة وحقوقها:
الفيديو أو رابط YouTube:
الرابط التشعبي داخل النص:
حالة المادة: مسودة / جاهزة للمعاينة / منشورة
رابط WordPress بعد الحفظ:
```

## ملاحظة عن الوصول

لا يمكن إنشاء مسودة WordPress من هذه الجلسة إلا إذا ظهر الموقع ضمن قائمة المواقع التي يملكها حساب WordPress المتصل. إذا كان الموقع لا يظهر، يجب الدخول بالحساب الذي يملك الموقع أو إضافة الموقع إلى الحساب المتصل، ثم إعادة المحاولة. لا نضع كلمات المرور أو مفاتيح الوصول داخل هذا المستودع.
