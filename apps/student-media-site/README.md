# منصة الإعلام الرقمي الطلابي

نموذج موقع عربي RTL مستوحى من خطة `docs/editorial/WORDPRESS-GRADUATION-PLAN.md`.

## المحتوى

- واجهة مجلة صحفية عربية باسم «صوت التلميذ».
- قصص طلابية عن رام الله وطولكرم والخليل وحكايات المكان.
- تصفية القصص حسب المنطقة.
- قسم مشاريع الطلاب ومختبر الوسائط الستة.
- نافذة معاينة للمقالات وروابط المصادر.
- تصميم متجاوب للهاتف وسطح المكتب.

## التشغيل

```bash
pnpm install
pnpm dev
```

هذا التطبيق هو نسخة واجهة مستقلة للتجربة والتطوير. WordPress يبقى مسار التحرير والنشر، بينما يحفظ GitHub مصدر الواجهة والوثائق.
