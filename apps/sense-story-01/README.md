# sense-story-01

نسخة GitHub من موقع القصة العربي الذي بُني أولًا في Manus WebDev، ثم نُقلت مصادره إلى مستودع `urban-sense-core`.

## ما نُقل

يحتوي هذا المجلد على مصدر React وملفات المحتوى والتنسيق الخاصة بموقع «حين يصبح الطريق سؤالًا». استُبعدت ملفات `node_modules` و`dist` و`.project-config.json` وملفات الأسرار عمدًا.

الأصول الإعلامية الكبيرة المرتبطة بالقصة والتقرير موجودة في:

`docs/content-samples/media/`

## التشغيل المحلي

```bash
pnpm install
pnpm check
pnpm build
pnpm dev
```

هذا الموقع واجهة تحريرية/قصصية، وليس مصدرًا مستقلًا لإثبات الوقائع. يجب أن تبقى المواد المولدة أو التوضيحية موسومة بوضوح، وأن تُستبدل بالصور والتسجيلات الميدانية المرخصة عند اكتمال البحث.
