محطات المنظومة

الحالة قبل الوعد.

مسار الاستقلال أداة شخصية محليةخطة تفاعلية للحركة والدراسة والعمل والإبداع والسكن؛ لا تشخيصات أو إرسال أو حجز أو إحالة.Urban‑Sense منشوربلاغات بلدية عربية بدورة عمل وصلاحيات وسجل تدقيق.SENSE Experience صفحات عملية محليةاستديو تجربة وخطة وصول ومسودة ادعاء؛ لا بيانات مزودين أو API إنتاجية بعد.مساكن الخير تجربة تشغيلية محليةمساحات فريق ومالك وخطة تجربة؛ لا قوائم مساكن أو طلبات أو وعود تمويلية قبل اعتماد الحوكمة.السوق والمتجر مقترحلا مدفوعات أو كتالوج حي أو حسابات تجارية الآن؛ راجع لوحة التقدم قبل افتراض الجاهزية.الدومين والبريد قيد قرارلا نطاق أم أو بريد مهني جديد مربوط قبل اعتماد المالك وفحصه.
