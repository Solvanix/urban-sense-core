# SENSE Routes

هذه النسخة العامة على GitHub Pages هي طبقة اكتشاف سياحي وتوثيق، وليست نظام حجز أو اعتمادًا بلديًا.

## مصدر البيانات

تقرأ `index.html` البيانات من [`data/routes.json`](data/routes.json) عبر `app.js`. الإصدار الحالي من العقد هو `1.1.0`.

كل مسار يحتوي على:

- `contentStatus`: حالة المحتوى التحريري.
- `confidence`: مستوى الثقة ومصادرها.
- `access`: حالة الوصول والأدلة المطلوبة.
- `booking`: حالة الحجز وما إذا كان مجرد اهتمام أو غير متاح.
- `difficulty`: مستوى الصعوبة الإرشادي، وليس تصنيفًا ميدانيًا معتمدًا.
- `experienceType`: نوع التجربة المستخدم في التصفية.
- `nextEvidence`: الخطوة التالية المطلوبة قبل رفع مستوى الوعد.

## SENSE Quest — مغامرة البطاقات

يحتوي `data/routes.json` على نموذج أولي لمغامرة من أربع بطاقات: سؤال لمضيف، منفعة لنقطة محلية، فعل عناية، ومشاركة قصة بإذن. التقدم يحفظ محليًا في جهاز الزائر فقط؛ لا يوجد حساب أو دفع أو قرعة تلقائية. أي جائزة مالية أو منفعة عامة تحتاج شريكًا معلنًا وميزانية وشروطًا وآلية مراجعة قبل الإعلان.

## التصفية

تسمح الواجهة بالتصفية حسب:

- المدة: أقل من ساعة، من ساعة إلى ساعتين، أكثر من ساعتين.
- السهولة: سهل، متوسط.
- نوع التجربة: مشي، قصة، ورشة، طعام، طبيعة، عائلة.

التصفية واجهة اكتشاف فقط. لا تغيّر حالة المسار ولا تعني أن المسار أصبح متاحًا أو محجوزًا.

## حالات الثقة

تظهر بطاقة الثقة للمستخدم داخل كل بطاقة مسار، وتعرض:

1. حالة الوصول.
2. المصادر المستخدمة.
3. الأدلة المطلوبة التالية.
4. حالة الحجز أو غيابه.

لا يجوز إضافة مضيف أو سعر أو سعة أو نقطة لقاء من دون دليل قابل للمراجعة ومالك معلوم للمعلومة.

## التشغيل المحلي

```bash
python3 -m http.server 8765 --directory tourism
```

ثم افتح:

```text
http://127.0.0.1:8765/
```

## الاختبارات السريعة

```bash
node --check tourism/app.js
python3 -m json.tool tourism/data/routes.json >/dev/null
```

## حدود الإصدار

- لا توجد مدفوعات.
- لا توجد حجوزات تشغيلية مؤكدة.
- لا توجد بيانات مرور حية.
- لا توجد شراكة بلدية مثبتة.
- لا توجد جائزة مضمونة أو نقاط بيع مشاركة قبل اعتمادها ميدانيًا.
- بعض المدد والتصنيفات تحريرية وتحتاج تحققًا ميدانيًا.

الهدف من هذه النسخة هو اختبار: هل يفهم الزائر المسار وحدوده؟ وهل يستطيع الانتقال من القصة إلى بطاقة قابلة للمراجعة دون تضليل؟
